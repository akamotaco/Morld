# engine/perception — 감각 시스템 설계

## 개요

캐릭터가 환경에서 정보를 얻는 통합 감각 프레임워크.
기존 물리 시스템(sound, lighting, stealth, pollution)의 출력을 감각 필터로 가공하여
캐릭터별 감도에 따라 다른 해상도의 정보를 제공한다.

## 감각 채널

| 채널 | prop | 소스 시스템 | 감지 대상 |
|------|------|------------|-----------|
| 청각 | `감각:청각` | sound.py | 소리 (발소리, 전투, 대화, 동물) |
| 시각 | `감각:시각` | lighting.py | 밝기 기반 (흔적, 그림자, 움직임) |
| 직감 | `감각:직감` | stealth/combat | 위협, 적의, 기척 |
| 후각 | `감각:후각` | pollution.py | 냄새 (피, 연기, 오염, 음식) |

## 감도 수치

```
0     : 해당 감각 없음 (장애)
1~3   : 둔감 — 강한 자극만 감지
4~6   : 보통 — 일반적 수준
7~9   : 예민 — 세부 정보 감지
10+   : 초감각 — 정체/방향/수량까지 파악
```

기본값: 모든 채널 5 (보통). prop 미설정 시 기본값 적용.
장비/스킬/상태로 보정 가능 (예: "감각:청각" +3 귀걸이, 부상 시 -2).

## 해상도 테이블

### 청각 (sound.py 연동)

```
감지 조건: attenuated_intensity ≥ (15 - 감도)
  → 감도 5: threshold 10 (보통)
  → 감도 10: threshold 5 (keen)
  → 감도 1: threshold 14 (둔감)

해상도:
  감도 1~3: 카테고리만 — "소리가 들린다"
  감도 4~6: 타입 수준 — "발소리가 들린다" / "싸우는 소리가 들린다"
  감도 7~9: 타입+거리 — "가까운 곳에서 발소리가 들린다"
  감도 10+: 타입+거리+출처 — "북쪽에서 누군가 달려오고 있다"
```

### 시각 (lighting.py 연동)

```
감지 조건: brightness ≥ (0.5 - 감도 * 0.05)
  → 감도 5: threshold 0.25 (보통)
  → 감도 10: threshold 0.0 (암시)

해상도:
  감도 1~3: 존재만 — "무언가 있다"
  감도 4~6: 종류 — "발자국이 보인다" / "그림자가 움직인다"
  감도 7~9: 상세 — "늑대의 발자국이 보인다"
  감도 10+: 추적 — "늑대 2마리, 1시간 전 흔적"
```

### 직감 (stealth/combat 연동)

```
감지 조건: 인접 Location에 적대/은신 유닛 존재 + 감도 판정

해상도:
  감도 1~3: (감지 불가)
  감도 4~6: 분위기 — "불온한 기운이 느껴진다"
  감도 7~9: 위협도 — "적의가 느껴진다. 조심하는 게 좋겠다"
  감도 10+: 구체 — "전방에 늑대 2마리의 기척이 느껴진다"
```

### 후각 (pollution.py 연동)

```
감지 조건: location_pollution ≥ (20 - 감도 * 2)

해상도:
  감도 1~3: (감지 불가)
  감도 4~6: 존재 — "냄새가 난다"
  감도 7~9: 종류 — "피 냄새가 난다" / "음식 냄새가 난다"
  감도 10+: 방향+강도 — "남쪽에서 강한 연기 냄새"
```

## 기존 시스템 변경

| 시스템 | 변경 | 내용 |
|--------|------|------|
| sound.py | 없음 | SoundEvent 그대로 활용 |
| lighting.py | 없음 | get_detection_brightness() 그대로 |
| stealth.py | 없음 | 감지율 공식 그대로, 직감 채널이 추가 레이어 |
| pollution.py | 없음 | get_location_pollution() 그대로 |
| **perception.py** | **신규** | 위 시스템들의 출력을 감각 필터로 가공 |

기존 물리 시스템은 건드리지 않고, perception이 읽기 전용으로 조합한다.

## UI 연동

```
상황 화면 하단에 감각 정보 표시:

[청각] 가까운 곳에서 발소리가 들린다.
[직감] 불온한 기운이 느껴진다.
```

시나리오에서 `get_perception_texts(player_id)`를 호출하여 footer나 상황 텍스트에 삽입.

## 시나리오 확장

- **S02**: 레인저/도적 클래스에 감각 보정. 은신 시 직감으로 위험 회피.
- **S04**: 던전 탐색 시 청각으로 몬스터 감지. 척후 클래스에 직감 보너스.
- **S03**: 도시 환경에서 후각으로 오염 감지. 수사 시 시각으로 단서 발견.

## 구현 우선순위

```
Phase 1: 청각 (sound 연동) — 인프라 대부분 완성됨
Phase 2: 직감 (stealth/combat) — 감지 정보 가공
Phase 3: 시각 (lighting + 흔적) — 새 데이터 필요
Phase 4: 후각 (pollution) — 기존 시스템 활용
```
