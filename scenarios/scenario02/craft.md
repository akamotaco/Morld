# 크래프팅 시스템 테스트 체크리스트

## 현재 상태 요약

### 제작 시스템 분류
| 제작 방식 | 위치 | 만들 수 있는 것 |
|---------|------|----------------|
| 휴대용 제작 도구 | 어디서나 (도구 소지 필요) | 토끼 덫 |
| 제작대 | 창고(5) | 나무판, 목검, 토끼 덫 |

### 도구 위치
| 도구 | 위치 | Location ID | 오브젝트 |
|------|------|------------|---------|
| 도끼 | 창고 | 5 | 도구함(Toolbox) 안에 있음 |
| 낚시대 | 창고 | 5 | 도구함(Toolbox) 안에 있음 |
| 제작대 | 창고 | 5 | CraftingTable |
| 휴대용 제작 도구 | 캐릭터 생성 시 선택 | - | 인벤토리 |

### 이동 경로
```
거실(1) → 2층 복도(14) → 창고(5)
현관(0) → 앞마당(12) → 숲 입구(20) → 숲 깊은 곳(21)  # 나무, 토끼 굴 있음
```

## 1. 휴대용 제작 도구 테스트

### 토끼 덫 제작 (나뭇가지)
**사전 준비:**
- [ ] 휴대용 제작 도구 소지 (캐릭터 생성 시 "장인" 선택 또는 획득)
- [ ] 나뭇가지(branch) 3개 소지

**테스트 순서:**
1. [ ] 인벤토리에서 "휴대용 제작 도구" 클릭
2. [ ] "제작" 액션 클릭
3. [ ] 카테고리 선택 → "도구" 클릭
4. [ ] "토끼 덫" 레시피 클릭
5. [ ] 재료 확인 화면 표시
   - 나뭇가지: 보유/필요 개수 + 체크 표시
6. [ ] 제작 실행 → 15분 경과
7. [ ] 토끼 덫 1개 획득 확인
8. [ ] 나뭇가지 3개 소비 확인

### 토끼 덫 제작 (나무판)
**사전 준비:**
- [ ] 휴대용 제작 도구 소지
- [ ] 나무판(plank) 1개 소지

**테스트 순서:**
1. [ ] "휴대용 제작 도구" → "제작"
2. [ ] "도구" → "토끼 덫 (나무판)" 선택
3. [ ] 제작 실행 → 10분 경과
4. [ ] 토끼 덫 1개 획득 확인

## 2. 벌목/가지 줍기 테스트

### 사전 준비
- [ ] 도끼 소지 확인 (`axe`)
- [ ] 도끼 장착 (`equip@inventory`) - can:chop 활성화

### 테스트 순서
1. [ ] 숲 깊은 곳(21)으로 이동
2. [ ] 나무(Tree) 클릭
3. [ ] "벌목" 액션이 표시되는지 확인 (can:chop 필요)
4. [ ] 벌목 실행 → 15분 경과
5. [ ] 60% 확률로 통나무 획득 확인 (인벤토리)
6. [ ] 통나무가 같은 슬롯에 쌓이는지 확인 (싱글톤 ID 시스템)

### 가지 줍기 테스트
1. [ ] "가지 줍기" 액션 클릭 (도구 불필요, can:gather 필요)
2. [ ] 5분 경과
3. [ ] 80% 확률로 나뭇가지 획득 확인

### 예상 결과
- 통나무(log): 60% 확률, 1개 획득
- 나뭇가지(branch): 80% 확률, 1개 획득
- 나무 자원 개수 감소
- 같은 아이템은 동일 슬롯에 쌓임

## 5. 토끼 사냥 시스템 테스트

### 토끼 덫 설치
**사전 준비:**
- [ ] 토끼 덫(rabbit_trap) 1개 이상 소지
- [ ] 숲 깊은 곳(21)에 토끼 굴(rabbit_burrow) 존재

**테스트 순서:**
1. [ ] 숲 깊은 곳(21)으로 이동
2. [ ] 토끼 굴 클릭
3. [ ] 인벤토리에서 토끼 덫 선택 → "넣기" 액션
4. [ ] 토끼 굴의 묘사가 "덫이 설치되어 있다"로 변경 확인

### 토끼 포획 대기
**예상 동작:**
- 6시간(360분)마다 40% 확률로 토끼 포획 체크
- 성공 시 토끼 덫 → 토끼가 붙잡힌 덫으로 교체
- 한 번에 하나의 덫만 체크 (여러 덫이 있어도)

**테스트 순서:**
1. [ ] 시간 경과 (6시간 이상)
2. [ ] 토끼 굴 확인
3. [ ] "토끼가 걸린 덫" 표시 확인

### 토끼 사체 획득
**테스트 순서:**
1. [ ] 토끼 굴에서 "토끼가 붙잡힌 덫" 가져가기
2. [ ] 인벤토리에서 "토끼가 붙잡힌 덫" 클릭
3. [ ] "분해" 액션 클릭 (can:disassemble 필요)
4. [ ] 5분 경과
5. [ ] 토끼 사체(rabbit_carcass) 1개 획득 확인
6. [ ] 토끼가 붙잡힌 덫 소멸 확인 (부서짐)

## 참고: 아이템 unique_id 목록

### 도구
| unique_id | 이름 | 위치 | 기능 |
|-----------|------|------|------|
| `axe` | 도끼 | 창고 도구함 | 장착: can:chop |
| `fishing_rod` | 낚시대 | 창고 도구함 | 장착: can:fish |
| `small_toolbox` | 휴대용 제작 도구 | 캐릭터 생성 | 휴대 제작 가능 |
| `rabbit_trap` | 토끼 덫 | 제작 | 토끼 굴에 설치 |

### 재료
| unique_id | 이름 | 카테고리 | 획득 방법 |
|-----------|------|---------|----------|
| `log` | 통나무 | material | 벌목 (도끼 장착, 60% 확률) |
| `branch` | 나뭇가지 | material | 가지 줍기 (80% 확률) |
| `plank` | 나무판 | material | 제작대에서 통나무 가공 |

### 사냥 관련
| unique_id | 이름 | 획득 방법 |
|-----------|------|----------|
| `trapped_rabbit` | 토끼가 붙잡힌 덫 | 토끼 굴에서 덫으로 포획 |
| `rabbit_carcass` | 토끼 사체 | 붙잡힌 덫 분해 |

### 제작품
| unique_id | 이름 | 제작 위치 | 재료 | 효과 |
|-----------|------|----------|------|------|
| `plank` | 나무판 | 제작대 | 통나무 1 | - |
| `wooden_sword` | 목검 | 제작대 | 나무판 2 | 공격 +3 |
| `rabbit_trap` | 토끼 덫 | 휴대/제작대 | 나뭇가지 3 또는 나무판 1 | - |

### 네이밍 규칙
- 재료류: category = "material"
- 도구류: equip_props에 특수 능력 부여

## 기술 구현 노트

### 싱글톤 아이템 ID 시스템
- `get_or_create_item_id(unique_id)` 함수로 동일 아이템 ID 보장
- 같은 unique_id 아이템은 항상 같은 instance_id 반환
- 인벤토리에서 같은 슬롯에 쌓임

### 재료 확인 로직
- `check_materials()`: 인벤토리를 unique_id 기준으로 합산하여 확인
- 여러 슬롯에 분산된 같은 아이템도 정상 인식

### 자원 보충 주기 (resource_agent)
| 자원 | 보충 주기 | 나무 종류 |
|------|----------|----------|
| 통나무 | 24시간 (1440분) | Tree, PineTree, OakTree, AppleTree |
| 나뭇가지 | 8시간 (480분) | Tree, PineTree, OakTree, AppleTree |

### 토끼 덫 체크 주기 (trap_agent)
| 오브젝트 | 체크 주기 | 성공 확률 |
|---------|----------|----------|
| 토끼 굴 | 6시간 (360분) | 40% |
