## 2. 벌목 테스트

### 사전 준비
- [ ] 도끼 소지 확인 (`axe`)
- [ ] 도끼 장착 (`equip@inventory`) - can:chop 활성화

### 테스트 순서
1. [ ] 숲 깊은 곳(21)으로 이동
2. [ ] 나무(Tree) 클릭
3. [ ] "벌목" 액션이 표시되는지 확인 (can:chop 필요)
4. [ ] 벌목 실행 → 15분 경과
5. [ ] 60% 확률로 통나무 획득 확인 (인벤토리)
6. [ ] 통나무가 같은 슬롯에 쌓이는지 확인 (싱글톤 ID 시스템)

### 가지 줍기 테스트
1. [ ] "가지 줍기" 액션 클릭 (도구 불필요)
2. [ ] 5분 경과
3. [ ] 80% 확률로 나뭇가지 획득 확인

### 예상 결과
- 통나무(log): 60% 확률, 1개 획득
- 나뭇가지(branch): 80% 확률, 1개 획득
- 나무 자원 개수 감소
- 같은 아이템은 동일 슬롯에 쌓임

## 3. 제작대 - 나무판 가공 테스트

### 레시피
| 결과물 | 재료 | 제작 시간 | 생성 개수 |
|-------|------|----------|----------|
| 나무판 | 통나무 1 | 10분 | 3개 |

### 사전 준비
- [ ] 통나무(log) 1개 이상 소지
- [ ] 창고(5)로 이동

### 테스트 순서
1. [ ] 창고(5)로 이동
2. [ ] 제작대 클릭
3. [ ] "제작하기" 액션 클릭
4. [ ] 카테고리 선택 → "재료" 클릭
5. [ ] "나무판" 레시피 클릭
6. [ ] 재료 확인 화면 표시
   - 통나무: 보유/필요 개수 + 체크 표시
7. [ ] 제작 실행 → 10분 경과
8. [ ] 나무판 3개 획득 확인
9. [ ] 통나무 1개 소비 확인

### 예상 결과
- "나무판 3개를 만들었다!" 메시지
- 나무판(plank) 3개 인벤토리에 추가
- 통나무 1개 소비

## 4. 플레이어 제작 테스트 (화살)

### 레시피
| 결과물 | 재료 | 제작 시간 | 생성 개수 |
|-------|------|----------|----------|
| 화살 | 나무판 1 + 깃털 1 | 10분 | 5개 |

### 사전 준비
- [ ] 나무판(plank) 1개 이상 소지
- [ ] 깃털(feather) 1개 이상 소지

### 깃털 획득 방법
**참고:** 현재 깃털은 게임 내에서 직접 획득 방법이 구현되지 않음
- 향후: 사냥으로 획득 예정

### 테스트 순서
1. [ ] 화면 하단 "제작" 버튼 클릭 (플레이어 액션)
2. [ ] 카테고리 선택 → "무기" 클릭
3. [ ] "화살" 레시피 클릭
4. [ ] 재료 확인 화면 표시
   - 나무판: 보유/필요 개수 + 체크 표시
   - 깃털: 보유/필요 개수 + 체크 표시
5. [ ] 재료가 충분하면 "제작하기" 버튼 활성화
6. [ ] 재료가 부족하면 "재료가 부족합니다" 표시
7. [ ] 제작 실행 → 10분 경과
8. [ ] 화살 5개 획득 확인
9. [ ] 나무판 1개, 깃털 1개 소비 확인

### 예상 결과
- "화살 5개를 만들었다!" 메시지
- 화살(arrow) 5개 인벤토리에 추가

## 7. 제작 분리 테스트

### 플레이어 제작에서 제작대 전용 아이템이 없는지 확인
1. [ ] 아무 곳에서나 "제작" 버튼 클릭
2. [ ] "무기" 카테고리 선택
3. [ ] 화살만 표시되고, 목검/사냥용 활은 표시되지 않아야 함
4. [ ] "재료" 카테고리가 표시되지 않아야 함

### 제작대에서 플레이어 전용 아이템이 없는지 확인
1. [ ] 창고(5)로 이동
2. [ ] 제작대 클릭 → "제작하기"
3. [ ] "재료" 카테고리에 나무판 표시
4. [ ] "무기" 카테고리에 목검, 사냥용 활 표시
5. [ ] 화살은 표시되지 않아야 함

## 참고: 아이템 unique_id 목록

### 도구
| unique_id | 이름 | 위치 | 기능 |
|-----------|------|------|------|
| `axe` | 도끼 | 창고 도구함 | 장착: can:chop |
| `fishing_rod` | 낚시대 | 창고 도구함 | 장착: can:fish |

### 재료
| unique_id | 이름 | 카테고리 | 획득 방법 |
|-----------|------|---------|----------|
| `log` | 통나무 | material | 벌목 (도끼 장착, 60% 확률) |
| `branch` | 나뭇가지 | material | 가지 줍기 (80% 확률) |
| `plank` | 나무판 | material | 제작대에서 통나무 가공 |
| `cord` | 끈 | material | (미구현) |
| `feather` | 깃털 | material | (미구현) |

### 제작품
| unique_id | 이름 | 제작 위치 | 재료 | 효과 |
|-----------|------|----------|------|------|
| `plank` | 나무판 | 제작대 | 통나무 1 | - |
| `wooden_sword` | 목검 | 제작대 | 나무판 2 | 공격 +3 |
| `hunting_bow` | 사냥용 활 | 제작대 | 나무판 2 + 끈 1 | - |
| `arrow` | 화살 | 플레이어 제작 | 나무판 1 + 깃털 1 | - |

### 네이밍 규칙
- 재료류: category = "material"
- 도구류: equip_props에 특수 능력 부여

## 기술 구현 노트

### 싱글톤 아이템 ID 시스템
- `get_or_create_item_id(unique_id)` 함수로 동일 아이템 ID 보장
- 같은 unique_id 아이템은 항상 같은 instance_id 반환
- 인벤토리에서 같은 슬롯에 쌓임

### 재료 확인 로직
- `check_materials()`: 인벤토리를 unique_id 기준으로 합산하여 확인
- 여러 슬롯에 분산된 같은 아이템도 정상 인식

### 자원 보충 주기 (resource_agent)
| 자원 | 보충 주기 | 나무 종류 |
|------|----------|----------|
| 통나무 | 24시간 (1440분) | Tree, PineTree, OakTree, AppleTree |
| 나뭇가지 | 8시간 (480분) | Tree, PineTree, OakTree, AppleTree |
