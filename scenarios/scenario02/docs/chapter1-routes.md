# 챕터 1 공략 루트 가이드

> 숲속 저택의 '알파' 지위를 획득하면 챕터 1 종료.
> 모든 경로는 혼합 가능하며, 기존 시스템의 유기적 연계로 동작.

---

## 알파 달성 조건 (OR)

1. **전원 신뢰/복종**: 세라+밀라+리나 모두 (신뢰≥10+호감≥60) 또는 (복종≥70)
2. **저택 점령**: `스토리:저택점령` prop (추방 후 귀환 전투 승리)
3. **세력 소멸**: 숲속 저택 세력의 활동 가능 인원 = 0 (전원 사망 or 전신결박)

---

## 캐릭터 역할

| 캐릭터 | 내부 공략 | 외부 공략 | 특성 |
|--------|----------|----------|------|
| 세라 | **내부 장벽** (리더/알파) | 전투력 보통 (공8/방5) | 경계심 높음, 협박/약점으로 무너뜨림 |
| 밀라 | 은근 지원 (플레이어 호감) | **외부 장벽** (공12/방8) | 은퇴한 전설의 전사, 내부에선 아군 |
| 리나 | 회유 대상 (순수, 낯가림) | 비전투 | 시간 들여 마음 열기 |

---

## 루트 A: 신뢰 루트 (평화적)

### 흐름
```
매일 일일퀘스트 수행 → 신뢰 +1
선물 + 대화 → 호감 축적
3명 모두 신뢰≥10 + 호감≥60 → 알파
```

### 핵심 행동
- 세라의 일일퀘스트 (매일 3개 중 선택) 성실히 수행
- 획득 아이템으로 선물 (GIFT_PREFERENCES 참고)
- 호감 임계치(30/50/70) 돌파 시 태도 변화 + 심화 대화 해금

### 주의사항
- 퀘스트 실패 시 신뢰 -1 (자동 — 18시 마감)
- 신뢰 -3 이하 → 추방 트리거
- 밀라는 내심 호감이지만 겉으로 안 드러냄 → 꾸준히 쌓아야 함
- 리나는 낯가림 → 초반에 대화가 짧고 회피적

### 소요 시간 (추정)
신뢰 10 도달: 최소 10일 (매일 퀘스트 성공) + 호감 60: 선물/대화 병행

---

## 루트 B: 굴복 루트 (내부 공략)

### 흐름
```
약점 발견 → 협박 → 단둘이 강제 행위 → 복종 축적
3명 모두 복종≥70 → 알파
```

### 단계별 공략

#### 1단계: 약점 수집
| 캐릭터 | 약점 | 발동 조건 | 효과 |
|--------|------|----------|------|
| 세라 | 자위 발각 | 밤 + 세라 방 앞 도달 | 협박 선택지, 복종 +15 |
| 세라 | 성인용품 발견 | 세라 부재 시 방 뒤지기 | 대화에서 언급 가능, 복종 +10 |
| 세라 | 부상 간호 | 사냥 후 부상 이벤트 | 심리적 우위, 반발 -10 |
| 리나 | 호기심 발각 | 성적 콘텐츠 보다 걸림 | 수치심, 복종 +15 |
| 리나 | 음주 | 약초주 제공 | 일시적 반발 -20 |
| 리나 | 악몽/공포 | 밤 + 날씨 조건 | 의존감, 호감+5/복종+5 |
| 밀라 | 호감 들킴 | 다른 NPC가 지적 | 동요, 이용 가능 |
| 밀라 | 비밀 일기 | 방 뒤지기 | 협박 소재, 복종+10/반발+5 |

#### 2단계: 강제 행위 (단둘이 필수)
- `is_alone_with()` — 플레이어 + 대상만 있는 위치
- NPC 스케줄을 파악하여 단둘이 되는 시간대 노림
- 약점 발동 후 "협박/위협" 선택지 등장
- 강제 성행위 → 기존 romance 시스템의 복종 자연 증가

#### 3단계: 발각 관리
- 행위 중 다른 NPC 도착 → 발각
- Sound 전파 시스템 → 소리가 크면 호기심으로 NPC 이동
- **밀라 발각**: 호감≥30이면 눈감아줌 / 미만이면 추방
- **리나/세라 발각**: 추방

### 권장 공략 순서
1. **리나 먼저** — 순수한 만큼 약점에 취약, 밀라가 눈감아줌
2. **세라** — 리더라 가장 어려움, 약점 2개 이상 확보 후 시도
3. **밀라** — 내심 호감이라 마지막, 가장 어려움 (전투력도 최강)

---

## 루트 C: 다수결 루트 (내부 혼합)

### 흐름
```
리나 + 밀라를 플레이어 편으로 → 다수결로 세라 강제 굴복
```

### 조건
- 리나: 호감≥50 OR 복종≥50
- 밀라: 호감≥50 OR 복종≥50
- 이 둘이 플레이어 편 → `check_majority_against("세라")` = True

### 효과
- 세라는 리나·밀라에게 약한 면이 있음
- 반발은 심하지만 수적 열세로 굴복
- 세라 복종 대폭 증가 → 알파 달성

### 장점
- 세라를 직접 공략하지 않아도 됨
- 발각 위험 낮음 (세라와 단둘이 안 해도 됨)

---

## 루트 D: 추방 → 귀환 점령 (외부 공략)

### 추방 트리거
- 발각 (굴복 루트 실패) → `check_discovery()` = "expulsion"
- 신뢰 바닥 (퀘스트 실패 누적, 신뢰 ≤ -3) → 자동 추방

### 추방 효과
- 도시로 이동 (텔레포트)
- 저택 NPC 전원: 호감 -15, 반발 +20, 세력도 → 적대(-1)
- 약점 정보는 유지됨

### 도시에서 합류

#### 유키 합류
| 방법 | 조건 | 효과 |
|------|------|------|
| 설득 | 호감≥50 | 자발적, 호감+5 |
| 납치 | 조건 없음 | 반발+30 |

#### 엘라 합류
| 방법 | 조건 | 효과 |
|------|------|------|
| 설득 | 호감≥60 | 자발적, 호감+5 |
| 협박 (유키 인질) | 유키 먼저 합류 | 반발+40, 분노 |

### 귀환 전투
```
플레이어(공3) + 엘라(공7) + 유키 vs 밀라(공12) + 세라(공8) + 리나

핵심: 밀라가 최종 장벽 (은퇴한 전설의 전사)
→ 장비/레벨업으로 전투력 확보 필요
→ 또는 세라·리나 먼저 무력화 후 밀라 집중
```

### 전투 후 처리
- 기절한 NPC에 대한 선택:

| 행동 | 시스템 | 효과 |
|------|--------|------|
| 방치 | survival.py | 시간 지나면 회복 (다시 적대) |
| 확인사살 | story.execute_finish() | 영구 사망 → 세력 인원 감소 |
| 결박 | restraint.attempt_restrain(unconscious) | 행동 불능 → 세력 인원 감소 |
| 운반 | carry.py | 원하는 장소로 이동 |

### 점령 완료
- 세력 인원 0 (전원 사망/전신결박) → 알파 자동 달성
- 또는 `apply_mansion_conquest()` → 점령 플래그 + 세력 중립 복원

## 루트 E: 결박 + 회유/복종 (장기전)

### 흐름
```
전투로 기절 → 결박 → 장기간 회유 or 복종 → 아군 전환
```

### 결박 상태에서 가능한 행동

| 행동 | 카테고리 | 효과 |
|------|---------|------|
| 대화 (talk) | 회유 | TALK_RULES 결박 분기, 호감 축적 |
| 선물 (give_gift) | 회유 | 호감 증가 (GIFT_PREFERENCES) |
| 음식 제공 | 회유 | 포만감 회복 + 호감 소폭 |
| 강제 행위 (force_romance) | 복종 | 복종 축적 (romance 시스템) |
| 성추행 | 복종 | 성욕 자극 + 반발 |
| 의류 강탈 | 복종 | 수치심 → 복종 보조 |
| 미약 사용 | 복종 | 저항력 일시 감소 |

### 결박 해제 조건
- NPC 자력 해제 시도 (30분마다, 확률 기반)
- 전신결박(상체+하체) → 해제 불가
- 부분결박 → 해제 확률 존재, 결박:강도에 따라 달라짐

### 스톡홀름 효과
- 반발 상승 + 호감/복종 동시 축적
- 기존 항상성(homeostasis)이 자연스럽게 밸런스 조절
- 장기간 회유 시 반발 감소, 호감 우위 → 아군 전환 가능

---

## 루트 F: 몰살 루트 (극단)

### 흐름
```
전투로 전원 기절 → 확인사살 → 세력 소멸 → 알파
```

### 주의사항
- 챕터 2에서 함께할 NPC가 없음
- 유키·엘라만 남음 (합류 시)
- 페이 합류 불가 (거래 신뢰 경로 — NPC 부재)
- **가장 자유롭지만 가장 외로운 결말**

---

## 루트 혼합 예시

### 예시 1: 세라=굴복, 밀라=신뢰, 리나=신뢰
```
리나에게 선물·대화 → 호감 축적
밀라는 자연스럽게 호감 상승 (내심 플레이어 편)
세라만 약점+협박으로 복종
→ 알파 달성 (혼합)
```

### 예시 2: 내부 실패 → 추방 → 외부 점령 → 결박 회유
```
세라 공략 중 발각 → 추방
도시에서 유키·엘라 합류 (납치)
저택 귀환 → 전투 → 전원 기절
밀라: 결박 + 회유 (내심 호감이라 빠르게 전향)
세라: 결박 + 복종 (강제)
리나: 결박 + 회유 (순수해서 시간 걸림)
→ 전원 아군 전환 후 결박 해제 → 알파
```

### 예시 3: 다수결 + 약점 조합
```
리나: 음주 → 약화 → 회유
밀라: 호감 자연 축적 (호감≥50)
→ 다수결로 세라 강제 굴복
→ 알파 달성
```

## 페이 합류 (선택)

| 경로 | 조건 | 비고 |
|------|------|------|
| 거래 신뢰 | 호감≥60 | 장기 거래로 친밀도 축적 |
| 위기 구출 | 숲에서 페이 구출 이벤트 | 빠른 합류 |
| 전속 상인 | 알파 달성 후 제안 | 안정적 |
| 협박 | 성인용품 판매 비밀 | 반발 높음 |
| 빚 | 외상 거래 → 체류 → 정착 | 자연스러움 |

합류 후: `faye_resident.py` (FayeResident 클래스) — 상인 기능 유지 + 일반 생활

## 시스템 연계 요약

```
피로 시스템 ──→ 강제 수면 ──→ 퀘스트 타임아웃 ──→ 신뢰 하락 ──→ 추방
     │                              │
     └── 행동 피로 (전투/채집)        └── 일일퀘스트 자동 실패

결박 시스템 ──→ 이동 불가 ──→ 세력 인원 감소 ──→ 알파 판정
     │              │
     └── 회유 가능    └── 강제 행위 가능 (romance)

Sound 전파 ──→ NPC 호기심 이동 ──→ 발각 ──→ 추방 (게임오버 아님)

세력 시스템 ──→ 추방 시 적대 ──→ 귀환 시 전투 ──→ 기절 ──→ 결박/사살
```
