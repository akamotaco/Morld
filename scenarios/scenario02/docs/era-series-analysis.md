# era 시리즈 분석 — 스탯 모델 참고

> 본 문서는 morld S02의 연애/성적 스탯 재설계를 위한 참고 분석.
> era 시리즈(특히 era TW)의 구조를 정리하여 morld S02와의 매핑 및 갭을 식별한다.
> **구현 가이드가 아닌 설계 연구 문서**.

---

## 1. 시리즈 개요

### 1.1 공통 프레임워크
- **EraBasic (EraB)** 스크립팅 엔진 기반
- 텍스트 인터페이스, 커뮤니티 포크 문화
- 공통 스탯 어휘(好感度/欲情/快楽 등)가 타이틀 간 유지됨
- 세계관은 타이틀마다 다르지만 **스탯 철학은 공통**

### 1.2 주요 타이틀
| 타이틀 | 세계관 | 특징 |
|---|---|---|
| era TW | 동방 Project | 샌드박스 생활 시뮬, 장기 포크 |
| era Megaten | 진 여신전생 | 악마 + 조교 융합 |
| era K | 칸코레 | 함대 + 육성 |
| era SR | 센란 카구라 | 닌자 학교 |
| era 妹 IF | 오리지널 | 가족 중심 |

morld S02(저택+마을+스케줄)와 구조적으로 가장 가까운 것은 **era TW**.

## 2. era TW 포지셔닝

### 2.1 세계관
- 동방 Project의 환상향(幻想郷)
- 플레이어는 인간/요괴/천구 등 종족 선택 가능
- NPC(레이무/마리사/사쿠야 등 다수)는 각자 세력과 위치 소유

### 2.2 구조적 특성
- **생활 시뮬레이션 중심**: 시간/날짜/스케줄
- **위치 기반 이동**: 신사/마을/숲/저택
- **직업/소속**: NPC가 고유 역할 수행
- **샌드박스**: 플레이어 자유도 높음
- **장기 포크**: 수년간 커뮤니티 업데이트로 스탯이 정교화됨

→ morld S02와 매우 유사한 구조. 참고 대상으로 적합.

## 3. 공통 스탯 프레임워크

### 3.1 관계 축 (per A→B, 양방향)

| 스탯 | 의미 | 상승 계기 | 특징 |
|---|---|---|---|
| **好感度** | 긍정 감정 | 대화, 선물, 도움 | 기본 축 |
| **愛情** | 연애 감정 | 好感度 고단계 + 이벤트 | 상위 티어, 연인 진입 |
| **隷属度** | 복종/예속 | 조교, 굴복 경험 | 별도 경로 — 好感 낮아도 허용 |
| **反抗心** | 반항 | 강제, 배신 | 隷属와 상반 |
| **苦痛** | 누적 고통 | 가학 행위 | 정신 상태에 영향 |
| **快楽** | 누적 쾌락 | 합의/조교 행위 | 허들 낮춤 (corruption 유사) |

**핵심 통찰**: 관계는 **다축**이며 상호 배타적이지 않다.
- 高好感 + 低隷属 = 연인 경로
- 低好感 + 高隷属 = 노예 경로
- 둘 다 허용되는 행위 판정으로 연결

### 3.2 독립 상태 (per character)

| 스탯 | 타임스케일 | 의미 |
|---|---|---|
| **体力** | 일 단위 | 육체 피로, 행동 포인트 |
| **気力** | 일 단위 | 정신 에너지, 의지력 |
| **精神力** | 일 단위 | 정신 충격 저항 |
| **欲情** | 일 단위 | 성적 충동 (자연 상승/배출로 감소) |
| **正気度** | 장기 | 정신 건강 (극단 상황에 감소) |
| **羞恥** | 장기 감소 | 수치심 (초기 높음, 경험으로 감소) — 일부 타이틀 |

### 3.3 경험/능력 (per character, 영구 누적)

| 스탯 | 의미 |
|---|---|
| **感度[부위]** | 부위별 민감도 (경험으로 상승) |
| **経験[부위]** | 부위별 사용 횟수 |
| **処女[부위]** | 미경험 플래그 (0/1) |
| **性知識** | 성적 지식 레벨 (특정 행위 이해/수용) |
| **調教経験** | 조교 받은 경험치 |

### 3.4 재생산

| 스탯 | 의미 |
|---|---|
| **月経周期** | 생리 주기 (배란일 추적) |
| **妊娠** | 임신 상태 + 주차 |
| **精液濃度** | 사정 질 |
| **体内精液** | 체내 잔류량 |

### 3.5 소유

| 스탯 | 의미 |
|---|---|
| **所持金** | 현금 |
| **装備** | 의복/장신구/성인용품 |
| **所持品** | 인벤토리 |

## 4. era TW 특이 요소

### 4.1 종족/소속
- 플레이어/NPC 종족별 스탯 보정
- 세력(신사/인간마을/요괴산/홍마관 등) 소속
- 세력 간 호감도가 별도 존재

### 4.2 TALENT (탤런트)
- 캐릭터별 특수 속성 플래그
- 예: 천연, 음란, 결벽, 처녀고집, 모성본능
- 스탯 변화율/허용 행위를 변조

### 4.3 CFLAG / MARK
- **CFLAG**: 캐릭터 로컬 플래그 (이벤트 진행도)
- **MARK**: 특수 상태 (노예 표식/각인 등)

### 4.4 NPC ↔ NPC 관계
- 好感度[A][B]: A가 B에 대한 호감
- NPC끼리도 관계 형성/행위 가능
- 플레이어가 관찰자로 개입

### 4.5 스케줄/위치 기반 샌드박스
- 시간대별 NPC 위치/활동
- 플레이어 개입 또는 관찰
- 계절/이벤트 시스템

## 5. 핵심 메커니즘

### 5.1 3-path 허가 모델

행위 허용 조건이 **OR**로 연결된 다중 경로:

```
행위 X 허용 ⇔
  (好感度 ≥ Req_affection)  // 연애 경로
  OR (隷属度 ≥ Req_servitude) // 조교 경로
  OR (欲情 ≥ Req_lust AND 反抗 < Limit) // 충동 경로
  AND (처녀/체력/지식 등 선결조건)
```

이 구조가 era 시리즈의 **서사적 유연성**을 만든다 — 같은 행위에 여러 도달 경로.

### 5.2 調教 (조교) 시스템
- 반복적 행위로 **快楽/隷属** 누적
- 快楽 누적 → 같은 행위 재수용 허들 낮아짐 (corruption)
- 隷属 고도화 → 반항 감소 → 저항 포기
- **"장기 음란 개발"** 메커니즘

### 5.3 欲情 자연 변동
- 아침 기상 시 +N (아침 발기/각성)
- 시간대별 +K
- 사정/자위 후 -M
- 상대 관찰/접촉으로 +L
- 체력 낮으면 감소율 증가

### 5.4 수치심 곡선 (타이틀별 존재 여부 상이)
- 초기 높음 → 경험/快楽으로 감소
- 낮을수록 노출/공개 행위 허용
- era TW는 약한 편, 다른 타이틀은 강한 축

## 7. 갭 분석

### 7.1 명백한 갭 — 제거 권장
- **`관계:{p}:욕망`**: era에 대응 개념 없음. 플레이어별 욕정은 `성욕(독립) × 호감(관계)`로 자연 표현 가능. 유지 시 이중 회계 + 디버그 혼선.

### 7.2 핵심 갭 — 도입 고려
- **快楽 누적 스탯** (`상태:쾌락`): era TW의 허들 낮추기 핵심 메커니즘
- **愛情 티어** (`관계:{p}:애정`): 호감 상위 — 연인/결혼 구분
- **調教経験** (`상태:조교경험`): 隷属 경로 진행 가시화

### 7.3 선택적 갭 — 서사 깊이용
- **苦痛 누적** (`상태:고통`): 가학 서사 확장용
- **性知識** (`상태:성지식`): 순수/경험 분리용
- **羞恥**: era TW는 약함, 도입 시 초기 거절 서사 강화

### 7.4 구조적 갭
- **NPC↔NPC 관계 행렬**: 현재 약함. 그룹 생활 시뮬 확장 시 필요

## 8. 설계 제안 (대안)

### 8.1 보수안 — 현재 구조 최소 정비
- `관계:{p}:욕망` 삭제 → 모든 참조를 `상태:성욕`으로 이관
- can_start_romance 3-path 게이트로 변경
- 기타 변경 없음

### 8.2 표준안 — era TW 핵심만 도입
- 보수안 + 다음 추가:
  - `관계:{p}:애정` (상위 티어)
  - `상태:쾌락` (누적) — 기존 `경험:{부위}` 합계 캐시
- 게이트 공식 확장:
  ```
  행위 허용 ⇔
    호감 ≥ R_aff
    OR 애정 ≥ R_love
    OR 복종 ≥ R_sub
    OR (성욕 ≥ R_lust AND 쾌락 ≥ R_pleasure AND 반발 < L_reb)
  ```

### 8.3 확장안 — era TW 완전 재현
- 표준안 + 다음 추가:
  - `상태:고통` / `상태:조교경험` / `상태:수치심`
  - NPC↔NPC 관계 행렬
  - TALENT 시스템 (캐릭터별 성향 플래그)
- **작업량 크다**. 장기 로드맵용.

## 9. morld 확장 방향 — era의 superset

> **핵심 방향성**: morld는 era 시리즈를 축소한 형태가 아니라 **확장한 형태**를 지향한다.
> 평범한 연애/데이트부터 NTR/NTL/플레이어가 당하는 서사까지 포괄.

### 9.1 확장 범위

| 카테고리 | 예시 시나리오 | era 커버리지 |
|---|---|---|
| 순애 | 스타듀 벨리식 데이트/연애/결혼 | 약 (era는 조교 중심) |
| 평범한 스킨쉽 | 손잡기, 키스, 합의 성행위 | 중 |
| 조교/지배 | era TW식 隷属 경로 | 강 |
| **NTR** (player 피해자) | 플레이어 파트너가 타 NPC와 관계 | 약 (타이틀별) |
| **NTL** (player 공유자) | 플레이어가 파트너 공유 허용 | 약 |
| **플레이어 피지배** | NPC가 플레이어를 지배/이용 | 약 |
| 군상극 | NPC↔NPC 연애/배신 | 중 |

### 9.2 확장에 필요한 신규 스탯 (섹션 3/6을 넘어서)

#### 9.2.1 NTR 지원
- `관계:{a}:충성:{b}` — a가 b에게 갖는 충성심 (배신 저항)
- `관계:{a}:질투:{b}` — a가 b→제3자 관계에 느끼는 질투
- `상태:비밀행위` — 은밀 모드 플래그
- 발각 이벤트 훅 (witness mechanics)

#### 9.2.2 NTL 지원
- `플레이어:공유허용:{target}` — 플레이어의 명시적 동의
- `상태:관음참여도` — 관찰자 흥분
- `플레이어:성벽:{tag}` — 플레이어 본인 페티시 플래그

#### 9.2.3 플레이어 피해자 경로
- **플레이어 본인 스탯 풀세트** — 현재 morld는 플레이어 스탯이 얇음
  - `플레이어:상태:성욕`
  - `플레이어:상태:수치심`
  - `플레이어:상태:복종:{npc}` — 역방향 지배 관계
  - `플레이어:경험:{부위}`
  - `플레이어:처녀:{부위}`
- 저항/굴복 선택지 시스템
- 역방향 게이트 (NPC가 플레이어에게 행위 시도)

#### 9.2.4 군상극 지원
- NPC↔NPC 관계 행렬 완성
- NPC 상호 스케줄 기반 발생 이벤트
- 플레이어 관찰자 모드

### 9.3 설계 원칙 (확장 시 지키기)

1. **독립 vs 관계 구분 유지**: 어떤 스탯이든 명확히 한쪽 네임스페이스
2. **대칭성**: NPC 스탯은 모두 플레이어에도 존재 가능 (역할 교환)
3. **선택적 활성화**: 확장 기능은 기본값으로 비활성 → 시나리오별 on
4. **era 호환 어휘**: 기존 era 관용 명칭을 최대한 재사용 (번역 품질)

## 10. 즉시 결정된 항목 (2026-04-21)

### 10.1 `관계:{p}:욕망` 삭제 확정
