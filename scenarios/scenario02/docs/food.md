## 3. 토끼 사냥 테스트

### 토끼 생고기 획득 흐름
```
토끼 굴에 토끼 덫 설치 → 6시간 대기 (40% 확률) → 토끼가 붙잡힌 덫 획득
→ 분해 → 토끼 사체 획득 → 박피 (날붙이 소지 필요) → 토끼 생고기 + 토끼 가죽
```

### 필요 도구
| 도구 | 위치 | 획득 방법 |
|------|------|----------|
| 토끼 덫 | - | 휴대용 제작 도구로 제작 (나뭇가지 3개 또는 나무판 1개) |
| 날붙이 (칼/단검) | 창고(5) 도구함 | 투박한 단검(세라 소유) 또는 낡은 칼(사냥꾼 선택 시 초기 장비) |

### 테스트 순서
1. [ ] 휴대용 제작 도구로 토끼 덫 제작
2. [ ] 숲속(숲 Region 3)으로 이동
3. [ ] 토끼 굴 클릭 → container UI
4. [ ] 토끼 덫 "넣기"
5. [ ] 6시간 이상 시간 경과 (휴식, 수면 등)
6. [ ] 토끼 굴 확인 → "토끼가 붙잡힌 덫" 획득
7. [ ] 인벤토리에서 "토끼가 붙잡힌 덫" → "분해"
8. [ ] 토끼 사체 획득 확인
9. [ ] 인벤토리에서 "토끼 사체" → "박피"
   - 날붙이가 여러 개면 도구 선택 다이얼로그 표시 (소요 시간 함께 표시)
   - 소요 시간: 도구별 상이 (낡은 칼 20분, 투박한 단검 15분)
10. [ ] 토끼 생고기 + 토끼 가죽 획득 확인

### 박피 조건
- **필수:** 날붙이 소지 (can:skin 능력 - passive_props)
- **장착 불필요:** 소지만 해도 박피 가능
- **도구 선택:** 날붙이가 여러 개면 선택 다이얼로그 표시
- **날붙이 종류 및 소요 시간:**
  - 낡은 칼 (old_knife) - 사냥꾼 초기 장비, **20분**
  - 투박한 단검 (rustic_dagger) - 창고 도구함 (세라 소유), **15분**

## 8. NPC 식사 시스템 — v0.2.1 추가

### 만복도 추적
- 캐릭터 prop: `생존:포만감` (초기 80, 최대 100)
- 감소율: 1시간당 1 (하루 24)
- `survival.register_npc(unit_id)` → Agent __init__에서 호출
- `survival.is_npc_hungry(unit_id, threshold=30)` → 배고픔 체크

### 배고픔 인터럽트
think()에서 스케줄보다 우선:
1. `_check_hunger()` → 포만감 30 이하이면 `_handle_eat` 활성화
2. `_handle_eat` phases: `idle → going_to_storage → taking_food → eating`
3. 인벤토리에 음식이 있으면 즉시 eating, 없으면 저장소로 이동

### NPC 요리 시스템
- `Stove.npc_cook(npc_id)` / `PortableStove.npc_cook(npc_id)`
- NPC 인벤토리의 재료로 `find_matching_recipe()` 호출
- 성공 시 재료 소비 → 결과물 NPC 인벤토리에 추가

### 보관소 동적 탐색 (`storage:{category}` prop)

NPC는 아이템을 보관할 때 `resolve_storage_container(agent, category)`로 거처 내 컨테이너를 동적 탐색합니다.
컨테이너에 `storage:{category}` prop이 있으면 해당 카테고리 아이템을 받을 수 있습니다.

| 컨테이너 | unique_id | 보관 카테고리 |
|----------|-----------|-------------|
| 주방 냉장고 | kitchen_fridge | food, food_ingredient, drink_ingredient |
| 은신처 식량함 | food_storage | food, food_ingredient, drink_ingredient |
| 재료 보관함 | ingredient_storage | material, seed, garden_supply |
| 도구함 | toolbox | tool, garden_tool |
| 옷장 | wardrobe | clothing |

탐색 범위: NPC의 `_get_home_region()` 내 오브젝트만 탐색.

### 자원 순환 파이프라인
```
채집/낚시 → NPC 인벤토리 → resolve_storage_container() → 보관소
                               ↓
                  요리 (재료 꺼내기 → 조리 → 결과물 저장)
                               ↓
                  식사 (음식 꺼내기 → 먹기 → 포만감 회복)
```
