# 분대 시스템 사용 가이드

> 플레이어 관점의 분대 운용 메뉴얼.
> 개발자용 설계 문서는 [party-design-notes.md](party-design-notes.md) 참조.

---

## 1. 개요

분대 시스템은 NPC를 모집하여 함께 행동하는 기능입니다.

- 분대를 편성하고, NPC를 모집하고, 지시를 내릴 수 있습니다
- 분대장을 지정하면 분대장 AI가 자율적으로 분대원을 지휘합니다
- 플레이어가 직접 리더인 분대에서는 분대원 개별 지시가 가능합니다

---

## 2. 기본 흐름

```
분대 편성 → NPC 모집 → (분대장 지정) → 지시/지휘 → (분대 해산)
```

### 2.1 분대 편성

**위치**: Situation Focus > 시간 보내기 아래 > `분대 편성`

플레이어 자신이 리더인 분대를 생성합니다.
이미 리더로 있는 분대가 있으면 추가 편성 불가.

### 2.2 NPC 모집

**위치**: Unit Focus (NPC 바라보기) > `분대 모집`

NPC를 분대에 편입합니다. 모집 시 NPC는 자동으로 "따라오기" 상태가 됩니다.

**모집 조건**:
- 반발 < 50 (필수, 초과 시 무조건 거절)
- 호감 >= 40 **또는** 복종 >= 50 (어느 하나 충족)

NPC별 오버라이드:

| NPC | 호감 조건 | 복종 조건 | 비고 |
|-----|----------|----------|------|
| 세라 | >= 50 | >= 50 | 기본보다 까다로움 |
| 유키 | >= 30 | >= 50 | 기본보다 쉬움 |
| 밀라 | >= 40 | >= 50 | 기본값 |
| 리나 | >= 40 | >= 50 | 기본값 |
| 엘라 | >= 60 | >= 40 | 호감 까다롭지만 복종 쉬움 |
| 페이 | >= 35 | >= 50 | 기본보다 약간 쉬움 |

**모집 불가 상황**:
- NPC가 이미 다른 분대에 소속
- 분대에 빈자리가 없음
- 데이트 중

### 2.3 분대장 지정

**위치**: Unit Focus (NPC 바라보기) > `분대장 지정`

리더가 없는 분대에 NPC를 리더로 지정합니다.
분대장은 자신의 성격에 따라 분대원에게 자율적으로 지시를 내립니다.

### 2.4 지시 내리기 (플레이어 리더 분대)

**위치**: Unit Focus (분대원 NPC 바라보기) > `지시`

플레이어가 직접 리더인 분대에서만 사용 가능.
분대원 개별로 지시를 내립니다.

| 지시 | 설명 |
|------|------|
| 따라오기 | 플레이어를 따라 이동 (기본) |
| 대기 | 현재 위치에서 대기 |
| 경계 | 현재 위치 주변 경계 |
| 수색 | 주변 수색 |
| 수집 | 자원 수집 |

### 2.5 지휘 변경 (NPC 리더 분대)

**위치**: Situation Focus > `지휘 변경`

NPC가 리더인 분대의 지휘 자세를 변경합니다.
분대장이 이 자세에 따라 분대원에게 지시를 내립니다.

| 지휘 자세 | 설명 |
|----------|------|
| 자동 | 분대장 판단에 맡김 (기본) |
| 수색 | 수색 중심 |
| 은밀 전투 | 은밀하게 전투 |
| 일반 전투 | 일반 전투 자세 |
| 공격적 전투 | 공격적으로 전투 |
| 후퇴 | 후퇴 |
| 대기 | 전원 대기 |

### 2.6 분대 해산

**위치**: Situation Focus > `분대 해산`

분대를 해산합니다. 모든 분대원이 원래 생활로 복귀합니다.
분대가 여러 개이면 해산할 분대를 선택합니다.

---

## 3. 액션 표시 조건

분대 관련 액션은 `can:` prop으로 동적 제어됩니다.
`party.py`가 분대 상태 변경 시 자동으로 prop을 갱신합니다.

| 액션 | prop | 활성 조건 |
|------|------|----------|
| 분대 편성 | `can:create_squad` | 항상 1 |
| 분대 해산 | `can:disband_squad` | 분대 존재 시 1 |
| 분대장 지정 | `can:assign_leader` | 리더 없는 분대 존재 시 1 |
| 지휘 변경 | `can:set_directive` | NPC 리더 분대 존재 시 1 |
| 분대 모집 | `can:recruit` | 빈자리 있는 분대 존재 시 1 |
| 지시 | `can:set_order` | 플레이어 리더 분대 존재 시 1 |

## 4. 분대원 행동

### 불복

분대원은 지시를 거부할 수 있습니다.

- **반발**이 높을수록 거부 확률 증가
- **복종**이 높을수록 거부 확률 감소
- 위험한 지시(전투 등)일수록 거부 확률 증가

불복 시 분대원은 5분간 "불복" 상태로 행동하지 않습니다.

### 따라오기 (follow)

분대원이 플레이어/분대장을 따라 이동합니다.
리더가 다른 장소로 이동하면 분대원도 따라갑니다.

### 전투 합류

같은 장소에서 전투가 발생하면 분대원이 자동으로 합류합니다.
(`combat_join_in_party` 설정에 따름)

---

## 5. 제약 사항

- 데이트 중인 NPC는 모집 불가
- 이미 다른 분대에 소속된 NPC는 중복 모집 불가
- 플레이어는 동시에 1개 리더 분대만 편성 가능
