# 연애 궤적 공간 분석

> 현 스탯 모델(확장 포함) 위에서 **A→B 관계가 그릴 수 있는 궤적**의 전수 분석.
> **A/B는 역할 대칭** — 플레이어/NPC 구분 없이 누구나 subject/object 될 수 있음.
> 목표: 구현 전 설계 공간 크기와 누락 경로 파악.

---

## 1. 궤적을 결정하는 축 (Axes)

### 1.1 시작 상태 축 (Initial State)

| 축 | 값 | 비고 |
|---|---|---|
| A→B 호감 | 호의 / 중립 / 반감 | 3단계 |
| A→B 애정 (상위) | 없음 / 있음 | 2단계 — Phase 2+ |
| A→B 복종 | 없음 / 약함 / 강함 | 3단계 |
| A 성욕 baseline | 낮음 / 보통 / 높음 | 3단계 |
| A 자제심 | 낮음 / 보통 / 높음 | 3단계 |
| A 수치심 | 낮음 / 보통 / 높음 | 3단계 |
| A 성별기호 | 이성애 / 양도 / 기피(이성·동성·인간) | 5단계 |
| A 경험 상태 | 순결 / 일부 경험 / 풍부 | 3단계 |
| A 핵심 성향 탤런트 | 정조/저항/즉각함락/도착/새드/마조/츤데레/순수/자기해방 등 | 다수 |
| A→B 기타 관계 | 친족/고용/적대/지인/타인 | 5단계 |

### 1.2 진행 변화 축 (Progression)

| 축 | 방향 | 계기 |
|---|---|---|
| 호감 | ↑↓ | 선물/데이트/배신/상처 |
| 복종 | ↑ | 굴복 경험/조교 |
| 반발 | ↑↓ | 강제/거부 누적 ↔ 쾌락/시간 |
| 쾌락 누적 | ↑ | 합의/강제 무관, 쾌락 경험 시 |
| 고통 누적 | ↑ | SM/강제/상처 |
| 수치심 | ↓ | 반복 노출/경험 |
| 자제심 | ↓ | 조교/약물/흥분 폭주 |
| 각인 (영구) | ↑ | 임계 도달 시 획득 |
| 애정 (상위) | ↑ | 호감 고단계 + 이벤트 |

### 1.3 종료 상태 축 (Endpoint)

| 축 | 값 |
|---|---|
| 관계 라벨 | 타인 / 지인 / 친구 / 연인 / 아내/남편 / 섹프 / 노예 / 적대 |
| 육체 각인 | 무 / 쾌락 / 고통 / 반발 / 굴복 / 시간 / 성장 (복수 가능) |
| 정신 상태 | 충족 / 굴복 / 붕괴 / 해방 / 저항 유지 |
| 자손 | 무 / 임신중 / 출산 / 복수 자녀 |
| 충성 (to A) | 강함 / 보통 / 약함 / 배신 |

## 2. 주요 궤적 아크타입 (16종)

### 2.1 합의·감정 중심

#### ① 순애 (Pure Love)
```
시작: 중립 / 자제심·수치심 高 / 처녀
경로: 호감 ↑ → 데이트 → 수치심 ↓ → 첫 키스 → 합의 스킨쉽 → 합의 성행위 → 임신 → 결혼/출산
게이트: 호감 경로만
종료: 연인·배우자, 쾌락각인(완만), 자녀
시그니처: 시간 투자 크고 감정 상승 곡선 부드러움
```

#### ② 츤데레 아크
```
시작: 반감 표면 + 호감 내심 (Talent 14 츤데레)
경로: 반발 표현 ↔ 내심 호감 ↑ → 순종 Lv 임계 돌파 → 급격 반전 → 순애 경로 합류
게이트: 인내 + 지속 접근
종료: ①과 유사하나 각성 시점이 극적
```

#### ③ 상호 완만 (Mutual Slow-Burn)
```
시작: 호의 낮음 양쪽
경로: 일상 접촉 / 일 협업 → 서로 호감 ↑ → 자연 스킨쉽 → 합의
게이트: 양방향 호감
종료: 연인·섹프 중간
시그니처: A·B 모두 능동, 장기 시뮬레이션형
```

### 2.2 욕정·충동 중심

#### ④ 육욕 함락 (Lust-Drive Fall)
```
시작: 약한 반감 / 자제심 낮음 or 쾌감응답 솔직
경로: 성욕 폭주 → 스킨쉽 허용 (성욕 경로) → 반발 + 쾌락 혼재 → 몸이 먼저 떨어짐 → 쾌락각인 → 서서히 마음도 함락 (굴복각인)
게이트: 성욕 경로 (호감 부족하지만 충동으로 통과)
종료: 섹프 중심, 사후 감정 정리 필요
시그니처: 유저 예시 ②번
```

#### ⑤ 관음·유혹 경로
```
시작: 어느 상태
경로: 관찰/노출 목격 → 성욕 급상승 → 유혹 (능동 or 수동) → 합의 or 강제 분기
게이트: 환경 자극 트리거
종료: 경로 분기 (①②④⑥ 등으로 흡수)
시그니처: 진입 장벽 낮음, 이후 다양
```

#### ⑥ 술·약물 (Intoxication)
```
시작: 어느 상태
경로: 술/약 투여 → 자제심 급감 → 즉흥적 스킨쉽 → 각성 후 반응 (수용/부정/수치)
게이트: 화학적 게이트 우회
종료: 각성 후 반응에 따라 분기 (관계 심화 or 파탄)
```

### 2.3 강제·함락 중심

#### ⑦ 강제 함락 (Forced Submission)
```
시작: 반감 / 저항 탤런트 / 자제심 高
경로: 강제 행위 → 고통각인 + 반발각인 → 저항 지속 → 약물/시간정지 등으로 강제 절정 → 쾌락각인 발생 → 반발 일부 감소 → 임신 → 출산
게이트: 강제 경로 (무 게이트)
종료: 복잡 분기 — 붕괴 / 함락 / 영구 반발
시그니처: 유저 예시 ③번
```

#### ⑧ 조교 길들이기 (Training)
```
시작: 어느 상태 (주로 복종 확보 후)
경로: 반복 SM·도구·조교 → 고통+쾌락 동시 누적 → 자존심 붕괴 → 굴복 각인 완성
게이트: 복종 경로 + SM 허용
종료: M형 노예 / 도착 파트너
시그니처: 장기 투자, 탤런트(마조/도착) 있으면 가속
```

#### ⑨ 정신 붕괴 (Mental Break)
```
시작: 어느 상태
경로: 반발각인 + 고통각인 + 굴복각인 극한 → Talent 28 붕괴
게이트: 지속 극한 스트레스
종료: 붕괴(인격 변질), 정상 대화 불가
시그니처: 극단적, 회귀 어려움
```

### 2.4 제3자 개입

#### ⑩ NTR 가해 (A가 C의 파트너 B를 뺏음)
```
관계자: A (가해자) · B (파트너) · C (원래 파트너)
경로: A가 B에게 접근 → B 충성(→C) vs 호감(→A) 갈등 → 비밀 관계 → C 질투 발현 → 발각 or 숨김 유지
게이트: B의 C에 대한 충성 약화 필요
종료: 삼각 해소 (B→A 전환 / B→C 회귀 / 양다리) / C 붕괴
시그니처: 감정적 복잡성, 질투·배신 각인
```

#### ⑪ NTR 피해 (A의 파트너 B가 C와)
```
관계자: A (피해자) · B (파트너) · C (침해자)
경로: B가 C에게 흔들림 → A의 질투 발현 → 발각 or 묵인 → A 정신 충격 / 성벽 발현 → 이후 분기 (A 폭주 / A 단념 / NTL 전환)
게이트: B의 A에 대한 충성 약화 (외부 요인 — C의 유혹, A의 소홀)
종료: A 붕괴 / 재구축 / 공유 전환
시그니처: 관찰자 역할 강함, 플레이어 피해 서사
```

#### ⑫ NTL·공유 (Voluntary Sharing)
```
관계자: A (관대자) · B (파트너) · C (제3자) 
경로: A 동의 → B와 C 관계 → A 관찰/참여 → 관계 심화 or 파탄
게이트: A의 명시적 동의 필요 + B·A 신뢰
종료: 안정 공유 / 질투 폭발 / 다자 관계
시그니처: ⑪과 시작은 비슷하나 동의 유무로 분기
```

### 2.5 대칭·특수 경로

#### ⑬ 플레이어 피해 역방향
```
관계자: P (플레이어) · N (NPC)
경로: N이 P에게 행위 시도 → P 저항/굴복 → P 스탯 갱신 (성욕/수치심/경험/처녀)
게이트: N의 P에 대한 지배력 + P 저항 탤런트
종료: P 노예 / 유지 / 반격
시그니처: 역할 대칭 — P가 대상이 됨
```

#### ⑭ 양방향 정복 (Mutual Capture)
```
관계자: A · B 동시 조교
경로: 서로 상대를 길들이려 시도 → 교호 주도권 → 각자 쾌락/굴복 누적
게이트: 양방 합의
종료: 동반 의존 / 한쪽 우세
```

#### ⑮ 동성 경로 (Same-sex Overlay)
```
전제: A 성별기호 = -1 양도 or 동성 대상 허용
경로: 기본 아크타입 위에 동성 행위 오버레이
게이트: 기본 아크타입 게이트 + 성별기호 조건
종료: 레즈/게이 경험·중독 각인 추가, 관계 라벨은 기본 아크타입 따름
시그니처: ①~⑫ 어느 경로에도 적용 가능
```

#### ⑯ 구원·재생 (Redemption)
```
시작: 붕괴/노예/깊은 반발 상태
경로: 애정/친절/치료 → 각인 약화 or 감정 복구 → 원래 성격 일부 회복
게이트: 치유자의 높은 호감 + 시간 투자
종료: 복합 — 완전 회복 드물고 흔적 남음
시그니처: 역순 진행, 실패 가능
```

### 2.6 배경·설정 특수 (Setting-Origin)
*일본 갤게/만화 정형 — 시작 조건이 서사적으로 사전 결정됨*

#### ⑰ 소꿉친구 (Childhood Friend)
```
시작: 호감 고·경험 없음·오랜 공유 기억 플래그
경로: 베이스 친밀 → 연애 전환 망설임 → 이벤트 트리거 → 고백/전환
게이트: "관계 재정의" 플래그 (경계 돌파)
종료: 순애 합류 or 영원한 친구 고정
시그니처: 출발점이 이미 높음, 허들은 "선 긋기"
참조: 거의 모든 일본 갤게
```

#### ⑱ 권력 격차 (Hierarchical)
```
시작: 상하 관계 (교사/학생, 주인/하인, 포로/간수, 상사/부하)
경로: 금기 의식 → 은밀 접근 → 발각 위험 동거 → 관계 공식화 or 파국
게이트: 지위 탤런트 (상하 플래그) + 금기 돌파 의지
종료: 탈출 결속 / 사회적 파멸 / 우발적 드러남
시그니처: 권력 비대칭이 에너지원, NTR과 친화
참조: 교사물/포로물/주종물
```

#### ⑲ 계약·중매 (Arranged / Contract Marriage)
```
시작: 외부 강제 (정치/경제/약속), 감정 무관
경로: 의무적 공존 → 마찰 → 점진 이해 → 감정 후발
게이트: 외부 고정 → 내부 감정 발생 여부가 분기
종료: 진짜 사랑 / 의무만 유지 / 파탄
시그니처: "처음엔 남, 나중에 연인", 역순 순애
참조: 인처계 / 시대극 / 이세계 왕가
```

#### ⑳ 거짓 연인 → 진짜 (Fake Dating → Real)
```
시작: 외부용 연기 동맹 (명분 필요)
경로: 연기 지속 → 상호 의존 → 한쪽의 진심 각성 → 고백 → 상호 전환
게이트: 연기 중 스킨쉽이 실제 감정 트리거
종료: 순애 합류 / 연기 만료 후 후회 / 이별
시그니처: 서브컬처 대표 트로프
참조: 가짜 커플 만화·갤게 다수
```

### 2.7 병리·집착 (Pathological)
*일본 심리 장르 — 감정이 건강한 방식이 아님*

#### ㉑ 얀데레 (Yandere)
```
시작: 편애·집착, 상대의 독점 욕구 (Talent: 집착 + 저항 음수)
경로: 이상적 애정 표현 → 제3자 배제 (질투 폭발) → 감금/협박/폭력 → 고립 관계
게이트: 상대를 독점할 수단 확보 (감금 가능성)
종료: 왜곡된 공존 / 발각 파탄 / 상대 각성 반격
시그니처: 애정 강도 = 파괴력, ⑦ 강제와 구분: 얀데레는 "사랑 때문에"
참조: 미친사랑하는 집착형 만화·게임
```

#### ㉒ 공의존 (Codependent)
```
시작: 양쪽 모두 결핍 (정신 약점 탤런트)
경로: 상호 구원자 역할 → 서로 없이 못 사는 상태 → 건강한 성장 차단
게이트: 양방 결핍 탤런트 매칭
종료: 영구 공의존 / 외부 충격으로 한쪽 독립 / 공동 붕괴
시그니처: "건강하지 않지만 절대 못 떠남"
참조: 공의존 관계를 다룬 청년 만화
```

#### ㉓ 트로피·복수 유혹 (Conquest / Vengeful Seduction)
```
시작: A 의도 — 정복/복수/증명
경로: 계산된 접근 → 상대 함락 → 목적 달성 시 관심 소멸 or 파괴
게이트: A의 감정 투자 없음, 기술만 사용
종료: 상대 상처·붕괴 / 역설적으로 A 감정 각성 / 발각 역풍
시그니처: "함락된 쪽만 사랑", 가학적 성벽
참조: 팜므파탈 / 여성 복수물 / 악역 영애
```

### 2.8 시뮬레이션 발생형 (Simulation-Emergent)
*스탯 시스템에서 자연 발생하는, 대본 없는 궤적*

#### ㉔ 변태 각성 (Fetish Awakening)
```
시작: 특정 성벽 탤런트 비활성 (마조/도착/노출 등 탤런트 값 0)
경로: 반복 경험 → 경험치 임계 → 관련 탤런트 자동 획득 → 기존 궤적이 전환
게이트: 경험 누적 + 쾌락 각인 발생
종료: 성향 영구 변화, 이후 행동 패턴 전환
시그니처: "만들어진 성벽", 정체성 변화
참조: 에로게 조교물 / 만화 "~에 눈뜨는 이야기"
```

#### ㉕ 체인 함락 (Chain Corruption)
```
시작: 이미 함락된 A
경로: A가 B에게 자신의 경험 전파 → B 호기심·유혹 → B 함락 → B가 C에게 → 연쇄
게이트: A의 적극적 유혹 의지 (타락 후 탤런트)
종료: 다수 NPC 도미노 함락, 공동체 변질
시그니처: 마을/집단 전체가 서서히 변질
참조: 마을 타락물 / 에로게 "~가 ~을 ~하게 만드는"
```

#### ㉖ 자연발생 삼각 (Emergent Triangle)
```
시작: 두 NPC (B·C)가 독립적으로 같은 A에 호감
경로: 각자 접근 → 우연 충돌 → 대립 or 협력 → 해소
게이트: 시뮬레이션 내 우연한 스탯 상승 동시 발생
종료: 승자 1인 / 공유 / 양쪽 포기 / 파탄
시그니처: 플레이어가 의도 안 했지만 NPC끼리 만든 상황
참조: 자율 NPC 시뮬의 특권
```

#### ㉗ 중재자 (Matchmaker / Saboteur)
```
시작: 플레이어/NPC가 다른 두 캐릭터 관계에 개입 의지
경로: 유도 이벤트 / 방해 이벤트 제공 → 타인 관계 가속·지연·파괴
게이트: 개입자의 두 대상에 대한 영향력
종료: 성공 (짝 맺음 공로) / 실패 (관계 파탄) / 폭로 역풍
시그니처: 플레이어가 자기 관계 아닌 타인 관계 manipulate
참조: 시녀/집사 캐릭터의 연애 성사 서브퀘 / 중매형 RPG
```

### 2.9 대안 결속 (Alternative Bond)
*성적/연애 표준 궤적이 아닌 대안적 관계 유지*

#### ㉘ 무성애 동반 (Platonic Life Partner)
```
시작: 호감 있으나 성욕 영구 낮음 (무관심/감정결여 탤런트)
경로: 깊은 감정 교류 → 생활 공유 → 성적 단계 영구 스킵
게이트: 성적 행위 의도 없음 (양방 동의)
종료: 가족 같은 동반 / 다른 파트너 + 감정 파트너 병행
시그니처: 관계 라벨은 "연인"이지만 경험 기록 0
참조: Q&A 애로매틱·에이섹슈얼 대중 서사
```

#### ㉙ 임신 수단 관계 (Instrumental Reproductive)
```
시작: 한쪽이 자식만 목적 (임신소망 Talent 9 또는 기타 동기)
경로: 거래적 접근 → 임신 달성 → 관계 종결 or 지속 분기
게이트: 임신 타이밍 맞추기
종료: 관계 종결 / 뜻밖의 감정 발생 / 아이 양육 협력
시그니처: 사랑 없이 자손만, 이후 드라마 분기점
참조: 씨받이 설정 / 이세계 혈통 요구물
```

### 2.10 판타지·특수 (Fantasy / Special)
*현실 초월 요소를 활용한 궤적 리셋/전환*

#### ㉚ 정신 조작 (Mind Control / Hypnosis)
```
시작: 마법/최면/약물 등 정신 조작 수단 확보
경로: 의식 조작 → 가짜 감정 주입 → 해제 시 진짜 감정 노출
게이트: 조작 도구 + 저항 탤런트 약화
종료: 조작 발각 → 배신감 폭발 / 해제 거부 (조작된 행복 유지) / 실제 감정 발생 후 융합
시그니처: 동의의 진위 문제, ⑥ 술·약물의 영구·의도 버전
참조: 최면물 / 사교 세뇌 서사
```

#### ㉛ 정체 숨김 (Hidden Identity)
```
시작: 한쪽이 진실 감춤 (정체/의도/과거/관계)
경로: 거짓 전제 하 관계 심화 → 진실 위협 → 발각 이벤트
게이트: 진실을 드러내는 조건 (시간/이벤트)
종료: 발각 후 수용 / 관계 파탄 / 복수 전환
시그니처: 리셋 이벤트 — 기존 궤적이 순간 재해석됨
참조: 요괴 신랑/신부 / 계급 숨긴 왕자 / 스파이 연인
```

## 6. 설계 함의

### 6.1 "역할 대칭"이 요구하는 것
플레이어/NPC 구분 없이 누구나 subject/object가 되려면:
- 플레이어에게 **NPC가 가진 모든 스탯 존재** 필요
- **AI 행동 루프**가 역방향에서도 작동 (N이 P를 대상으로 think)
- **게이트 공식**이 actor/target을 매개변수로 받아야

### 6.2 궤적 진행 기록
- 현재 morld는 "현재 상태"만 저장, 궤적 히스토리 없음
- 각인(Mark) 시스템이 도입되면 **"어느 궤적을 거쳤는지"가 영구 기록**됨
- 이 각인이 다음 행동/대사/이벤트 분기 조건

### 6.3 이벤트 훅 필요성
궤적이 자연 발생하려면 **수동 트리거가 아닌 능동 이벤트** 시스템 필요:
- 관찰 이벤트 (⑤)
- 질투 판정 (⑩⑪)
- 붕괴 임계 체크 (⑨)
- NPC 주도 충동 (④)

### 6.4 아크타입 → 대사·묘사 연결
각 궤적의 phase마다 아키타입별 대사/묘사 필요:
- ① 순애: 수줍음 → 감정고백 → 합의 → 행복
- ⑦ 강제: 저항 → 절규 → 굴복 → 붕괴 or 적응
- 현 dialogue-hybrid 엔진을 **궤적 단계 기반**으로 확장 필요
