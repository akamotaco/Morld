## 시나리오02 공유 시스템

시나리오03은 시나리오02의 기본 시스템을 활용한다:

| 시나리오02 시스템 | 시나리오03 활용 |
|-----------------|----------------|
| ECS 아키텍처 | 동일 |
| TextUI 시스템 | 동일 (CRT/CCTV 뷰 추가) |
| Dialog 시스템 | 동일 (원격 상담/취조에 활용) |
| Schedule/Agent AI | 확장 (분대원 자율 행동) |
| Time Flow | 적극 활용 (AutoTimeFlow) |

참고: `scenarios/scenario02/docs/`

## 시나리오02와의 차이점 요약

| 항목 | 시나리오02 | 시나리오03 |
|------|-----------|-----------|
| 플레이어 역할 | 직접 행동 캐릭터 | 원격 지휘 오퍼레이터 |

| 캐릭터 수 | 플레이어 1명 + NPC | 다수 분대원 관리 |
| 전투 | 직접 참여 | 지시만 가능 |
| 시간 | 액션 기반 | 자동 흐름 |
