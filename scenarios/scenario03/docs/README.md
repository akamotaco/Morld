## 시나리오02 공유 시스템

시나리오03은 시나리오02의 기본 시스템을 활용합니다:

| 시나리오02 시스템 | 시나리오03 활용 |
|-----------------|----------------|
| ECS 아키텍처 | 동일 |
| TextUI 시스템 | 동일 (CCTV 뷰 추가) |
| Dialog 시스템 | 동일 |
| Schedule/Agent AI | 확장 (더 복잡한 자율 행동) |
| Time Flow | 적극 활용 (AutoTimeFlow) |

| 시간 | 액션 기반 | 자동 흐름 |
