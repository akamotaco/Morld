# 요원 시스템 (Agent System)

## 개요

요원(Agent)은 플레이어가 지휘하는 캐릭터입니다. 플레이어는 직접 행동하지 않고, 요원들을 통해 미션을 수행합니다.

## 자율 행동 (Agent AI)

### 베이스캠프에서의 자율 행동

요원들은 베이스캠프에서 자율적으로 행동합니다:

- **기본 욕구 충족**: 식사, 수면, 휴식
- **훈련**: 스탯 향상 활동
- **사교**: 다른 요원과 교류
- **개인 활동**: 취미, 독서 등

시나리오02의 `schedule.md`, `life.md` 참고

### 미션 중 행동

미션 중에는 플레이어의 지시를 따르되, 긴급 상황에서는 자율 판단:

- **기본**: 플레이어 지시 대기
- **긴급**: 자율 판단 (회피, 응사 등)
- **위기**: 후퇴/구출 자동 시도

## 관계 시스템

### 요원 간 관계

| 관계 수준 | 효과 |
|----------|------|
| 적대 | 협동 효율 저하, 갈등 발생 |
| 냉담 | 기본 협동만 가능 |
| 동료 | 정상적인 협동 |
| 친밀 | 협동 보너스, 구출 의지 상승 |
| 깊은 유대 | 강력한 시너지, 상실 시 큰 트라우마 |

### 플레이어와의 관계

오퍼레이터에 대한 신뢰도:

- **신뢰도 높음**: 명령 즉시 수행, 위험 감수
- **신뢰도 보통**: 일반적인 명령 수행
- **신뢰도 낮음**: 명령 거부, 독자 행동

## 부상/사망/MIA

### 부상

- 전투 중 HP 감소 시 부상 상태
- 베이스캠프에서 치료 필요
- 심한 부상: 장기간 미션 불참

### 사망

- HP 0 도달 시 사망 가능성
- 사망 시 영구 손실
- 다른 요원들에게 트라우마 유발

### MIA (Missing In Action)

- 미션 중 연락 두절
- 생사 불명 상태
- 구출 미션으로 복귀 가능
