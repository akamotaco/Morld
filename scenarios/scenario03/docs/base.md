# 플랫폼 시스템 (Base Camp)

## 개요

**플랫폼**은 분대원이 탐사 외 시간에 생활하는 공간이다. 객관적으로는 암반층의 낡은 역사에 불과하지만, 분대원에게는 유일한 안식처이다. 플레이어는 **CRT 모니터/CCTV 스타일**로 분대원의 생활을 관찰한다.

### 구현 기반

플랫폼은 시나리오02의 시스템을 그대로 사용한다:

- **Location/Object**: 수동 정의 (시나리오02 패턴 동일, 탐사 지역만 동적 생성)
- **분대원 자율 행동**: `BaseAgent` + `schedule_mixin.py` (일과 패턴)
- **시설**: `facility_resolver.py` (prop 기반 동적 탐색)
- **환경**: `temperature/humidity/pollution/congestion.py` (등록만 하면 자동)
- **시간 흐름**: `advance_time_des()` + AutoTimeFlow

## 관찰 시스템

### CCTV 뷰

플레이어는 플랫폼 내 여러 위치를 관찰할 수 있다:

- **텍스트 기반** 상황 묘사
- **위치 전환:** 다른 구역으로 시점 이동
- **자동 갱신:** AutoTimeFlow로 실시간 변화 반영

### 관찰 가능 정보

| 정보 | 설명 |
|------|------|
| 위치 | 각 분대원의 현재 위치 |
| 행동 | 현재 수행 중인 행동 |
| 상태 | 건강, 피로, 기분 등 |
| 대화 | 분대원 간 대화 내용 (일부) |

### 기본 시설

| 구역 | 기능 |

탐사에서 가져온 자원으로 플랫폼을 업그레이드할 수 있다 ([mission.md](mission.md) 참조):

- 시설 레벨업으로 효과 증가
- 새로운 시설 건설
- 전력망 복구, 환기 시스템 개선

## 분대원 자율 행동

### 일과 패턴

분대원은 자율적으로 일과를 수행한다:

```
06:00 - 기상
07:00 - 아침 식사
08:00 - 훈련/자유 시간
12:00 - 점심 식사
13:00 - 훈련/자유 시간
18:00 - 저녁 식사
19:00 - 자유 시간/사교
22:00 - 취침 준비
23:00 - 취침
```

### 자유 시간 행동

- 훈련 (자발적)
- 독서
- 사교 (분대원 간 관계에 영향)
- 휴식
- 개인 취미

시나리오02의 `schedule.md`, `life.md` 시스템 활용.

## 플레이어 개입

### 직접 개입 불가

플레이어는 분대원 행동에 직접 개입할 수 없다. "식당으로 가라" 같은 명령 불가. **관찰자 역할**에 충실.

### 간접 개입 가능

| 방법 | 설명 |
|------|------|
| 상담실 호출 | 개별 분대원과 원격 대화 |
| 취조실 호출 | 의심 분대원 심문 |
| 시설 운영 | 시설 개방/폐쇄 |
| 일정 조정 | 탐사 스케줄 조절 |
| 공지 | 전체 공지 (사기 영향) |

## 이벤트 시스템

### 자동 이벤트

| 이벤트 | 조건 | 효과 |
|--------|------|------|
| 분대원 간 갈등 | 적대 관계 + 접촉 | 사기 저하 |
| 친밀 이벤트 | 친밀 관계 + 자유 시간 | 관계 강화 |
| 부상 악화 | 치료 미흡 | 상태 악화 |
| 훈련 성과 | 꾸준한 훈련 | 스탯 상승 |
| 기억 파편 회복 | Vita 성장 + 안정적 생활 | 자아 강화 |

### 플레이어 대응

- 이벤트 발생 시 알림 수신
- 필요시 상담실 호출로 개입
- 심각한 상황은 긴급 개입 가능

## 시간 흐름

### AutoTimeFlow 적용

- 플랫폼에서는 자동 시간 흐름
- 실시간 대비 게임 시간 배속 설정 가능
- 탐사 출발 등 중요 시점에서 일시 정지

### 시간 조작

| 조작 | 효과 |
|------|------|
| 가속 | 빠르게 시간 진행 |
| 일시정지 | 상황 파악, 판단 |
| 특정 시점 대기 | 탐사 출발 시간까지 대기 |
