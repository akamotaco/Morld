# 베이스캠프 시스템 (Base Camp)

## 개요

**베이스캠프**는 요원들이 미션 외 시간에 생활하는 공간입니다. 플레이어는 **CCTV 스타일**로 요원들의 생활을 관찰합니다.

---

## 관찰 시스템

### CCTV 뷰

플레이어는 베이스캠프 내 여러 위치를 관찰할 수 있습니다:

- **텍스트 기반** 상황 묘사
- **위치 전환**: 다른 구역으로 시점 이동
- **자동 갱신**: AutoTimeFlow로 실시간 변화 반영

### 관찰 가능 정보

| 정보 | 설명 |
|------|------|
| 위치 | 각 요원의 현재 위치 |
| 행동 | 현재 수행 중인 행동 |
| 상태 | 건강, 피로, 기분 등 |
| 대화 | 요원 간 대화 내용 (일부) |

## 요원 자율 행동

### 일과 패턴

요원들은 자율적으로 일과를 수행합니다:

```
06:00 - 기상
07:00 - 아침 식사
08:00 - 훈련/자유 시간
12:00 - 점심 식사
13:00 - 훈련/자유 시간
18:00 - 저녁 식사
19:00 - 자유 시간/사교
22:00 - 취침 준비
23:00 - 취침
```

### 자유 시간 행동

- 훈련 (자발적)
- 독서
- 사교
- 휴식
- 개인 취미

시나리오02의 `life.md`, `schedule.md` 시스템 활용

## 플레이어 개입

### 직접 개입 불가

- 플레이어는 요원 행동에 직접 개입 불가
- "식당으로 가라" 같은 명령 불가
- **관찰자 역할**에 충실

### 간접 개입 가능

| 방법 | 설명 |
|------|------|
| 상담실 호출 | 개별 요원과 대화 |
| 시설 운영 | 시설 개방/폐쇄 |
| 일정 조정 | 미션 스케줄 조절 |
| 공지 | 전체 공지 (사기 영향) |

---

## 이벤트 시스템

### 자동 이벤트

베이스캠프에서 자동으로 발생하는 이벤트:

| 이벤트 | 조건 | 효과 |
|--------|------|------|
| 요원 간 갈등 | 적대 관계 + 접촉 | 사기 저하 |
| 친밀 이벤트 | 친밀 관계 + 자유 시간 | 관계 강화 |
| 부상 악화 | 치료 미흡 | 상태 악화 |
| 훈련 성과 | 꾸준한 훈련 | 스탯 상승 |

### 플레이어 대응

- 이벤트 발생 시 **알림** 수신
- 필요시 **상담실 호출**로 개입
- 심각한 상황은 **긴급 개입** 가능

---

## 시간 흐름

### AutoTimeFlow 적용

- 베이스캠프에서는 자동 시간 흐름
- 실시간 대비 게임 시간 배속 설정 가능
- 미션 출발 등 중요 시점에서 일시 정지

### 시간 조작

| 조작 | 효과 |
|------|------|
| 가속 | 빠르게 시간 진행 |
| 일시정지 | 상황 파악, 판단 |
| 특정 시점 대기 | 미션 출발 시간까지 대기 |
