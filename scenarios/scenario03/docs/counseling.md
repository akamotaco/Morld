# 상담실 시스템 (Counseling Room)

## 개요

**상담실**은 플레이어(오퍼레이터)가 개별 분대원과 1:1로 대화할 수 있는 시설이다. 모든 상담은 **원격(CRT 모니터/통신)**으로 진행된다 — 플레이어는 관제실에서 모니터를 통해 분대원과 소통하며, 직접 대면하지 않는다. 직접적인 접촉은 DLC "강림"의 화신을 통해서만 가능하다.

### 구현 기반

상담실은 시나리오02의 Dialog 시스템을 그대로 사용한다. 취조실도 동일 구조.

- **대화**: `morld.dialog()` + proc 핸들러 (시나리오02 패턴 동일)
- **분대원 호출**: `Order` API로 상담실 Location 이동 지시
- **심리 효과**: `needs.py` 스트레스/사기 prop 변경
- **약물 모니터링**: `humanity` prop 변화 관찰

---

## 상담실 기능

### 분대원 호출

- 플레이어가 원하는 분대원을 상담실로 호출
- 분대원이 다른 활동 중이어도 호출 가능
- 긴급 상황 아니면 분대원은 응함

### 대화 시스템

상담실에서 분대원과 원격 대화:

- **상태 확인:** 건강, 정신 상태 파악
- **고민 상담:** 분대원의 고민 청취
- **조언/격려:** 사기 회복
- **정보 수집:** 분대원 간 관계, 플랫폼 분위기 파악
- **지시 전달:** 비공식적 지시

## 상담 효과

### 정신 건강 관리

| 상담 유형 | 효과 |
|----------|------|
| 일반 대화 | 소량 스트레스 해소 |
| 깊은 상담 | 중간 스트레스 해소 |
| 트라우마 상담 | 트라우마 회복 진행 |
| 격려 | 사기 상승 |

### 관계 형성

- **신뢰도 상승:** 대화를 통해 오퍼레이터 신뢰도 증가
- **정보 공유:** 친해지면 더 많은 정보 공유
- **개인 스토리:** 분대원의 기억 파편/배경 해금

---

## 심리 시스템

### 정신 상태 관리

탐사의 공포, 폐쇄 공간의 압박, 동료의 죽음은 분대원의 정신을 마모시킨다.

| 정신 상태 | 증상 |
|----------|------|
| 안정 | 정상 행동 |
| 불안 | 판단력 저하, 경계심 과잉 |
| 스트레스 | 갈등 유발, 명령 수행 지연 |
| 착란 | 환각, 동료 오인 |
| 정신분열 | 명령 불응, 자해/타해 위험 |

### 인간성 잔존율(H.I)과의 관계

약물 투여와 극한 경험은 인간성을 마모시킨다. 인간성이 낮아질수록:

- 감정 표현이 사라짐
- 동료와의 유대가 끊어짐
- 명령에는 충실하지만, '사람다운' 반응이 없어짐

상담실에서는 이 변화를 텍스트 로그의 어조 변화로 관찰한다.

---

## 약물 시스템 연동

상담실은 약물 투여 전후 분대원의 변화를 모니터링하는 역할도 한다.

| 약물 | 상담실에서 관찰되는 변화 |
|------|----------------------|
| 강화 약물 투여 후 | 대답이 짧아짐, 감정 표현 감소, 사무적 어조 |
| 진정 약물 투여 후 | 기억의 파편 언급 감소, 멍한 상태 |
| 임계 약물 투여 후 | 자아 거의 상실, 시리얼 번호로만 자신을 지칭 |

약물 시스템 상세는 [agent.md](agent.md) 약물 시스템 절 참조.

## 상담 대화

### 대화 구조

시나리오02의 Dialog 시스템 활용:

```python
# 예시
def counseling_echo07():
    yield morld.dialog("Echo-07이 상담실 모니터 앞에 앉는다.")

    state = {"topic": None}

    def handle(action):
        if action == "status":
            state["topic"] = "status"
            return True
        elif action == "concern":
            state["topic"] = "concern"
            return True

    text = """
    [상담실 - Echo-07]

    무엇을 이야기할까?

    [url=@proc:status]상태 확인[/url]
    [url=@proc:concern]고민 상담[/url]
    [url=@proc:encourage]격려하기[/url]
    [url=@proc:dismiss]돌려보내기[/url]
    """
    yield morld.dialog(text, autofill="off", proc=handle, result=state)

    if state["topic"] == "status":
        yield from ask_status()
```

### 대화 분기

분대원의 상태, 관계, 최근 이벤트에 따라 대화 내용 변화:

| 조건 | 대화 변화 |
|------|----------|
| 최근 탐사 실패 | 실패 관련 대화 옵션 |
| 동료 MIA/사망 | 위로 옵션 |
| 갈등 중 | 갈등 상대 언급 |
| 트라우마 | 트라우마 관련 대화 |
| 기억 파편 회복 | 과거 관련 단서 |
| 인간성 저하 | 감정적 반응 감소 |

## 상담 제한

### 시간 제한

- 상담 1회당 게임 시간 소모 (예: 30분)
- 하루 상담 횟수 제한 (선택적)

### 분대원 상태

- **탐사 중:** 상담 불가
- **수면 중:** 호출 시 피로 증가
- **부상 중:** 의무실에서 원격 상담

---

## 특수 상담

### 트라우마 치료

심각한 트라우마를 가진 분대원 치료:

- 여러 차례 상담 필요
- 점진적 회복
- 완전 회복 또는 적응

### 갈등 중재

갈등 중인 분대원 중재:

- 각 분대원과 개별 상담
- 상황 파악 → 중재안 제시
- 성공 시 관계 개선

### 개인 스토리

분대원과의 신뢰도가 높아지면:

- 기억 파편을 통한 과거 단서 해금
- 시리얼 번호 이전의 흔적 발견
- Vita 트랙 성장과 연동
