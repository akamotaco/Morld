# 상담실 시스템 (Counseling Room)

## 개요

**상담실**은 플레이어(오퍼레이터)가 개별 요원과 1:1로 대화할 수 있는 유일한 공간입니다. 베이스캠프에서 플레이어가 직접 개입할 수 있는 주요 수단입니다.

---

## 상담실 기능

### 요원 호출

- 플레이어가 원하는 요원을 상담실로 호출
- 요원이 다른 활동 중이어도 호출 가능
- 긴급 상황 아니면 요원은 응함

### 대화 시스템

상담실에서 요원과 대화:

- **상태 확인**: 건강, 정신 상태 파악
- **고민 상담**: 요원의 고민 청취
- **조언/격려**: 사기 회복
- **정보 수집**: 요원 간 관계, 베이스 분위기 파악
- **지시 전달**: 비공식적 지시

---

## 상담 효과

### 정신 건강 관리

| 상담 유형 | 효과 |
|----------|------|
| 일반 대화 | 소량 스트레스 해소 |
| 깊은 상담 | 중간 스트레스 해소 |
| 트라우마 상담 | 트라우마 회복 진행 |
| 격려 | 사기 상승 |

### 관계 형성

- **신뢰도 상승**: 대화를 통해 오퍼레이터 신뢰도 증가
- **정보 공유**: 친해지면 더 많은 정보 공유
- **개인 스토리**: 요원의 배경 스토리 해금

## 상담 대화

### 대화 구조

시나리오02의 Dialog 시스템 활용:

```python
# 예시
def counseling_sera():
    yield morld.dialog("세라가 상담실에 들어온다.")

    state = {"topic": None}

    def handle(action):
        if action == "status":
            state["topic"] = "status"
            return True
        elif action == "concern":
            state["topic"] = "concern"
            return True
        # ...

    text = """
    [상담실 - 세라]

    무엇을 이야기할까?

    [url=@proc:status]상태 확인[/url]
    [url=@proc:concern]고민 상담[/url]
    [url=@proc:encourage]격려하기[/url]
    [url=@proc:dismiss]돌려보내기[/url]
    """
    yield morld.dialog(text, autofill="off", proc=handle, result=state)

    if state["topic"] == "status":
        yield from ask_status()
    # ...
```

### 대화 분기

요원의 상태, 관계, 최근 이벤트에 따라 대화 내용 변화:

| 조건 | 대화 변화 |
|------|----------|
| 최근 미션 실패 | 실패 관련 대화 옵션 |
| 동료 MIA/사망 | 위로 옵션 |
| 갈등 중 | 갈등 상대 언급 |
| 트라우마 | 트라우마 관련 대화 |

## 상담 제한

### 시간 제한

- 상담 1회당 게임 시간 소모 (예: 30분)
- 하루 상담 횟수 제한 (선택적)

### 요원 상태

- **미션 중**: 상담 불가
- **수면 중**: 호출 시 피로 증가
- **부상 중**: 의무실에서 상담

---

## 특수 상담

### 트라우마 치료

심각한 트라우마를 가진 요원 치료:

- 여러 차례 상담 필요
- 점진적 회복
- 완전 회복 또는 적응

### 갈등 중재

갈등 중인 요원들 중재:

- 각 요원과 개별 상담
- 상황 파악
- 중재안 제시
- 성공 시 관계 개선

### 개인 스토리

요원과의 친밀도가 높아지면:

- 개인 배경 스토리 해금
- 과거 트라우마 원인 파악
- 특별 이벤트 발생

## UI 설계

### 상담실 화면

```
[상담실]

현재 시각: 14:30

호출할 요원을 선택하세요:

[url=@proc:sera]세라[/url] - 휴게실에서 독서 중
[url=@proc:john]존[/url] - 훈련장에서 훈련 중
[url=@proc:mia]미아[/url] - 숙소에서 휴식 중 (피로)
[color=gray]알렉스 - 미션 중 (호출 불가)[/color]

[url=@proc:cancel]나가기[/url]
```
