# Mind The Gap - 시나리오 설계

## 개요

**Mind The Gap**은 플레이어가 오퍼레이터(Operator)로서 요원(Agent)들을 원격으로 지휘하는 택티컬 시뮬레이션 게임입니다.

- **장르**: 택티컬 시뮬레이션 + 생활 관리
- **핵심 컨셉**: 직접 전투하지 않고 요원들을 관리/지휘
- **게임 구조**: 일상 파트(Daily Part) + 미션 파트(Mission Part)

### 조직 (Organization)

- 조직은 플레이어와 요원들을 지원하는 입장
- 자원, 장비, 정보 등을 제공

## 플레이어 역할

### 오퍼레이터 (Operator)

플레이어는 **오퍼레이터**로서:
- 요원들에게 직접 지시를 내림
- 베이스캠프에서 요원들의 생활을 관찰
- 미션 중 전술적 판단 및 명령
- 요원들의 정신 건강 관리 (상담실)

### 직접 개입 범위

| 상황 | 개입 가능 여부 |
|------|---------------|
| 미션 중 전술 지시 | O |
| 일상 중 요원 호출 | O (상담실) |
| 요원 간 갈등 중재 | O (간접적) |
| 물리적 전투 참여 | X |

## 게임 구조

### 일상 파트 (Daily Part)

베이스캠프에서 요원들의 일상을 관찰하고 관리합니다.

- **CCTV 스타일** 관찰 시스템
- 요원들은 **자율적으로** 생활 (schedule/agent AI 기반)
- 플레이어는 직접 개입하지 않고 관찰
- **상담실**을 통해 개별 요원과 대화 가능

자세한 내용: [base.md](base.md)

### 미션 파트 (Mission Part)

요원들을 미션에 파견하여 목표를 달성합니다.

- **분대 단위** 파견 (4인 1조)
- **자동 시간 흐름** (AutoTimeFlow) 적용
- 실시간으로 상황 보고를 받으며 지시
- 전술적 판단이 결과에 영향

자세한 내용: [mission.md](mission.md)

## 시나리오02와의 차이점

| 항목 | 시나리오02 | 시나리오03 |
|------|-----------|-----------|
| 플레이어 역할 | 직접 행동하는 캐릭터 | 원격 지휘하는 오퍼레이터 |
| 시점 | 1인칭 (플레이어 시점) | 3인칭 (관찰자 시점) |
| 전투 | 플레이어가 직접 전투 | 요원들이 전투, 플레이어는 지시 |
| NPC AI | 플레이어 중심 | 요원 중심 (더 복잡한 자율 행동) |
| 시간 흐름 | 플레이어 액션 기반 | 자동 시간 흐름 적극 활용 |
