# MIA 시스템 (Missing In Action)

## 개요

**MIA(Missing In Action)**는 탐사 중 연락이 두절된 분대원 상태이다. 생사를 알 수 없으며, 구출 미션을 통해 복귀시킬 수 있다.

### 구현 기반

MIA는 기존 시스템의 확장으로 구현한다:

- **상태 관리**: `mia_status` prop (None/mia/rescued/kia) — `survival.py` 패턴
- **구출 미션**: 탐사 시스템의 변형 — 동적 맵 생성 + 시간 제한 ([mapgen.md](mapgen.md))
- **분대원 영향**: `needs.py` 스트레스/사기 확장
- **충원**: 새 시리얼 번호 에이전트 생성 + 전임자 장비/prop 계승

---

## MIA 발생 조건

### 발생 상황

| 상황 | MIA 확률 | 설명 |
|------|---------|------|
| 분대 전멸 | 높음 | 통신 두절, 상황 불명 |
| 낙오 | 중간 | 분대에서 이탈 |
| 포로 | 중간 | 적에게 포획 |
| 고립 | 낮음 | 퇴로 차단 |

### 확률 영향 요소

- **분대원 스탯:** Vita(생존력), Sapientia(판단력)
- **탐사 난이도:** 높을수록 MIA 확률 증가
- **상황:** 철수 실패 > 전투 패배 > 고립
- **동조율:** 높은 친밀도의 동료가 구출 시도 → 추가 MIA 위험

## MIA 상태

### 상태 정보

| 정보 | 확인 가능 |
|------|----------|
| 생존 여부 | 불명 |
| 위치 | 대략적 (탐사 지역) |
| 상태 | 불명 |
| 포로 여부 | 불명 (정찰로 파악 가능) |

### 시간 제한

- MIA 발생 후 일정 기간 내 구출 필요
- 기간 초과 시:
  - 사망 확정 (높은 확률)
  - 자력 귀환 (낮은 확률)
  - 영구 MIA (적 포로)

---

## 구출 미션

### 구출 미션 발동

- MIA 발생 시 구출 미션 옵션 제공
- 즉시 출발 또는 준비 후 출발
- 다른 탐사와 병행 불가 (선택적)

### 구출 미션 특성

| 특성 | 설명 |
|------|------|
| 난이도 | 원래 탐사 + 추가 난이도 |
| 시간 압박 | 시간 제한 있음 |
| 정보 부족 | 정찰 없이 진입 |
| 목표 | MIA 분대원 확보 및 귀환 |

### 구출 결과

| 결과 | 설명 |
|------|------|
| 성공 - 생존 | 분대원 복귀, 부상/트라우마 가능 |
| 성공 - 시신 회수 | 사망 확정, 장례 가능 |
| 실패 | 추가 MIA 발생 가능 |
| 정보 획득 | 분대원 상태/위치 파악 |

## 귀환의 불확실성

### 자력 귀환

MIA 분대원이 스스로 귀환하는 경우:

- 높은 Vita 스탯
- 포로가 아닌 경우
- 운 요소

**그러나 돌아온 그가 '진짜' 그 사람인지는 불확실하다.** MIA 귀환자는 행동 변화, 기억의 불일치, 설명할 수 없는 상처 등을 보일 수 있다. 취조실에 보낼 것인지, 신뢰할 것인지는 플레이어의 판단에 달려 있다.

### 귀환 상태

| 상태 | 확률 | 설명 |
|------|------|------|
| 경상 | 낮음 | 빠른 복귀 가능 |
| 중상 | 중간 | 장기 치료 필요 |
| 심각한 트라우마 | 높음 | 정신 치료 필요 |

---

## 유해 발견

탐사 중 이전 분대원의 시체나 유품을 발견하는 이벤트.

- **시신 확인:** MIA 분대원의 사망 확정. 장례/추모 이벤트로 다른 분대원 스트레스 해소
- **유품 발견:** 이전 시리얼 번호의 장비, 메모, 흔적. 숙소 벽에 긁어 남긴 낙서 등
- **현 시리얼에게 전달:** 같은 모델의 현재 시리얼에게 전임자의 유품을 보여줄 수 있음 → 강한 심리적 영향

---

## MIA의 영향

### 다른 분대원에게

| 관계 | 영향 |
|------|------|
| 친밀 | 높은 스트레스, 구출 의지, 후퇴 명령 무시 가능 |
| 동료 | 중간 스트레스 |
| 냉담 | 낮은 영향 |

### 분대/플랫폼에게

- **사기 저하:** 전체 사기 감소
- **불안감:** 탐사 기피 경향
- **단결:** 구출 성공 시 사기 상승

---

## 사망 확정과 충원

### 확정 조건

- 시간 제한 초과
- 시신 확인
- 사망 정보 입수

### 사망 처리

- **장례/추모:** 다른 분대원 스트레스 해소
- **유품 정리:** 특수 이벤트
- **결번 처리:** 해당 시리얼 번호 폐기

### 빈자리 충원

동일 모델의 다음 시리얼 번호가 보급된다. 같은 얼굴의 새로운 분대원이 이전 개체의 장비, 혈흔, 심지어 파편화된 트라우마를 계승하며 등장한다.

---

## 포로 상태

### 적 포로

MIA 분대원이 적에게 포획된 경우:

- **정보 유출 위험:** 플랫폼 정보 노출 가능
- **구출 난이도 상승:** 경비 강화
- **협상 가능:** 자원 교환 (선택적)
