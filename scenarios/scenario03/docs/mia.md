# MIA 시스템 (Missing In Action)

## 개요

**MIA(Missing In Action)**는 미션 중 연락이 두절된 요원 상태입니다. 생사를 알 수 없으며, 구출 미션을 통해 복귀시킬 수 있습니다.

---

## MIA 발생 조건

### 발생 상황

| 상황 | MIA 확률 | 설명 |
|------|---------|------|
| 분대 전멸 | 높음 | 통신 두절, 상황 불명 |
| 낙오 | 중간 | 분대에서 이탈 |
| 포로 | 중간 | 적에게 포획 |
| 고립 | 낮음 | 퇴로 차단 |

### 확률 영향 요소

- **요원 스탯**: 생존력, 은신 등
- **미션 난이도**: 높을수록 MIA 확률 증가
- **상황**: 철수 실패 > 전투 패배 > 고립

## 구출 미션

### 구출 미션 발동

- MIA 발생 시 구출 미션 옵션 제공
- 즉시 출발 또는 준비 후 출발
- 다른 미션과 병행 불가 (선택적)

### 구출 미션 특성

| 특성 | 설명 |
|------|------|
| 난이도 | 원래 미션 + 추가 난이도 |
| 시간 압박 | 시간 제한 있음 |
| 정보 부족 | 정찰 없이 진입 |
| 목표 | MIA 요원 확보 및 귀환 |

### 구출 결과

| 결과 | 설명 |
|------|------|
| 성공 - 생존 | 요원 복귀, 부상/트라우마 가능 |
| 성공 - 시신 회수 | 사망 확정, 장례 가능 |
| 실패 | 추가 MIA 발생 가능 |
| 정보 획득 | 요원 상태/위치 파악 |

## MIA의 영향

### 다른 요원에게

| 관계 | 영향 |
|------|------|
| 친밀 | 높은 스트레스, 구출 의지 |
| 동료 | 중간 스트레스 |
| 냉담 | 낮은 영향 |

### 분대/조직에게

- **사기 저하**: 전체 사기 감소
- **불안감**: 미션 기피 경향
- **단결**: 구출 성공 시 사기 상승

---

## 자력 귀환

### 발생 조건

MIA 요원이 스스로 귀환하는 경우:

- 높은 생존력 스탯
- 포로가 아닌 경우
- 운 요소

### 귀환 상태

| 상태 | 확률 | 설명 |
|------|------|------|
| 경상 | 낮음 | 빠른 복귀 가능 |
| 중상 | 중간 | 장기 치료 필요 |
| 심각한 트라우마 | 높음 | 정신 치료 필요 |

---

## 사망 확정

### 확정 조건

- 시간 제한 초과
- 시신 확인
- 사망 정보 입수

### 사망 처리

- **장례/추모**: 다른 요원 스트레스 해소
- **유품 정리**: 특수 이벤트
- **빈 자리**: 신규 요원 모집

## UI 설계

### MIA 알림

```
[긴급 보고]

알파 분대 통신 두절!
마지막 위치: B구역

MIA 요원:
- 세라 (생사 불명)

[url=@proc:rescue]즉시 구출 미션[/url]
[url=@proc:prepare]준비 후 출발[/url]
[url=@proc:wait]대기 (정보 수집)[/url]
```

### MIA 현황

```
[MIA 현황]

세라 - MIA 2일차
  마지막 위치: B구역
  예상 생존 확률: 70%
  남은 시간: 5일

[url=@proc:rescue_sera]구출 미션[/url]
[url=@proc:recon]정찰 미션[/url]
```
