# 미션 시스템 (Mission System)

## 개요

**미션**은 요원들이 베이스캠프 밖에서 수행하는 작전입니다. 플레이어는 오퍼레이터로서 원격으로 지휘합니다.

---

## 미션 흐름

### 1. 미션 수주

- 상부 조직에서 미션 제공
- 미션 정보 확인 (목표, 위험도, 보상)
- 수락/거절 선택

### 2. 브리핑

- 작전실에서 미션 브리핑
- 분대 편성
- 장비 배분
- 전술 계획 수립

### 3. 출발

- 분대 파견
- 이동 시간 (자동 진행)

### 4. 미션 수행

- 실시간 상황 보고 수신
- 전술 지시 하달
- 돌발 상황 대응

### 5. 귀환/보고

- 미션 완료 후 귀환
- 결과 보고
- 보상 획득

## 미션 진행

### 자동 시간 흐름

- 미션 중 **AutoTimeFlow** 적용
- 실시간 대비 게임 시간 배속
- 중요 분기점에서 일시 정지

### 상황 보고

분대로부터 주기적으로 상황 보고 수신:

```
[보고] 알파 분대
현재 위치: B구역 진입
상태: 이상 없음
발견 적: 경비 2명
대기 중...
```

### 지시 유형

| 지시 | 설명 |
|------|------|
| 전진 | 다음 구역으로 이동 |
| 대기 | 현재 위치에서 대기 |
| 교전 | 적과 전투 |
| 회피 | 은신하여 우회 |
| 철수 | 미션 포기, 귀환 |

## 전술 요소

### 접근 방식

| 방식 | 장점 | 단점 |
|------|------|------|
| 정면 돌파 | 빠름 | 피해 큼 |
| 잠입 | 피해 적음 | 느림, 탐지 위험 |
| 양동 | 적 분산 | 분대 분리 위험 |

### 환경 요소

- **시간대**: 주간/야간 (탐지율 영향)
- **날씨**: 시야, 이동 속도 영향
- **지형**: 엄폐물, 진입로

---

## 미션 결과

### 성공 조건

미션별로 다름:
- 목표 달성
- 시간 내 완료
- 분대 생존

### 실패 조건

- 분대 전멸
- 목표 달성 불가
- 시간 초과
- 철수

### 보상/손실

| 결과 | 보상 | 손실 |
|------|------|------|
| 완전 성공 | 최대 보상 | 없음 |
| 부분 성공 | 일부 보상 | 일부 손실 |
| 실패 | 없음 | 자원 손실, MIA 가능 |

---

## 돌발 상황

### 예상치 못한 상황

| 상황 | 발생 조건 | 대응 |
|------|----------|------|
| 증원 출현 | 경보 발령 | 전투/철수 |
| 함정 | 정찰 부족 | 피해 감수/해제 |
| 통신 두절 | 전파 방해 | 분대장 자율 판단 |
| 부상자 발생 | 전투 중 | 치료/후송 |
| 민간인 발견 | 잠입 중 | 제압/회피/무시 |

### 플레이어 판단

돌발 상황 시 선택지 제공:

```
[긴급 상황] 알파 분대
적 증원 3명 접근 중!

1. 교전 - 적 제거 후 진행
2. 은신 - 지나가길 기다림
3. 우회 - 다른 경로 탐색
4. 철수 - 미션 포기
```
