# 탐사/미션 시스템 (Mission System)

## 개요

**탐사**는 분대원이 플랫폼 밖에서 수행하는 작전이다. 배급만으로는 살아갈 수 없으므로, 플레이어는 분대를 지저철 선로 너머의 미지 영역으로 내보내 자원을 확보해야 한다. 플레이어는 오퍼레이터로서 원격으로 지휘한다.

---

## 탐사 흐름

### 1. 탐사 준비

- 상부에서 탐사 목표/지역 정보 제공
- 분대 편성 + 장비 배분
- 대열 순번(Rank) 지정 ([squad.md](squad.md) 참조)

### 2. 출발

- 분대가 플랫폼의 열차에 탑승하여 미지의 지역으로 이동
- 이동 시간 (자동 진행)

### 3. 탐사 수행

- 실시간 텍스트 로그 + 오디오 통신으로 상황 수신
- 전술 지시 하달
- 돌발 상황 대응

### 4. 귀환/보고

- 탐사 완료 후 귀환
- 결과 보고 + 자원 획득

---

## 탐사 지역

### 1D 공간 구조

각 방(Room)은 **1차원 공간(X축)**으로 구성된다. 방 안에는 탐사를 위한 오브젝트가 존재할 수도 있고, 빈 공간일 수도 있다.

- **전투:** 반 필수적이며, 운 좋게 적이 없는 공간도 존재
- **장애물:** 함정, 잠긴 문, 해킹/폭발로 돌파해야 하는 장벽
- **환경 위협:** 포자 안개, 독성 가스, 진드기 군집 등

전투 시스템 상세는 [combat.md](combat.md) 참조.

### 환경 요소

| 요소 | 영향 |
|------|------|
| 조명 | 탐지율, CRT 영상 품질 |
| 기압/수압 | 심층일수록 장비 부담 |
| 오염도 | 방독면 필터 소모, 건강 피해 |
| 구조물 상태 | 붕괴 위험, 통로 차단 |

## 오퍼레이터 지시

### 지시 유형

| 지시 | 설명 |
|------|------|
| 전진 | 다음 구역으로 이동 |
| 대기 | 현재 위치에서 대기 |
| 교전 | 적과 전투 개시 |
| 은신 | 은신하여 우회 |
| 철수 | 탐사 포기, 귀환 |

### 돌발 상황

| 상황 | 발생 조건 | 대응 |
|------|----------|------|
| 증원 출현 | 경보 발령 | 전투/철수 |
| 함정 | 정찰 부족 | 피해 감수/해제 |
| 통신 두절 | 전파 방해 | 분대장 자율 판단 |
| 부상자 발생 | 전투 중 | 치료/후송/포기 |

플레이어는 직접 조준하거나 이동하지 않는다. 간접 개입 수단(공세 레벨, 해킹, 약물, 좌표)으로만 개입한다 ([combat.md](combat.md) 참조).

## 플랫폼 확장

탐사에서 가져온 자원으로 플랫폼을 업그레이드할 수 있다.

| 시설 | 효과 |
|------|------|
| 침실 | 더 많은 분대원 수용 |
| 여가 공간 | 분대원 정신 안정, 휴식 |
| 상담소 | 분대원 정신 관리 핵심 시설 ([counseling.md](counseling.md)) |
| 시설 개선 | 낡은 공간 보수, 전력망 복구, 환기 개선 |

플랫폼은 객관적으로는 암반층의 낡은 역사에 불과하지만, 분대원에게는 유일한 안식처이다.

## 탐사 결과

### 성공/실패

| 결과 | 보상 | 손실 |
|------|------|------|
| 완전 성공 | 최대 보상 | 없음 |
| 부분 성공 | 일부 보상 | 일부 손실 |
| 실패 | 없음 | 자원 손실, MIA 가능 |

### MIA / KIA

탐사의 위험성으로 인해 행방불명(MIA)과 전사(KIA) 상황이 빈번하게 발생한다. 상세는 [mia.md](mia.md) 참조.
