# 분대 시스템 (Squad System)

## 개요

미션은 **분대(Squad)** 단위로 수행합니다. 한 분대는 **4명**의 요원으로 구성됩니다.

---

## 분대 구성

### 기본 규칙

- **분대 인원**: 4명 (고정)
- **역할 분배**: 자유 (권장 구성 있음)
- **리더 지정**: 분대장 1명 필수

### 권장 구성 (예시)

| 구성 | 역할 배분 | 적합한 미션 |
|------|----------|------------|
| 균형형 | 돌격1 + 정찰1 + 지원1 + 저격1 | 범용 |
| 돌격형 | 돌격2 + 지원1 + 저격1 | 전투 중심 |
| 잠입형 | 정찰2 + 지원1 + 해커1 | 잠입 미션 |
| 정찰형 | 정찰3 + 지원1 | 정보 수집 |

---

## 분대장 (Squad Leader)

### 역할

- 분대원 통솔
- 현장 판단 (오퍼레이터 통신 두절 시)
- 사기 유지

### 분대장 스탯

| 스탯 | 효과 |
|------|------|
| 리더십 | 분대원 사기 유지 |
| 판단력 | 자율 행동 시 결정 품질 |
| 카리스마 | 명령 수행률 |

## 분대 운영

### 분대 편성

- 미션 전 분대 구성
- 요원 상태 확인 (부상, 피로 등)
- 장비 배분

### 분대 교대

- 연속 미션 시 피로 누적
- 분대 단위 휴식 필요
- 최소 2개 분대 권장

---

## 통신 시스템

### 오퍼레이터 ↔ 분대

- 실시간 음성 통신 (가정)
- 상황 보고 수신
- 명령 하달

### 통신 두절 상황

- 전파 방해, 지하 구역 등
- 분대장 자율 판단으로 전환
- 일정 시간 후 자동 복귀/철수
