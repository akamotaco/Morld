# S04 확장 시스템 설계

> 상태: 설계 단계 (미구현)

기존 시스템 (침식/신뢰/사기/파티) 위에 얹는 확장 시스템.
핵심 테마: **"이 사람과 던전 깊은 곳에서 등을 맡길 수 있는가?"**

---

## 1. 자물쇠 따기 (Lockpicking)

### 개요

던전 내 잠긴 보물상자, 잠긴 문, 감옥 등에 적용.
성공/실패에 따라 보상/위험이 갈린다.

### 스킬 수치

```
lockpick_score = base_agi × class_modifier + tool_bonus + (침식 보정)
```

| 요소 | 설명 |
|------|------|
| base_agi | 민첩 스탯 (기본) |
| class_modifier | 직업 보정 (도적 ×1.5, 척후 ×1.2, 기타 ×0.5) |
| tool_bonus | 자물쇠 도구 품질 (조잡 +2, 보통 +5, 정밀 +10) |
| 침식 보정 | 침식 100 이상 → 손 떨림 → -5 |

### 자물쇠 난이도

| 등급 | 필요 점수 | 예시 |
|------|----------|------|
| 간단 (Simple) | 10 | 나무 상자, 허름한 문 |
| 보통 (Normal) | 20 | 철제 상자, 일반 문 |
| 복잡 (Complex) | 35 | 보물 상자, 감옥 문 |
| 마법 (Magic) | 50+ | 봉인된 문, 저주된 상자 |

### 판정

```
roll = random(0, lockpick_score)
if roll >= difficulty:
    성공 → 열림
elif roll >= difficulty × 0.5:
    실패 → 도구 파손 (50% 확률)
else:
    치명적 실패 → 소음 발생 (은신 판정) + 도구 파손 + 함정 발동 가능
```

### 관련 직업

| 직업 | lockpick 보정 | 부가 능력 |
|------|-------------|----------|
| 도적 (Thief) | ×1.5 | 함정 해제, 소매치기 |
| 척후 (Scout) | ×1.2 | 은신 파티 보정 (기존), 함정 탐지 |
| 암살자 (Assassin) | ×1.0 | 은신 단독 강화, 급소 공격 |
| 탐험가 (Explorer) | ×1.0 | 지도 자동 작성, 함정 탐지 |
| 기타 | ×0.5 | - |

### 기존 시스템 연동

- **은신**: 자물쇠 실패 → 소음 → `stealth.detection_check()` 발동
- **도구**: 인벤토리 아이템 (`lockpick_tool` category)
- **침식**: 높은 침식 → 손 떨림 패널티
- **도덕성**: 타인 소유물 해제 시 도덕성 하락

## 2. 명성 (Fame) & 도덕성 (Morality)

### 명성 (Fame) — 외적 평판

"세상이 나를 어떻게 보는가"

| 범위 | 등급 | 설명 |
|------|------|------|
| 0~10 | 무명 | 아무도 모름 |
| 11~30 | 떠돌이 | 여관 주인이 아는 정도 |
| 31~50 | 모험가 | 마을 주민이 인지 |
| 51~70 | 유명인 | 다른 마을까지 소문 |
| 71~90 | 영웅/악명 | 전설적 존재 |
| 91~100 | 전설 | 역사에 남을 인물 |

**변동 요인:**
- 던전 층 클리어: +5~15
- 퀘스트 완수: +3~10
- 마을 공공사업: +2~5
- 공개적 범죄: +5 (악명으로)
- 장기간 비활동: -1/주 (서서히 잊힘)

**영향:**
- NPC 초기 반응 (호의적/경계)
- 상점 가격 보정 (유명 → 할인 또는 바가지)
- 파티 모집 난이도 (유명 → 지원자 증가)
- 특정 퀘스트/이벤트 해금
- 매춘 가격 변동

### 도덕성 (Morality) — 내면의 양심

"나는 어떤 사람인가"

| 범위 | 등급 | 행동 특성 |
|------|------|----------|
| +70~+100 | 성인 (Saint) | 자기희생 가능, 악행 불가, 주변 NPC 신뢰 |
| +30~+69 | 선인 (Good) | 대부분의 선행 가능, 범죄 거부 |
| +10~+29 | 보통 (Neutral+) | 상황에 따라 유연, 소규모 범죄 가능 |
| -9~+9 | 회색 (Gray) | 제약 거의 없음, 기회주의적 |
| -29~-10 | 악인 (Evil) | 폭력/약탈 자연스러움, 선행에 거부감 |
| -69~-30 | 극악 (Wicked) | 살인/배신 거리낌 없음 |
| -100~-70 | 악귀 (Fiend) | 모든 악행 가능, NPC 전원 경계 |

**변동 요인:**

| 행동 | 도덕성 변화 |
|------|-----------|
| 무고한 자 구출 | +5~10 |
| 기부/자비 | +2~5 |
| 좀도둑 | -2~5 |
| 배신/사기 | -5~10 |
| 살인 (적) | -1~3 |
| 살인 (무고) | -10~20 |
| 매춘 (구매) | -1~3 |
| 매춘 (판매) | -3~5 |
| 동료 보호 (위험 감수) | +3~5 |

### 행동 제약 테이블

도덕성에 따라 플레이어가 **선택할 수 없는** 행동이 존재.

| 행동 | 필요 도덕성 | 비고 |
|------|-----------|------|
| 기부 | > -30 | 극악인은 기부에 거부감 |
| 자비 (적 방생) | > -10 | 회색 이상 |
| 좀도둑 | < +30 | 선인은 거부 |
| 자물쇠 따기 (타인 소유) | < +50 | 성인은 불가 |
| 협박 | < +10 | 보통 이하 |
| 매춘 (구매) | < +50 | 선인 이하 |
| 매춘 (판매) | < +30 | 보통 이하 |
| 살인 (무고) | < -10 | 악인 이하 |
| 배신 (동료) | < -30 | 극악 이하 |
| 노예매매 | < -50 | 악귀 이하 |

### 명성 × 도덕성 교차 효과

| | 명성 높음 | 명성 낮음 |
|---|---|---|
| **도덕성 높음** | 영웅 — NPC 흠모, 지원자 쇄도 | 무명의 선인 — 조용한 신뢰 |
| **도덕성 낮음** | 공포의 대상 — NPC 복종/도주 | 쥐새끼 — NPC 경멸, 밀고 위험 |

### 기존 시스템 연동

- **신뢰 (trust)**: 도덕성 극단 → NPC 신뢰 변동폭 확대
- **사기 (morale)**: 도덕 불일치 파티원 → 사기 하락 (선인이 악행 목격)
- **침식**: 높은 침식 → 도덕성 하락 경향 (던전의 부패)
- **파티 가입/이탈**: §4 참조

## 3. 매춘 시스템

### 개요

마을 술집 또는 특정 장소에서 성적 서비스를 거래.
플레이어는 구매자 또는 판매자가 될 수 있다.
NPC에게도 성적 지향과 욕구가 존재한다.

### NPC 성적 지향 (Orientation)

| 값 | 설명 | 대상 |
|---|---|---|
| hetero | 이성애 | 반대 성별만 |
| homo | 동성애 | 같은 성별만 |
| bi | 양성애 | 성별 무관 |
| ace | 무성애 | 성적 거래 거부 |

prop: `orientation` (캐릭터 생성 시 설정)

### 거래 조건

```
가능 여부 = 도덕성 제약 AND 지향 일치 AND 장소 AND 비용
```

| 조건 | 구매 | 판매 |
|------|------|------|
| 도덕성 | < +50 | < +30 |
| 장소 | 술집, 사창가, 은밀한 곳 | 동일 |
| 비용 | 소지금 충분 | - (수입 발생) |
| NPC 지향 | 플레이어 성별과 일치 | 상대 성별과 일치 |
| NPC 상태 | 거부 가능 (호감도, 도덕성) | - |

### 가격 체계

```
base_price = 50원
fame_modifier = 1.0 + (fame - 50) × 0.01  # 유명 → 비쌈(구매)/비쌈(판매)
appearance_modifier = 캐릭터 외모 보정
final_price = base_price × fame_modifier × appearance_modifier
```

### 영향

| 항목 | 효과 |
|------|------|
| 도덕성 | -1~5 (행위에 따라) |
| 명성 | 목격 시 +3 (악명) |
| 침식 | 쾌락 → 침식 -2~5 (일시적 해소) 또는 +3 (던전의 유혹) |
| 포만감/피로 | 피로 +10 |
| 동료 반응 | 목격한 파티원: 성격에 따라 사기/신뢰 변동 |
| 질병 리스크 | 낮은 확률로 상태이상 (향후) |

### NPC 매춘부

마을에 전용 NPC 배치 가능.
- 고유 대화/이벤트
- 반복 이용 시 관계 발전 가능
- 정보 거래 (던전 정보를 몸값으로)

## 4. NPC 파티 성향 시스템

### 핵심 원칙

**"NPC는 도구가 아니라 사람이다."**

NPC는 자신의 성향, 도덕성, 다른 파티원과의 관계에 따라:
- 파티 가입을 **거부**할 수 있다
- 새 멤버 영입 시 **스스로 나갈** 수 있다
- 긴 휴식 중 플레이어를 **덮칠** 수 있다

### 4.1 NPC 성향 (Disposition)

각 NPC에 내재된 성격 축:

| 축 | 범위 | 설명 |
|---|---|---|
| 공격성 (aggression) | -1.0 ~ +1.0 | 방어적 ↔ 공격적 |
| 탐욕 (greed) | 0.0 ~ 1.0 | 무욕 ↔ 탐욕 |
| 충성도 성향 (loyalty_tendency) | 0.0 ~ 1.0 | 배신 쉬움 ↔ 끝까지 따름 |
| 도덕성 (npc_morality) | -100 ~ +100 | 플레이어와 동일 스케일 |
| 성적 충동 (libido) | 0.0 ~ 1.0 | 무관심 ↔ 강한 욕구 |
| 독립성 (independence) | 0.0 ~ 1.0 | 순종적 ↔ 독립적 |

### 4.2 파티 가입 거부

NPC가 파티 초대를 거부하는 조건:

```python
def can_join_party(npc, player, current_members):
    # 1. 도덕성 차이
    morality_gap = abs(npc.morality - player.morality)
    if morality_gap > 60:
        return False, "우리는 너무 다른 사람이야."

    # 2. 기존 파티원과의 적대 관계
    for member in current_members:
        if npc.has_hostility(member):
            return False, f"{member.name}과(와) 같은 파티는 싫어."

    # 3. 신뢰 부족
    if trust.get_trust(npc.id) < 20:
        return False, "아직 널 믿을 수 없어."

    # 4. 명성에 따른 반응
    if player.fame < 10 and npc.independence > 0.7:
        return False, "무명인 네가 날 이끈다고?"

    # 5. 성향 충돌 (선인 NPC + 악인 플레이어)
    if npc.morality > 30 and player.morality < -30:
        return False, "네 방식은 따를 수 없어."

    return True, None
```

### 4.3 자발적 이탈

새 NPC 영입 시 기존 파티원이 떠나는 조건:

```python
def check_voluntary_leave(existing_npc, new_member, party):
    reasons = []

    # 1. 새 멤버와 적대
    if existing_npc.has_hostility(new_member):
        reasons.append(f"{new_member.name}과(와)는 함께할 수 없어.")

    # 2. 도덕성 갈등 (새 멤버가 극단적)
    morality_gap = abs(existing_npc.morality - new_member.morality)
    if morality_gap > 50 and existing_npc.independence > 0.5:
        reasons.append("저 사람과는 길이 다르다.")

    # 3. 파티 내 자기 역할 상실 (같은 직업 충돌)
    if existing_npc.character_class == new_member.character_class:
        if existing_npc.independence > 0.6:
            reasons.append("내 자리가 없어진 것 같군.")

    # 4. 사기/신뢰 임계 (기존 불만 누적)
    if morale.get_morale(existing_npc.id) < 20:
        reasons.append("더 이상은 못 참겠어.")

    if reasons:
        # 이탈 확률 = independence × (불만 수 × 0.3)
        leave_chance = existing_npc.independence * len(reasons) * 0.3
        if random.random() < leave_chance:
            return True, reasons[0]

    return False, None
```

**이탈 시 처리:**
- 마을 여관으로 돌아감
- 소지품 유지 (약탈 성향 NPC는 아이템 가져갈 수도)
- 재가입 가능 (관계 회복 후)
- 탐욕 높은 NPC: 파티 공유 자원 일부 가져감

### 4.4 야간 습격 (Rest Ambush)

**긴 휴식 중 NPC가 플레이어를 덮치는 상황.**

두 가지 유형:

#### A. 성적 습격 (Sexual Ambush)

조건:
```
libido > 0.6
AND 성적 지향이 플레이어와 일치
AND 침식 > 50 (던전의 부패가 억제력 약화)
AND 신뢰 < 40 OR 도덕성 < -20
AND 은신 판정 성공 (파티원 감시 회피)
```

발생 확률:
```
chance = libido × (erosion / 200) × (1 - trust / 100) × night_modifier
```

결과:
- 플레이어 인지 판정 (perception)
  - 성공 → 저지 가능 (대화/전투 선택)
  - 실패 → 이벤트 진행
- 사후: 신뢰/사기 변동, 도덕성 변동, NPC 수치심/만족

#### B. 약탈 습격 (Theft/Murder Ambush)

조건:
```
greed > 0.7 AND 플레이어 소지금 > NPC 기대치
OR
npc_morality < -50 AND loyalty_tendency < 0.3
OR
침식 > 100 (침식에 의한 광기)
```

발생 확률:
```
chance = greed × (1 - loyalty_tendency) × (1 - trust / 100)
# 침식 100+ 이면 ×2 보정
```

결과:
- 소지품 도난
- 극단적 경우: 살해 시도 → 전투
- 다른 파티원이 감시 중이면 저지 가능
  - 감시자의 loyalty_tendency 높으면 → 플레이어 편
  - 감시자의 greed 높으면 → 가담 가능

### 4.5 휴식 감시 시스템

긴 휴식 시 파티원 중 1명을 **보초**로 지정 가능.

```
보초 효과:
- 습격 감지 확률 = 보초의 perception × (1 - fatigue/100)
- 보초는 피로 회복 없음
- 보초 미지정 → 전원 취약 (습격 확률 ×2)
```

보초의 성향에 따른 반응:
| 보초 성향 | 성적 습격 감지 시 | 약탈 습격 감지 시 |
|----------|-----------------|-----------------|
| 충성 높음 | 즉시 저지 | 즉시 저지 |
| 독립적 | 상황 관망 → 개입 | 개입 |
| 탐욕 높음 | 무시 (거래 제안?) | 가담 가능 |
| 도덕 높음 | 즉시 저지 + 분노 | 즉시 저지 |

## 6. 구현 우선순위 (제안)

| 순위 | 시스템 | 이유 |
|------|--------|------|
| 1 | 도덕성 | 행동 제약의 기반 — 다른 시스템이 참조 |

### S04 성욕 이벤트 시스템

성욕(libido)이 임계치를 넘으면 **휴식 중 자동 이벤트** 발생.
캠프/안전 방에서의 장 휴식 시 판정.

#### 이벤트 발동 조건

```
휴식 시작
  │
  ├─ 각 캐릭터별 libido 체크
  │    libido > 0.6 → 이벤트 후보
  │
  ├─ 깨어있는 인원 체크
  │    보초 1명 + 본인만 깨어있음 → 1:1 가능
  │    보초 없음 + 본인만 깨어있음 → 단독 가능
  │    다수 깨어있음 → 이벤트 억제 (예외: 난교 조건)
  │
  └─ 이벤트 분기
```

#### 단독 이벤트 (본인만 깨어있음)

| 이벤트 | 조건 | 성별 | 효과 |
|--------|------|------|------|
| **몽정** | libido > 0.5, 수면 중 | 남성 | libido 해소, 더러움 +1, 수치심 -2 (목격 시) |
| **자위** | libido > 0.7, 깨어있음 | 공통 | libido 해소, 수치심 -3, 침식 -2 (쾌락=일시 해소) |
| **수면 중 신음** | libido > 0.4, 수면 중 | 공통 | 소음 → 주변 NPC 깨움 가능 (은신 판정) |

몽정: 성별 차이
- 남성: 더러움(정액) 잔류 → 아침에 발견 가능 (수치심)
- 여성: 외적 흔적 없음, 내적 자각만

자위: 수치심에 따른 분기
- shame > 60: 참으려 하지만 실패 → 조용히 (은신 판정)
- shame 30~60: 조심스럽게 처리
- shame < 30: 거리낌 없이 (소음 발생 가능)

#### 1:1 이벤트 (두 명만 깨어있을 때)

**조건:**
```python
def can_trigger_intimate_event(npc_a, npc_b):
    # 둘 다 깨어있음
    # 성적 지향 일치 (orientation 호환)
    # libido 양쪽 모두 > 0.5
    # 신뢰 > 30 (최소한의 관계)
    # 적대 관계 아님
    # 수치심: 둘 중 하나라도 shame > 80 → 불발
    return all_conditions_met
```

| 이벤트 | 조건 | 효과 |
|--------|------|------|
| **분위기** | libido 양쪽 > 0.5, trust > 30 | 대화 이벤트만. 관계 발전 힌트 |
| **스킨십** | libido 양쪽 > 0.6, trust > 50 | 가벼운 접촉. libido 소폭 해소, 신뢰 +3 |
| **성관계 (합의)** | libido 양쪽 > 0.7, trust > 60, shame < 70 | libido 해소, 침식 -5, 신뢰 +5, 도덕성 변동 (매춘 아님) |
| **성적 습격** | §4.4 야간 습격 조건 참조 | 비합의. 신뢰 -20, 수치심 -10, 파티 위기 |

**대화 형식:**
- 다이얼로그 기반 (ui.dialog)
- 선택지: 수용 / 거절 / (은신하여) 모른 척
- NPC 주도 or 플레이어 주도 분기
- 거절 시: NPC libido 유지 (다음 휴식에서 재시도 가능)

#### 난교 조건 (Orgy Route)

**극히 드문 특수 이벤트.** 모든 파티원이 조건 충족 시에만 발동.

```python
def check_orgy_conditions(party_members):
    # 전원 깨어있음 (보초 없음 or 보초도 참여)
    # 전원 libido > 0.7
    # 전원 shame < 40 (수치심 낮음)
    # 전원 trust 상호 > 40 (최소 친밀도)
    # 전원 orientation 호환 (적어도 bi 또는 상호 호환)
    # 침식 > 50 (던전의 부패가 억제력 약화)
    # 파티원 3명 이상
    return all_conditions_met
```

**발동 확률:** 조건 충족 시에도 30% (매번 발생하면 의미 감소)

**효과:**
- 전원 libido 완전 해소
- 전원 침식 -10 (공유된 쾌락)
- 전원 신뢰 +5
- 전원 수치심 -15 (큰 충격/해방)
- 전원 사기 +10 (유대감)
- 도덕성: 각자 -3~5
- 보초 부재 → 습격 무방비 (리스크)
- 이후 대화 선택지 변화 ("그날 밤 이후로...")

**억제 요인:**
- shame > 40인 멤버가 한 명이라도 있으면 불발
- 적대 관계 멤버 존재 → 불발
- ace(무성애) 멤버 존재 → 해당 멤버 제외 (3명 미만이면 불발)

#### NPC 간 이벤트 (플레이어 수면 중)

플레이어가 자고 있는 동안 NPC끼리도 이벤트 발생 가능:
- 아침에 분위기가 다름 (대사 변화)
- "밤에 소리가 들렸다" 텍스트
- NPC 간 신뢰/관계 변동 (플레이어 모르게)
- 도감에는 기록되지 않음 (당사자만 앎)

#### 침식과 성욕의 관계

```
침식 0~49:  정상적 성욕 조절
침식 50~99: 성욕 억제력 약화 (libido 감소 속도 ×0.5)
침식 100+:  성욕 폭주 경향 (libido +0.1/시간, shame -1/시간)
```

**"던전에 오래 있으면 이성을 잃는다"** — 침식이 정신뿐 아니라 본능도 부추긴다.
