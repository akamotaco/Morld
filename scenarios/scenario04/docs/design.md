# Scenario04: 마을과 던전 — 설계 문서

## 개요

**목적:** 시나리오02의 생활 시스템 기반 + JRPG 파티 '대결' 전투 검증

디아블로 1의 트리스트럼을 참고한 마을-던전 루프.
마을에서 준비하고, 인스턴트 던전에서 '대결'로 전투하며, 마을로 돌아와 회복/강화한다.

**참고 게임:**
- 디아블로 1 — 마을-던전 루프, 안전 거점
- 세계수의 미궁 — 미지의 던전 탐사, FOE, 5인 파티 턴제
- 컨셉션 — NPC 교류 → 파티원 생성, 관계가 전투력에 직결
- 메트로 퀘스터 — 생존 압박 (7일 식량), AP 기반 스킬 (마법 없음)
- 다키스트 던전 — 스트레스/기벽/광기, 던전의 정신적 압박
- 아우터 월드 2 — 행동 패턴 → 후천적 기벽 획득

**차별점: "같이 사는 사람과 같이 싸운다"**

기존 던전 RPG에서 파티원은 전투 유닛이다. 스탯을 보고 고른다.
시나리오04에서 파티원은 같이 생활하는 사람이다. 밥 먹고, 자고, 대화하며 관계가 형성된다.
핵심 질문: **"이 사람과 던전 깊은 곳에서 등을 맡길 수 있는가?"**

### 핵심 루프

```
마을 (준비/회복/거래/건축)
  │
  ├── 인스턴트 던전 (대결 전투, 탐사)
  │
  └── 자원 채취 필드 (벌목/채집/낚시)
```

## 시놉시스

### "바닥의 소문"

어느 날 마을 근처에 던전이 나타났다.
처음엔 모험가들이 보물을 찾아 들어갔지만, 돌아온 자는 거의 없었다.
돌아온 자들은 하나같이 말한다 — *"아래층에 뭔가 있다."*

소문이 퍼진다. **"최하층에 도달하면 소원이 이루어진다."**

플레이어는 던전의 최하층을 목표로 한다. 하지만 혼자서는 갈 수 없다.
마을의 여관에 모이는 떠돌이들을 모아 파티를 꾸려야 한다.

**문제는 — 누구도 믿을 수 없다는 것.**

### 중반 꺾기

던전 중간층에 도달하면 이벤트 발생:

> **"소원은 단 한 명에게만 이루어진다."**

이 순간 모든 관계가 재해석된다.

| 시점 | 전반부 | 꺾기 이후 |
|------|--------|----------|
| 파티원 | 동료 | 잠재적 경쟁자 |
| NPC 모집 | "강한 사람 환영" | "이 사람의 소원이 뭐지?" |
| 신뢰 | 쌓을수록 좋음 | 높은 신뢰 = 배신 시 더 치명적 |
| 타 파티 | 경쟁자 | 연합? 제거? 납치? |
| 도덕적 선택 | 가벼움 | 무거움 |

### 꺾기 이후 파티원 반응

NPC의 반응은 **전반부에서 쌓은 신뢰도 + NPC 성향**에 따라 결정:

| 유형 | 조건 | 행동 |
|------|------|------|
| **충성파** | 높은 신뢰 + 소원이 소박 | "그래도 당신을 따르겠다" |
| **동요파** | 중간 신뢰 | 주저, 도주/배신 가능성 |
| **이탈파** | 낮은 신뢰 | 즉시 탈퇴 또는 몰래 배신 준비 |
| **야심파** | 성향 무관 | 겉으로는 따르지만 기회를 노림 |

### 엔딩 구조

최하층 도달 시 — **"누구의 소원을 들어줄 것인가?"**

| 엔딩 | 조건 | 내용 |
|------|------|------|
| **자신의 소원** | 최하층 도달 + 마을 유지 | 플레이어의 소원 달성 |
| **파티원의 소원** | 특정 NPC 높은 신뢰 | 그 NPC에게 소원을 양보 |
| **소원 거부** | 특수 조건 | 던전의 진실을 밝힘 |
| **독점 실패** | 파티원 배신 | 야심파가 소원을 가로챔 |
| **전멸** | 파티 와해 | 아무도 소원을 이루지 못함 |
| **마을 붕괴** | 혼란도 임계 도달 | 외부 세력이 던전 봉쇄/파괴 |
| **추적자** | 혼란도 위기 + 플레이어 적대 | 군대/조사단이 플레이어를 표적으로 |

## 던전의 정체와 세계관

### 핵심 전제

**던전은 자연현상이 아니다. 누군가 만들었고, 운영되고 있다.**

"소원을 이루어준다"는 소문은 **미끼**. 모험가를 끌어들이기 위한 것.
왜 모험가가 필요한가:
- 모험가가 가져오는 **물자** (장비, 식량, 금화)
- 모험가 자체가 **자원** (노동력, 실험체, 에너지원)
- 모험가 간 **경쟁과 살육**이 목적 그 자체일 수도

### 소문의 구조 — 와전과 진실

```
[사실] 던전은 "특수 존재"와 상호작용한다
  │
  ├── 과거: 特수 존재가 던전에서 무언가를 얻었다
  │
  ├── 와전1 (소문1): "던전이 소원을 들어준다"
  │   → 특수 존재의 경험이 일반인에게 와전됨
  │
  └── 와전2 (소문2): "한 명의 소원만 들어준다"
      → 특수 존재가 희소하기에, 한 사람만 경험한 것이 "한 명만"으로 와전
      → D와 연계: 특수 존재가 복수이면 여럿에게 반응?
```

플레이어 인식 변화:

| 시점 | 플레이어 인식 | 실제 |
|------|------------|------|
| 초반 | "소원을 이루러 왔다" | 특수 존재라는 것도 모름 |
| 꺾기 | "한 명만이라고?!" | 와전이지만 진실처럼 느껴짐 |
| D 조우 | "이 사람도 나같은...?" | 특수 존재가 복수일 수 있다는 단서 |
| 심층 | "소문은 와전이었다" | 그렇다면 던전의 진짜 목적은? |

### 던전의 진실 (미확정)

소문이 와전이라면, 던전이 특수 존재와 **진짜** 하는 것은?

| 후보 | "특수 존재와의 상호작용"의 의미 | 톤 |
|------|--------------------------|-----|
| 변환 | 특수 존재를 던전의 일부로 흡수 (진화? 변이?) | 호러 |
| 공생 | 던전 = 생명체, 특수 존재 = 숙주 | SF |
| 계승 | 이전 특수 존재가 현 던전을 만듦. 다음은 플레이어? | 루프 |
| 해방 | 던전 안에 뭔가 갇혀 있고, 특수 존재만 해방 가능 | 판타지 |

→ 구현하면서 확정. "특수 존재"의 고유 명칭도 추후 결정.

### 던전 내 세력

| 세력 | 정체 | 행동 |
|------|------|------|
| **몬스터** | 던전의 원주민 또는 생성물 | 적대 (층별 생태계) |
| **수거반** | 던전에 적응한 생존자/패잔병 | 함정 설치, 실신자 약탈, 아이템 회수 |
| **관리자** | 던전 운영 세력의 말단 | 층 구조 변경, 몬스터 배치, 소문 유포 |
| **체류자** | 귀환을 포기하고 던전에 정착한 자들 | 중립 거래 가능, 정보 판매 |

- **수거반**: 함정을 깔고 실신한 NPC의 아이템을 훔치는 도둑 역할
- **관리자**: 던전이 왜 존재하는지의 단서를 제공, 세계관 핵심 연결
- **체류자**: 던전 내 중립 NPC, 물자 교환/정보 구매 가능
- 이들의 존재가 던전의 "의도된 운영" 느낌을 줌

## 인스턴스 모델 (하이브리드)

### 디아블로식 vs 세계수식

| 모델 | 장점 | 단점 |
|------|------|------|
| 디아블로식 (세션 고정) | 탐사 연속성, 지도 유지 | 패턴 학습 후 긴장감 소실 |
| 세계수식 (매번 랜덤) | 항상 신선함 | 진행감 부족, 전략 세우기 어려움 |

### 채택: 점진적 돌파 (디아블로식) + 실신 트리거 재편성

```
던전 생성 → 플레이어가 실신할 때까지 유지
  │
  ├── 유지 중: 동일 구조, 탐사 연속
  │   - 지도 유지됨
  │   - 실신 NPC 해당 위치에 잔류
  │   - 수거반/체류자도 위치 유지
  │   - 마을 ↔ 던전 자유 왕래 (포탈 없음, 도보/숏컷)
  │
  └── 플레이어 실신: "재편성"
      - 플레이어 마을에서 깨어남
      - 던전 구조 재생성 (새 BSP)
      - 해금한 숏컷 리셋
      - 잔류 NPC 처리 (아래 참조)
```

### 플레이어 실신 = 재편성 트리거

| 항목 | 처리 |
|------|------|
| 플레이어 | 마을에서 깨어남 (구호소) |
| 던전 구조 | 전체 재편성 (새 BSP 생성) |
| 숏컷 | **리셋** (다시 해금 필요) |
| 도달 기록 | 최고 층 기록은 유지 (실적) |

**"게임 오버이지만 게임 오버가 아닌"** — 실신의 대가는 던전 진행도 리셋.
스토리적 핍진성: 플레이어의 의식이 던전과 연결되어 있다? (추후 확정)

### 실신 NPC 처리

| 상태 | 처리 |
|------|------|
| 실신 중 + 던전 유지 | 해당 Location에 잔류 (구출 가능) |
| 재편성 발생 | **MIA 처리 → 삭제** (아이템 포함) |
| 자력 회복 / 타 파티 구출 | **MIA 처리 → 삭제** (아이템 포함) |

→ 실신 NPC를 빨리 구출해야 하는 동기 부여. 못 하면 영영 잃음.
→ 플레이어가 실신하면 던전 안의 모든 잔류 NPC도 잃음.

### 재편성과 세계관

- 플레이어와 던전의 연결 — 실신이 재편성을 유발하는 이유 (향후 스토리 핍진성 부여 필요)
- 관리자 시점에서는 "리셋" — 던전이 다시 먹이를 받아들일 준비
- 체류자/수거반은 재편성에 적응 → 새 구조에 재배치
- **NPC는 재편성을 인지하지 못함** — "길이 달라졌다"고 느끼지만 랜덤 던전이니 당연하다고 치부
- 플레이어만 반복 경험으로 패턴을 파악 → "왜 나만 돌아오지?"

### 스토리 전달 구조 (다크 소울식 + 파티 보강)

```
스토리 전달 채널:
  ├── 1순위: 환경 단서 (항상 존재, 솔로 플레이 가능)
  │   - 벽화, 유물, 이전 탐사자 유품/일지
  │   - 관리자가 남긴 메모/장치
  │   - 층마다 달라지는 던전의 "분위기"
  │   - 재편성 흔적 (이전 구조의 잔해?)
  │
  ├── 2순위: 파티원 반응 (동료 있을 때 보너스)
  │   - 재편성 후 혼란 대사
  │   - 특수 NPC가 단서를 해석
  │   - 꺾기 이후 의심/추궁
  │   - "세계의 지식" 축적 → 이탈 압박
  │
  └── 3순위: 던전 세력 NPC (조우 시)
      - 체류자의 단편적 정보 판매
      - 관리자와의 조우 (희귀 이벤트)
```

### "세계의 지식" 시스템

파티원이 던전의 진실에 가까워질수록 이탈 압박이 높아짐.

```
던전 탐사 중 단서 축적 → NPC가 진실에 가까워짐
  │
  ├── 무지: "이상한 던전이네"
  ├── 의심: "뭔가 숨겨진 게 있어"
  ├── 확신: "이 던전은... 우리를 이용하고 있어" (신뢰↓↓)
  └── 한계: "더 이상 못하겠어" → 이탈 선언
```

지식 축적 요인:
- 환경 단서 발견 (벽화, 일지 등)
- 재편성 경험
- 꺾기 이벤트
- 깊은 층 도달
- 특수 NPC와의 대화

### "아는 자"에 대한 플레이어 선택

NPC가 한계에 도달하면:

| 선택 | 수단 | 결과 |
|------|------|------|
| **처리** | 전투/실신/사고 위장 | 영구 제거, 목격자 사기↓↓ |
| **복종** | 조교/협박/약점 이용 | 입을 막음, 자율성↓ |
| **기억 소거** | 특수 아이템/정화사? | 지식 리셋 (희귀 수단) |
| **방치 (이탈)** | 파티에서 나감 | 마을로 돌아감 → 마을 혼란도↑ |

### 마을 혼란도

이탈한 "아는 자"가 마을에 돌아가면 마을 혼란도가 상승.

```
"아는 자"가 마을에 돌아옴
  │
  ├── 1명: "미친 소리" → 무시됨
  ├── 2~3명: "혹시...?" → 소문 확산
  ├── 4~5명: "사실이야" → 마을 동요
  └── 임계점: 외부 세력 개입
```

| 혼란도 | 마을 변화 |
|--------|----------|
| 낮음 | 평소와 동일 |
| 소문 | NPC 모집 난이도↑, 물가↑ |
| 동요 | 일부 상점 폐쇄, NPC 유입 감소 |
| 위기 | **군대/교단/조사단 도착** → 던전 봉쇄 시도? 플레이어 추적? |
| 붕괴 | 마을 기능 마비, 엔딩 분기 진입 |

### 귀환과 숏컷

포탈은 없다. 오염 속을 직접 걸어야 한다.

| 방법 | 내용 |
|------|------|
| 도보 귀환 | 왔던 길을 되돌아감 (오염 노출 지속) |
| 숏컷 | 특정 층에서 해금 (보스 클리어, 열쇠 등) → 해당 층 ↔ 입구 직행 |
| 숏컷 리셋 | 플레이어 실신(재편성) 시 모두 리셋 |

숏컷이 없는 깊은 층에서 귀환하려면 긴 도보 → 오염 누적 → "더 깊이 갈 것인가 돌아갈 것인가" 전략 판단.

| 배고픔/피로/체온 | Python | 동일 (needs.py, survival.py, temperature.py) |
| 날씨/습도 | Python | 동일 (weather, humidity) |
| 건축/파괴 | Python | 동일 (build.py) |

### 미사용 시스템

| 시스템 | 이유 |
|--------|------|
| 기본 공격 (1D 거리 기반) | '대결'로 대체 |
| 연애/임신 | **재활용 + 조교/복종 확장**. 던전 오염이 생체 주기를 가속 (임신~출산 대폭 단축) |
| NPC 고정 스케줄 | 랜덤 NPC는 스케줄 없음 |
| 혼잡 (congestion) | 단순화 |

### 재해석 시스템

| 시스템 | S02 의미 | S04 의미 |
|--------|---------|---------|
| **오염 (pollution.py)** | 위생 오염 (먼지, 더러움) | **던전 오염** (던전 기운의 농도) |

S02의 `pollution.py` 인프라를 그대로 재활용하되 의미를 재해석:
- location별 오염도 = 해당 구역의 던전 기운 농도
- 층별 기본 오염도 (깊을수록 높음) + 전투/이벤트로 추가 축적
- location 오염도가 부식/침식의 기반이 됨

```
층별 기본 오염도 (깊을수록 높음)
  + 전투/사망/에로 함정 등으로 추가 오염
  → location 오염도
      ├── 부식: 해당 location 체류 시 장비 내구도 감소
      └── 침식: 해당 location 체류 시 캐릭터 침식 축적
```

## 대결 (Encounter) 시스템

### 컨셉

시나리오02의 기본 공격(1D 거리 기반)을 **사용하지 않음**.
대신 '대결'이라는 별도 전투 모드로 진입.

### 구조

```
일반 게임플레이 (TextUI)
    │
    │  대결 발생 (몬스터 조우 / NPC 도전 / 타 파티 습격)
    ▼
미니게임 씬 로드 (Godot Scene 전환)
    │
    │  전투 진행 (JRPG 커맨드 전투)
    │  - 플레이어: 직접 조작
    │  - 파티원: 자동 전투 (지시 가능, 불복 가능)
    │
    │  전투 종료 (승리/패배/도주)
    ▼
일반 게임플레이 복귀 (결과 반영)
```

### 미니게임 씬 방식

- Python에서 Godot 미니게임 씬을 호출
- `scenes/minigame/` 하위에 전투 씬 배치
- 기존 `MiniGameContainer` 노드 활용
- 전투 외에도 낚시 등 다른 미니게임에 동일 패턴 적용 가능

### 전투 대상

| 대상 | 조건 | 예시 |
|------|------|------|
| 몬스터 | 던전 내 조우 | 층별 생태계 |
| 타 파티 | 던전 내 조우 / 플레이어 선택 | 경쟁 모험가 파티 |
| NPC | 특정 조건 (도전/적대) | 수거반, 관리자 |

### 전투 지시 + 불복

```
플레이어 → 파티원에게 지시
  │
  ├── 복종 (신뢰 높음 / 지시가 합리적)
  ├── 주저 (신뢰 중간 / 위험한 지시) → 지연 실행
  └── 불복 (신뢰 낮음 / 기벽 발동 / 공포) → 독자 행동
```

불복 요인:
- **신뢰도** — 낮으면 불복 확률 증가
- **기벽** — 겁쟁이는 돌격 명령 거부
- **상황** — HP 낮은데 위험한 지시
- **꺾기 이후** — "단 한 명" 사실 인지 후 불복률 상승

### 전투 방식 (추후 상세화)

> 턴제 / ATB / 하이브리드 등 — 별도 논의 필요

## 파티 시스템

### 시나리오04의 파티 = JRPG 파티

- 위자드리/FF 스타일: 파티원이 플레이어와 **일심동체**
- 스쿼드(CRPG)와 다름: **파티 상태에서는** 개별 이동/독립 행동 없음
- 단, 이탈/반란 이벤트 발생 시 **파티 강제 탈퇴 후** 독립 행동
  - 도주: 야영 중 파티 이탈 → 독자 행동 (던전 탈출 또는 타 파티 합류)
  - 반란: 파티 해제 → 적대 전환 → 대결 또는 도주

### 파티 통합 관리

파티에 합류하면 개별 NPC의 욕구가 **파티 단위로 통합**:

| 항목 | 비파티 | 파티 합류 후 |
|------|--------|-------------|
| 이동 | 독립 | 플레이어 따라감 |
| 배고픔 | 개별 관리 | 파티 통합 (공유 식량) |
| 피로 | 개별 관리 | 파티 통합 (동시 휴식) |
| 전투 | 없음 | 대결 시 함께 참전 (자동 전투) |
| 스케줄 | 없음 (여관 대기) | 없음 (플레이어 따라감) |

### 실신 = 자동 이탈

```
파티원 실신 → 자동 파티 탈퇴 → 해당 Location에 쓰러진 상태로 배치
```

이로 인한 파생 상황:

| 상황 | 결과 |
|------|------|
| 내 파티원 실신 | 자동 이탈, 구출하거나 버리거나 |
| 짐이 되는 파티원 | 의도적으로 위험에 노출 → 이탈 유도 |
| 타 파티원 실신 발견 | 구출/약탈/납치 선택 |
| 타 파티 공격 → 실신 | 대결 → 실신시킨 NPC 납치 가능 |

플레이어/NPC 파티 무관하게 동일 규칙 적용.

### NPC 반란/배신

신뢰도 + 꺾기 이후 + 기벽 조합에 따라:

| 조건 | 결과 |
|------|------|
| 신뢰 낮은 NPC 1명 | 단독 이탈 (야영 중 도주) |
| 신뢰 낮은 NPC 복수 | 합심 → 플레이어 기습 → 아이템 강탈 후 도주 |
| 야심파 NPC | 꺾기 이후 독자 행동, 최하층 경쟁자로 전환 |
| 극단적 | 플레이어 실신시키고 던전에 버림 |

### 복수 파티

- 플레이어 파티 외에 **NPC 파티**도 존재 가능
- NPC 파티 = 여러 NPC를 하나의 그룹으로 묶음
- 시나리오02의 creature(생명체)와 유사하나, 파티 단위로 행동
- NPC 파티와도 '대결' 가능
- 이탈한 야심파 NPC가 자체 파티를 결성할 수도 있음

## 오염 시스템

### 용어 체계

"오염"은 던전에서 발생하는 부정한 기운의 총칭.
세계관 고유 명칭은 추후 확정 (후보: 명독, 어스름 등).

```
오염 = 던전의 부정한 기운 (총칭)
  ├── 부식 = 장비/아이템에 대한 오염
  ├── 침식 = 캐릭터에 대한 오염
  └── 잠식 = 공간에 대한 오염 (던전 확장)
```

관련 참고:
- 젤다 Gloom — 깊을수록 강해짐, HP 상한 감소
- 메이드 인 어비스 — 깊이에 비례하는 저주
- FF Crystal Chronicles Miasma — 세계를 뒤덮은 독기
- Symbaroum Corruption — 마법 = 오염 축적
- 다키스트 던전 Stress — 스트레스 → 고질/미덕

| 용어 | 뜻 | 용례 |
|------|-----|------|
| **오염** | 던전의 부정한 기운 총칭 | "오염이 짙다" |
| **부식** | 장비 열화 | "검이 부식됐어" |
| **침식** | 정신 열화 | "침식이 한계야" |
| **잠식** | 공간 열화 | "마을 근처까지 잠식이 번졌다" |
| **오염도** | 오염 수치 | "이 층은 오염도가 높다" |
| **정화** | 오염 제거 행위 | "정화 받아야 해" |
| **정화사** | 오염 전문가 | "정화사한테 가자" |
| **내오성** | 오염 내성 | 장비/캐릭터 속성 |
| **변이** | 오염에 의한 변질 | 과부식 장비, 깨우침 |
| **오염원** | 오염의 근원 | 던전 최하층 |

### 부식 (Corrosion) — 장비/아이템

| 항목 | 내용 |
|------|------|
| 대상 | 장비, 소모품, 소지 아이템 전반 |
| 축적 | 던전 체류 시간에 비례하여 자연 축적 |
| 효과 | 내구도 저하 → 성능 하락 → 최종 파괴 |
| 대응 | 대장간 수리, 아이템 교체 |

부식된 장비의 갈래:
- 수리하여 원상복구
- 방치하면 파괴
- **과부식 장비**: 오염의 힘이 깃든 변이 장비? (미확정)
- 수거반이 부식 장비를 싸게 거래

### 침식 (Erosion) — 캐릭터

| 항목 | 내용 |
|------|------|
| 대상 | 플레이어 + NPC (파티원 포함) |
| 축적 | 던전 체류, "던전의 힘" 사용, 전투, 에로 함정 등 |
| 효과 | 기벽 발현, 명령 불복, 광기, 실신 |
| 대응 | 휴식, 마을 귀환, 정화소 |

```
침식 게이지 (0~200)
  │
  ├── 0~50: 정상
  ├── 50~100: 경미한 기벽 발현 가능
  │
  ├── 100: 판정 (Resolve Check)
  │   ├── 75%: 고질 (Affliction) — 심각한 기벽 획득
  │   └── 25%: 깨우침 (Awakening) — 일시 또는 영구 강화
  │   → 판정 후 게이지 절반으로 감소 (100 → 50)
  │     (밸런스 조정 가능 — 리셋(0)/소폭감소(80~90)/유지(100) 등)
  │
  ├── 100~200: 고질/깨우침 보유 상태에서 추가 축적
  │   → 2차 판정 없음, 200 도달 시 즉시 붕괴
  │
  └── 200: 심신 붕괴 → 실신 (= 파티 이탈)
```

### 깨우침 (Awakening)

침식 100 도달 시 25% 확률로 고질 대신 깨우침 발생.

| 깨우침 | 효과 | 지속 |
|--------|------|------|
| 결의 | 침식 축적 속도 -50% | 해당 던전 탐사 중 |
| 용맹 | 공격력↑, HP 낮을수록 강화 | 해당 던전 탐사 중 |
| 집중 | 명중/회피↑, 파티 버프 | 해당 던전 탐사 중 |
| **영구 깨우침** (극희귀) | 고유 스킬 해금 또는 스탯 영구 상승 | 영구 |

영구 깨우침 확률: 깨우침의 ~10% (전체 ~2.5%).
침식을 감수하고 "던전의 힘"을 적극 사용하는 플레이에 대한 보상.

### 이중 압박

```
던전 오염
  ├── 부식 → 장비 열화 → 수리/교체 필요 (자원 소비)
  └── 침식 → 정신 열화 → 휴식/치료 필요 (시간 소비)
```

오래 머물수록 장비도 망가지고 정신도 무너짐.
짧은 탐사 반복 vs 깊은 원정의 트레이드오프.

### 침식 가속/감소 요인

| 요인 | 침식 변화 |
|------|----------|
| 던전 체류 시간 | 시간당 소폭 증가 (깊은 층일수록 가속) |
| "던전의 힘" 사용 | 사용량에 비례 증가 |
| 전투 패배 / 동료 실신 목격 | 급증 |
| 에로 함정 | 증가 (성적 침식) |
| 꺾기 사실 인지 | 일시 급증 |
| 사기 저하 | 침식 축적 가속 |
| 짧은 휴식 | 소폭 감소 |
| 긴 휴식 | 대폭 감소 |
| 마을 귀환 | 시간 경과로 점진 감소 |
| 정화소 | 즉시 감소 (비용) |
| 술집 | 소폭 감소 |

## 전투 능력 — "던전의 힘"

### 마법은 없다

이 세계에 전통적인 MP 기반 마법은 존재하지 않는다.
대신 던전의 오염 에너지를 끌어다 쓰는 초월 능력이 존재한다.

**참고:** 브레스 오브 파이어 5의 D-카운터 — 용의 힘을 쓸수록 게이지가 올라가고 100%에서 게임 오버.
S04도 동일한 구조이나, **던전 밖에서 침식을 줄일 수 있다**는 점이 다름.

### 이중 전투 체계

| 구분 | AP 스킬 | 던전의 힘 |
|------|---------|----------|
| 자원 | AP (Action Point) | **침식 축적 (부작용)** |
| 안정성 | 안전, 반복 가능 | 강력하지만 대가 |
| 성장 | 클래스/장비 의존 | 던전 깊이에 비례 |
| 리스크 | 없음 | **침식 급증 → 기벽/광기/실신** |

```
AP 스킬: 안전, 반복 가능 (일반 전투)

던전의 힘: 침식 급증 (핵심 부작용)
  ├── 던전 안: 휴식으로 소폭 감소 가능하지만 한계
  ├── 던전 밖: 정화소/시간 경과로 감소 가능
  └── 남용 시: 침식 100 판정 → 고질/깨우침 → 200 실신
```

### 사용 자격

**모든 생명체가 쓸 수 있는 것은 아니다.** 특수한 존재만 가능:

| 대상 | 사용 가능 | 조건 |
|------|----------|------|
| 플레이어 | O | 기본 특수 |
| 특수 NPC | O | 특수 직업 (희소, 모집 가치 높음) |
| 특수 몬스터 | O | 오염 친화 개체 (강적) |
| 일반 NPC | X | AP 스킬만 |
| 일반 몬스터 | X | AP 스킬만 |

- "던전의 힘"을 쓸 수 있는 파티원은 **희소한 자원** → 모집 가치 차별화
- 특수 몬스터의 던전의 힘 사용 → 일반 몬스터와 위협도 차이
- "마법"이라 부르지 않음 — "던전의 힘", "심연의 속삭임" 등 세계관 용어

### NPC 자동전투 시 통제

파티원이 자동전투 중 던전의 힘을 쓸 때, 플레이어가 전투 지시로 빈도 통제:

```
전투 지시 옵션:
  ├── 물리만 (AP 스킬만 사용 — 침식 안전)
  ├── 자유 (AI 판단에 맡김)
  └── 전력 (던전의 힘 적극 사용 — 침식 급증 감수)
```

- 세계관과 직결: 던전이 모험가에게 힘을 줘서 중독시키고, 결국 잠식
- 던전이 깊을수록 강한 힘을 쓸 수 있지만 침식도 가속

## 기벽 (Quirk) 시스템

### 기벽의 두 축

| 축 | 대상 | 획득 방식 |
|----|------|----------|
| **선천 기벽** | NPC | 생성 시 결정, 숨겨짐 → 점진적 발각 |
| **후천 기벽** | NPC + 플레이어 | 침식 축적 또는 행동 패턴 반복으로 획득 |

**NPC 선천 기벽**: 모집 시 안 보임, 함께 지내며 드러남 (관찰력 영향)
**후천 기벽**: 침식이 쌓이면 발현 (다키스트 던전식) + 행동 패턴 반복 시 획득 (아우터 월드 2식)

### 기벽 등급

#### 자잘한 기벽 (침식 50+)

| 기벽 | 효과 |
|------|------|
| 잠꼬대 | 긴 휴식 시 파티원 수면 방해 |
| 코골이 | 긴 휴식 시 파티원 피로 회복 감소 |
| 편식 | 특정 식량만 섭취, 나머지 거부 |
| 수집벽 | 쓸모없는 아이템 줍기 (인벤토리 낭비) |
| 혼잣말 | 가끔 위치 노출 (몬스터 조우 확률↑) |

#### 신경쓰이는 기벽 (침식 70+ 또는 선천)

| 기벽 | 효과 |
|------|------|
| 도벽 | 휴식 시 동료 아이템 훔침 |
| 대식 | 식량 1.5~2배 소비 |
| 겁쟁이 | HP < 30%에서 명령 무시, 도주 |
| 의심병 | 타 파티원 신뢰 하락 유발 |
| 과식 | 식량 있으면 자동 소비 |
| 독백 | 불안한 말을 해서 파티 침식 소폭 가속 |

#### 심각한 기벽 (침식 100+ 고질)

| 기벽 | 효과 |
|------|------|
| 폭주 | 전투 중 아군 공격 |
| 피해망상 | 랜덤 파티원을 적으로 인식 |
| 탐욕 | 보물 독식, 공유 거부 |
| 배신 | 야영 중 아이템 훔치고 도주 |
| 바람기 | 타 파티에 정보 유출 |
| 난폭 | NPC 도발, 원치 않는 대결 유발 |

#### 성적 기벽 (침식 80+ 또는 에로 함정)

| 기벽 | 효과 |
|------|------|
| 몽정 | 긴 휴식 시 성적 반응 (무해) |
| 노출증 | 장비 탈의 충동 (방어력 하락) |
| 성적 집착 | 특정 파티원에 대한 성적 관심 |

#### 성적 심각 (침식 100+ 고질)

| 기벽 | 효과 |
|------|------|
| 무차별 흥분 | 에로 함정 없이도 자발적 흥분 |
| 강제 관계 시도 | 휴식 중 파티원에게 성적 접근 |
| 복종 갈망 | 명령에 과도하게 순종 (역이용 가능?) |

#### 긍정 기벽 (각성 / 선천)

| 기벽 | 효과 |
|------|------|
| 충직 | 명령 불복 확률 감소 |
| 자기희생 | 동료 위기 시 자발적 방어 |
| 결의 | 침식 축적 속도 감소 |
| 집중 | 전투 명중률/회피율 상승 |
| 용맹 | HP 낮을수록 공격력 상승 |

### 플레이어 후천 기벽 (행동 패턴 기반)

아우터 월드 2 방식: 특정 행동 반복 시 기벽 획득 제안이 뜸.

| 행동 패턴 | 획득 기벽 | 효과 |
|----------|----------|------|
| 소매치기 반복 | 도벽 | 자동 훔침 (발각 리스크) |
| 성추행 반복 | 변태 | 특정 상황 자동 반응, NPC 경계 |
| 약탈 반복 | 약탈자 | 전투 보상↑, 모집 난이도↑ |
| 구출 반복 | 영웅심 | 치료소 할인, 위험 상황 자동 개입 |
| NPC 사망 방관 반복 | 냉혈 | 신뢰 변동 둔감, 모집 난이도↑ |
| 던전의 힘 남용 | 심연 친화 | 던전의 힘 강화, 침식 가속 |

## 사기 (Morale) 시스템

### 개인 사기 + 파티 평균

사기는 **개인별 수치**. 파티 사기는 평균 + 분산으로 표시.

```
파티원 A: 사기 80
파티원 B: 사기 45  ← 불안정
파티원 C: 사기 70
플레이어: 사기 90

파티 평균: 71 — "보통"
분산 높음 — "불온한 기운이 감지된다"
```

### 개인 사기의 효과

| 범위 | 상태 | 효과 |
|------|------|------|
| 높음 (70+) | 안정 | 불복↓, 기벽 발현 억제, 전투 보너스 |
| 보통 (40~69) | 동요 | 기본 |
| 낮음 (20~39) | 위험 | 불복↑, 기벽 발현 가속, 도주/배신 가능 |
| 바닥 (0~19) | 붕괴 | 반란, 파티 이탈, 독자 행동 |

### 파티 사기 표시 (UI)

| 표시 | 조건 | 의미 |
|------|------|------|
| 평균만 | 분산 낮음 | 파티 안정적 |
| 평균 + 경고 | 분산 높음 | 누군가 흔들리고 있음 |
| 평균 + 위험 | 최저치가 임계(20) 이하 | 반란/이탈 임박 |

### 플레이어 사기

**플레이어도 사기 영향을 받는다.**
- 플레이어 사기 저하 → 일부 행동 제한 (선택지 감소, UI 연출)
- 플레이어 사기 붕괴 → 컨트롤 불가능한 상황 (자동 행동)
- **사기 면역 아이템**: 플레이어 한정, 희귀. 장착 시 사기 하락 면역
  - 면역 아이템 없이 저사기 버티기 = 하이리스크 플레이 (후천 기벽 가속)

### 사기 변동 요인

사기 +/-는 **파티원 전원에게 공통 적용** (개인별 수치에 각각 반영):

| 상승 | 하락 |
|------|------|
| 전투 승리 | 전투 패배 |
| 보물 발견 | 동료 실신 |
| 공정한 분배 | 불공정 분배 |
| 긴 휴식 성공 | 식량 부족 |
| 팀 내 좋은 관계 | 팀 내 불화/기벽 충돌 |
| 층 돌파 | 꺾기 사실 인지 |
| 깨우침 발생 | 고질 발생 (본인 + 파티 전원) |

### 사기와 침식의 양방향 연결

- **사기 → 침식**: 낮은 사기 → 침식 축적 가속 (정신적으로 취약)
- **침식 → 사기**: 고질 NPC 존재 → 파티 전원 사기 지속 하락
- **기벽 → 사기**: 기벽 행동 발현(독백, 폭주 등) → 목격자 사기 하락 이벤트
- **사기 붕괴 + 높은 침식** → 반란/파티 와해

## 경제 시스템

### 화폐: 원

현실 화폐 단위를 사용. 물가 감각이 직관적.

### 경제 톤: "돈은 있는데 쓸 곳이 많다"

```
수입 (던전 전리품 + 경영 + 기타)
  vs
지출 (정화비 + 수리비 + 식량 + 모집비 + ...)
```

### 마을 경제 흐름

```
던전 출현 → 모험가 유입 → 재화/물자 유입 → 상점/여관/대장간 순환
```

마을 경제는 던전에 의존. 모험가가 줄면 마을도 쇠퇴 (혼란도와 연동).

### 플레이어 수입원

| 수입원 | 내용 | 규모 |
|--------|------|------|
| 던전 전리품 | 잡동사니/장비 수집 → 잡화점 판매 | 주 수입 |
| 특수 아이템 | 미확인 장비/장치 → 수집가/연구자 고가 매입 | 가끔, 고수입 |
| 자원 채취 | 필드에서 벌목/낚시/채집 → 판매 | 안정적, 소액 |
| 경영 수익 | 여관/상점 운영 (알바생 고용 가능) | 궤도 타면 안정적 |
| 구출 보상 | 실신 NPC 구출 → 답례금 | 불규칙 |
| 약탈/강매 | 타 파티/NPC 대상 | 즉시, 평판↓ |
| 인신매매 | 암시장 | 고수입, 고위험 |

### 주요 지출

| 지출 | 내용 | 빈도 |
|------|------|------|
| 정화비 | 정화소에서 침식 해소 | 매 원정 후 |
| 수리비 | 대장간에서 부식 수리 | 매 원정 후 |
| 식량 | 파티 식량 구매 | 상시 |
| 모집비 | NPC 파티 합류 보수 | 파티 편성 시 |
| 소모품 | 회복약, 항오염제 등 | 원정 준비 |
| 숙박비 | 여관 휴식 | 긴 휴식 시 |
| 건축비 | 시설 건축/확장 | 경영 투자 |

### 경제 성장

초반: 모든 지출이 빠듯 → 어디에 돈을 쓸지 선택의 연속
중반: 경영(상점/여관) 궤도 + 알바생 고용 → 지출 일부 상쇄
후반: 깊은 층 전리품 가치↑, 경영 안정 → 여유 생기지만 지출도 커짐

## 플레이어 자유도

던전 공략만이 아닌, 마을에서의 다양한 삶.

### 생업

| 생업 | 내용 | 수입원 |
|------|------|--------|
| **모험가** | 던전 공략, 보물 | 전리품, 소재 |
| **상인** | 던전 내 NPC에게 물자 판매 | 금화 |
| **구조자** | 실신 NPC 구출 → 마을 치료소 | 답례금, 평판 |
| **사냥꾼** | 자원 채취 필드 활동 | 소재, 식량 |
| **약탈자** | 타 파티 습격, 강탈 | 장비, 금화, 평판 하락 |
| **인신매매** | 실신/포획 NPC 매매 | 큰 금화, 평판 대폭 하락 |
| **조교사** | 포획 NPC → 복종 → 파티 편입 | 충성 파티원 (불안정) |

### 경영 시스템

건축을 통해 플레이어가 직접 시설을 짓고 운영:

| 경영 | 내용 | 수입 | 연결 시스템 |
|------|------|------|-----------|
| 여관 운영 | NPC 체류 → 숙박비 | 안정적 소득 | 건축 + 평판 |
| 상점 운영 | 크래프트 아이템 판매 | 자원→금화 | 크래프트 + 평판 |
| 삥뜯기 | 타 파티/NPC 협박 → 금품 | 즉시 금화 | 전투 리스크, 평판↓ |
| 강매 | 비싼 가격에 아이템 떠넘김 | 폭리 | 화술, 평판↓ |

경영 시스템은 별도 시스템이 아닌 **기존 생활 시스템의 확장**으로 구현.
S02/S03에서도 재활용 가능한 공통 시스템으로 설계.

### 평판 시스템

| 세력 | 관계 영향 |
|------|----------|
| 마을 주민 | 상점 가격, NPC 모집 난이도 |
| 모험가 길드 | 정보, 구출 보상, 파티 후보 질 |
| 암시장 | 인신매매, 밀수품, 금지 아이템 |
| 던전 세력 | 수거반/체류자와의 거래 가능 여부 |

**트레이드오프:**
- 구조자 플레이 → 길드 평판↑ → 좋은 NPC 모집 가능
- 약탈자 플레이 → 길드 평판↓, 암시장 평판↑ → 강력하지만 불안정한 NPC
- 인신매매 → 암시장 전용, 발각 시 마을 추방 리스크
- 경영자 플레이 → 마을 주민 평판↑, 안정적 수입, 던전 진행은 느림

## NPC 시스템

### 정규 NPC (4명)

스토리/메인 퀘스트와 연결된 고유 NPC. 전원 파티 합류 가능.

#### A — 욕망의 동반자 (마을 정기 방문)

| 항목 | 내용 |
|------|------|
| 성격 | 탐욕, 실리적, 유쾌 |
| 동기 | 돈. 던전 = 금광 |
| 역할 | 정보상/상인 계열. 소문/정보 제공, 꺾기 힌트 |
| 플레이어 관계 | "넌 리셋해도 살아남잖아? 최고의 파트너야" |
| 특수성 | 플레이어의 비밀에 개의치 않음. 오히려 이용하려 함 |
| 위험 요소 | 탐욕이 극에 달하면 배신 가능 (보물 독식) |
| 꺾기 이후 | "소원? 나는 돈이면 돼. 소원은 네가 가져" (진심? 거짓?) |

#### B — 대척점/적대자 (마을 정기 방문)

| 항목 | 내용 |
|------|------|
| 성격 | 정의감, 의심, 행동파 |
| 동기 | 던전의 위험으로부터 사람들을 지키고 싶음 |
| 역할 | 전직 모험가. 던전 지식 제공, 위화감 감지 |
| 플레이어 관계 | 초반 동료 → 힘을 깨닫고 경계 → 적대 가능 |
| 스토리 흐름 | 위화감 → 조사 → 확신 → "네가 던전과 연결된 거잖아" |
| 분기 | 설득 성공 → 강력한 아군 / 실패 → 군대 소환 (혼란도 급등) |
| 특수성 | 세계의 지식 가장 빨리 축적. 마을 혼란도의 핵심 트리거 |

B와 마을 혼란도 연동:
- B 설득 성공 → 혼란도 억제
- B 이탈 → 혼란도 급등 (군대 연결)
- B 처리 → 혼란도 안정, 도덕적 대가

#### C — 트라우마/부활 (던전 내 조우)

| 항목 | 내용 |
|------|------|
| 성격 | 과묵, 체념적, 내면에 강한 힘 |
| 동기 | 없음 (파티 전멸 후 삶의 의미 상실) |
| 역할 | 체류자 출신. 던전 세력 정보, 수거반/관리자 단서 |
| 플레이어 관계 | 무관심 → 케어받으면 서서히 마음 열림 |
| 스토리 흐름 | 구출 → 무기력 → 재편성 목격 → 경악/공포 → 분기 |
| 분기 (방치) | 절망 심화 → 파티 이탈 → 자살 암시 (던전에서 혼자 걸어감) |
| 분기 (케어) | 신뢰 회복 → 과거의 강력한 전투력 부활 → AP 스킬 최강 |
| 특수성 | 부활 시 정규 NPC 중 최강 전투력 (던전의 힘은 없음) |

#### D — 거울/진실 (던전 내 조우)

| 항목 | 내용 |
|------|------|
| 성격 | 외유내강, 내성적, 비밀 많음 |
| 동기 | 자신의 정체를 알고 싶지만 두려움 |
| 역할 | 플레이어의 거울. 진실 탐구 파트너 |
| 플레이어 관계 | 동질감 → 유일한 이해자 → 함께 진실에 다가감 |
| 스토리 흐름 | 조우 → 힘 숨김 → 점진적 공개 → 진실 탐구 |
| 던전의 힘 | **플레이어보다 압도적으로 강함** (하지만 안 씀) |
| 핵심 갈등 | "쓰면 강하지만 인간이 아니게 되는 느낌" |
| 특수성 | **D 실신 = 재편성 트리거** (플레이어와 동일). 심층 진실의 열쇠 |

D가 재편성을 유발하는 이유 → 플레이어와 같은 종류의 존재? → 심층 진실 단서.
D를 파티에 넣으면 강력하지만, D가 실신하면 전부 리셋 → 하이리스크.

#### 정규 NPC 스토리 진행

```
초반: A 합류 (마을) → 던전 탐사 시작
      B 합류 (마을) → 파티 멘토
      
중반: C 조우 (던전 5~10F) → 구출/합류
      D 조우 (던전 10F+) → 미스터리 시작
      
꺾기: "단 한 명" → A 무관심, B 의심 가속, C 공포, D "알고 있었어"

후반: B 분기 (설득 or 적대)
      C 분기 (부활 or 자살)
      D 함께 심층 진입 → 진실
```

#### 4인 엔딩 영향

| 엔딩 | A | B | C | D |
|------|---|---|---|---|
| 자신의 소원 | 독점? 분배? | 설득됐으면 묵인 | — | 양보? |
| A에게 소원 | **돈** | — | — | — |
| B에게 소원 | — | **던전 봉쇄** | — | — |
| C에게 소원 | — | — | **동료 부활?** | — |
| D에게 소원 | — | — | — | **인간이 되기?** |
| 소원 거부 | "왜?!" | 동의 | 동의 | **D와 함께 진실 규명** |
| 마을 붕괴 | 돈 들고 도주 | B가 군대 소환 | — | — |
| 추적자 | — | B 루트 결과 | — | D를 보호해야 |

## 휴식 시스템

### 짧은 휴식 vs 긴 휴식

| 구분 | 짧은 휴식 | 긴 휴식 |
|------|----------|---------|
| 내용 | 앉아서 쉼 | 잠을 잠 |
| 회복 | HP 일부, 침식 소폭 감소 | HP 전부, 침식 대폭 감소, 배고픔/피로 해결 |
| 시간 | 1~2시간 | 6~8시간 |
| 공간 | 중간 크기 Location | **넓은 Location만 가능** |
| 리스크 | 낮음 | 높음 (습격, 도둑, 에로 이벤트, 배신) |
| 기벽 발현 | 낮음 | 높음 (휴식 중 이벤트 다수 발생) |

### 공간 제약

던전 Location의 크기(length)에 따라 휴식 가능 여부가 결정됨:
- **좁은 방**: 휴식 불가 → 통과만 가능
- **중간 방**: 짧은 휴식만 가능
- **넓은 방**: 긴 휴식 가능

던전 설계 시 넓은 방을 희소하게 배치 → 휴식 포인트 탐색이 탐사 동기가 됨.

### 휴식 중 이벤트

긴 휴식은 시간이 길어 다양한 이벤트가 발생할 수 있음:
- 기벽 발현 (도벽, 몽정, 잠꼬대 등)
- 수거반 습격
- 파티원 간 대화 (신뢰 변동)
- 파티원 도주 (신뢰 낮은 경우)
- 플레이어 선택: 수면 대신 성추행 (회복 포기, 침식↑)

## 퍼즐 시스템

던전을 내려가기 위한 조건이 전투만은 아님.

### 퍼즐 유형

| 유형 | 예시 | 연결 |
|------|------|------|
| 환경 퍼즐 | 스위치 조합, 물길 변경, 빛 반사 | 층 이동 조건 |
| 지식 퍼즐 | 벽화 해독, 단서 조합 | 체류자가 힌트 판매 |
| 파티 퍼즐 | 동시 행동 필요 (2인 스위치) | 파티원 신뢰 필요 (불복 시 실패) |

파티 퍼즐이 핵심 차별점: **신뢰 낮은 파티원은 협력 퍼즐에서 불복할 수 있음.**

## 에로 함정 + 성적 상호작용

### 에로 함정

던전 특정 Location에 설치된 함정.

| 함정 | 효과 | 비고 |
|------|------|------|
| 최음 가스 | 파티 전원 성적 흥분 상태 | 침식 증가 |
| 속박 함정 | 1명 구속 → 구출 필요 | 파티 퍼즐 요소 |
| 환각 포자 | 환각 + 성적 자극 | 침식 급증, 성적 기벽 유발 |

### 흥분 상태에서의 파생

S02의 arousal/stimulation 시스템 재활용:

| 조건 | 발생 이벤트 |
|------|-----------|
| 2인 + 높은 호감 + 흥분 | 성행위 이벤트 (선택적) |
| 다수 + 높은 호감 + 흥분 | 난교 이벤트 |
| NPC끼리 높은 호감 + 흥분 | NPC 간 성행위 (NTR/BBS 요소) |
| 플레이어 선택 (휴식 시) | 회복 포기 + 성추행 (신뢰↓, 복종↑) |
| 고침식 NPC + 성적 기벽 | 자발적 성적 접근 |

### 성적 관계의 영향

- 합의된 관계 → 신뢰↑, 파티 결속
- 강제/비합의 → 신뢰↓↓, 반란 리스크, 복종 전환 가능
- NPC 간 관계 → 파티 내 파벌, 질투, NTR 긴장
- 조교 완료 NPC → 높은 복종, 낮은 자율성

## 맵 구조

### Region 0: 마을

트리스트럼 컨셉. 안전 거점.

```
┌─────────────────────────────┐
│         마을 광장            │
│     (게시판, 우물, NPC)      │
│                             │
│  여관──대장간──잡화점──광장  │
│   │                    │    │
│  창고──농장──────────채취장  │
│                        │    │
│              던전 입구──출구  │
└─────────────────────────────┘
```

**특징:**
- 모든 Location이 2D 좌표를 가짐 (지도 탭에서 공간적 배치)
- 지도 = 최대 줌아웃 상태 고정, 전체 공개
- 한 번의 클릭으로 어디든 이동 가능 (직접 이동)
- 건축 기능으로 Location/Gate 동적 추가 → 마을 복잡도 증가

### Region 1: 자원 채취 필드

마을 외곽. 벌목/채집/낚시 등 자원 획득.

```
마을 출구 ── 숲길 ── 벌목장
                └── 강가 (낚시)
                └── 야생 채집지
```

### 인스턴트 던전

- 시나리오02의 BSP + Bridge 생성 재활용
- 던전 입구 Location에서 진입
- 층별 절차적 생성
- 점진적 돌파 + 실신 트리거 재편성

### 던전 층 구조 (초안, 밸런싱 추후)

총 **20층**. 5층마다 구간 전환.

| 구간 | 층 | 오염도 | 특징 |
|------|-----|--------|------|
| **상층** | 1~5F | 낮음 | 입문, 약한 몬스터, 튜토리얼 구간 |
| **중층** | 6~10F | 보통 | 난이도 상승, 타 파티 조우, 수거반 활동 |
| **하층** | 11~15F | 높음 | 강적, 에로 함정, 체류자 거점 |
| **심층** | 16~20F | 극심 | 관리자 조우, 퍼즐 복잡화, 최종 보스 |

### 보스/숏컷 배치

| 층 | 이벤트 |
|----|--------|
| 5F | 1구간 보스 + **숏컷 해금** (1F↔5F) |
| 10F | 2구간 보스 + **숏컷 해금** (1F↔10F) + **꺾기 이벤트** |
| 15F | 3구간 보스 + **숏컷 해금** (1F↔15F) |
| 20F | **최종 보스** → 엔딩 분기 |

### 오염도 곡선

```
오염도
  │
  │                          ████ 심층
  │                   ███████
  │            ███████        하층
  │      ██████
  │  ████                     중층
  │██
  └──────────────────────── 층
   1F    5F    10F   15F   20F
```

- 상층: 오래 머물어도 여유
- 중층: 장기 체류 시 부식/침식 체감 시작
- 하층: 짧은 휴식만으로는 감당 어려움
- 심층: 매 방 이동마다 침식 체감, 던전의 힘 유혹 극대화

## 마을 지도 시스템

### 기존 던전 지도와의 차이

| 항목 | 던전 지도 (S02) | 마을 지도 (S04) |
|------|----------------|----------------|
| 공개 범위 | 탐사 기반 (어둠) | **전체 공개** |
| 줌 | 다단계 줌 | **최대 줌아웃 고정** |
| 이동 | 인접 이동만 | **한 클릭 = 어디든 이동** |
| 스크롤 | 뷰포트 스크롤 | 불필요 (전체 보임) |
| 동적 변화 | 없음 | **건축으로 Location/Gate 추가** |

### 2D 좌표 배치

- 각 Location이 2D 좌표 (x, y)를 가짐
- Gate 연결이 지도에서 선(경로)으로 표시
- 건축 시 새 Location이 좌표와 함께 추가
- 지도에서 Location 클릭 → 해당 위치로 직접 이동

### Location → 2D 좌표 변환

> Location/Gate 구조를 먼저 만들고, 2D 좌표를 부여하는 방식.
> 수동 배치 또는 Force-Directed 자동 배치 — 추후 결정.

장비가 곧 외형. 대화/모집/거래에 영향:

| prop | 의미 | 발생 조건 | NPC 반응 |
|------|------|----------|---------|
| 피묻음 | 전투/약탈 흔적 | 전투 후, 약탈 후 | 경계, 암시장은 호감↑ |

| 깨끗함 | 세탁/수리 완료 | 세탁/수리 후 | 기본 호감 |

| 상태 | 대응 | 시설 |
|------|------|------|
| 피묻음 | 세탁 | 여관/세탁소 |
| 해짐 | 수리 | 대장간 |
| 부식 | 수리 + 정화 | 대장간 + 정화소 |

### 무게 시스템

캐릭터의 근력에 따라 소지 가능한 총 무게가 결정됨.

| 상태 | 조건 | 효과 |
|------|------|------|
| 여유 | 소지 무게 < 50% | 정상 |
| 적재 | 50~80% | 이동 속도 소폭 감소 |
| 과적 | 80~100% | 이동 속도 대폭 감소, 회피↓ |
| 한계 초과 | 100% 초과 | 이동 불가 (아이템 버려야 함) |

파생:
- 무거운 갑옷 vs 가벼운 가죽 → 방어력/기동력 트레이드오프
- 전리품 많이 주우면 → 무거워짐 → 귀환 느림 → 오염 노출 증가
- 파티원에게 짐 분배 가능 (파티 통합 관리 확장)
- 실신 NPC 운반 = 무게에 포함 → 납치의 물리적 비용

## 클래스/직업 체계

### 구조

```
스킬 셋 (내부 시스템) — 개별 스킬 단위
  └── 클래스 (겉으로 보이는 묶음) = 스킬 셋 조합
      └── 변경 가능 (전직)

던전의 힘 (특수 전용) — 클래스와 무관, 항시 적용
```

```
일반 NPC:  [클래스 스킬 셋]
특수 NPC:  [클래스 스킬 셋] + [던전의 힘 스킬 셋]
플레이어:  [클래스 스킬 셋] + [던전의 힘 스킬 셋]
```

### 클래스 목록 (초안, 명칭 변경 가능)

참고: 메트로 퀘스터 — 판타지와 거리 먼 직업명 (난봉꾼, 순경, 기동대 등)

| 클래스 | 역할 | 스킬 셋 핵심 | 전직 조건 |
|--------|------|------------|----------|
| **척후** | 정찰/회피 | 은신, 함정 감지, 회피 | 민첩 높음 |
| **타격수** | 근접 딜러 | 근접 공격, 연타, 기절 | 근력 높음 |
| **사수** | 원거리 딜러 | 사격, 집중, 관통 | 민첩+지각 |
| **방패잡이** | 탱커 | 방어, 도발, 버티기 | 체력 높음 |
| **약사** | 회복/해독 | 치료, 해독, 항오염제 | 지식 높음 |
| **기술자** | 제작/함정 | 크래프트, 함정 설치, 수리 | 지식+손재주 |
| **거간꾼** | 화술/거래 | 협상, 정보, 강매, 매수 | 화술 높음 |
| **정화사** | 오염 전문 | 정화, 오염 감지, 내오성 부여 | 특수 (희귀) |

### 전직 규칙

- **능력치/성향 기반**: 조건 충족하면 자유 전직
- **타락 방향은 가능, 역방향은 불가**: 약사→거간꾼 OK, 거간꾼→약사 X
- **던전의 힘은 클래스 무관**: 특수 캐릭터는 어떤 클래스든 사용 가능
- 랜덤 NPC 생성 시 능력치 기반 클래스 배정

## 세이브 시스템

| 위치 | 방식 | 슬롯 |
|------|------|------|
| 마을 | 수동 세이브 | **다중 슬롯** (자유 저장/불러오기) |
| 던전 (긴 휴식) | **자동 세이브** | 단일 슬롯 (덮어쓰기) |
| 던전 (그 외) | 세이브 불가 | — |

- 마을에서 다중 세이브 → 다양한 분기/실험 가능
- 던전 긴 휴식 = 자동 세이브 → 게임을 끄고 이어할 수 있음
- 던전 내 수동 세이브 불가 → 세이브/로드 남용 방지, 긴장감 유지
- 플레이어 실신 → 마을 귀환 + 재편성 (자동 세이브 덮어써짐 → 되돌릴 수 없음)

## 마을 ↔ 던전 시간 동기화

S02의 DES(단일 시계)를 그대로 사용. 마을과 던전은 동시에 시간이 흐름.

| 상황 | 마을 | 던전 |
|------|------|------|
| 플레이어 마을 | 시간 진행 (경영/생활/NPC 체류 감소) | 던전 내 NPC/몬스터 시간 경과 |
| 플레이어 던전 | NPC 체류 시간 감소, 경영 수익 발생, NPC 출현/소멸 | 시간 진행 (탐사) |

파생:
- 마을에서 너무 오래 머물면 → 던전 내 실신 NPC가 수거반에 약탈당할 수 있음
- 던전에서 너무 오래 머물면 → 마을 NPC가 체류 만료로 떠남 (모집 기회 손실)
- 경영 시설은 플레이어 부재 중에도 수익 발생 (알바생 고용 시)

## 운반/납치 메카닉

### 운반 기본

S02의 `carry.py` 재활용. 실신 NPC를 물리적으로 운반.

| 항목 | 내용 |
|------|------|
| 운반 주체 | 플레이어 + 파티원 (지시로 위임 가능) |
| 운반 대상 | 실신 NPC (파티/비파티 무관) |
| 무게 | 운반 대상의 체중이 소지 무게에 추가 |
| 슬롯 | 1인당 1명까지 운반 가능 |

### 운반 중 디스어드밴티지

| 페널티 | 내용 |
|--------|------|
| 이동 속도 | 대폭 감소 |
| 함정 감지 | 능력 저하 (운반자 본인) |
| 회피 | 저하 |
| 대결 발생 시 | 운반 대상을 내려놓고 전투 (전투 중 방치) |

### 운반 후 선택지

| 선택 | 조건 | 결과 |
|------|------|------|
| 마을로 귀환 → 구호소 | 없음 | 치료, 답례금, 평판↑ |
| 마을로 귀환 → 감금 | 파티 내 반대 성향 NPC 없을 것 | 조교소에서 조교 가능 |
| 마을로 귀환 → 인신매매 | 파티 내 반대 성향 NPC 없을 것 | 암시장 매각, 고수입, 평판↓↓ |
| 던전 내 방치 | 없음 | 재편성 시 MIA 삭제 |

### 성향 제약

감금/인신매매 등 비도덕 행위는 **파티 내 반대 성향 NPC가 있으면 불가**:
- 해당 NPC가 항의 → 실행 불가
- 강행하려면 먼저 **파티 해제** 필요
- 파티 해제 시 해당 NPC 신뢰↓↓, 목격 시 사기↓↓

### 파티 해제 후 NPC 처리

| 시점 | 상태 |
|------|------|
| 해제 직후 | 마을에 체류 (여관 등) |
| 일정 기간 경과 | 마을을 떠남 → 삭제 |
| "세계의 지식" 보유 시 | 마을 체류 중 혼란도↑ 기여 후 떠남 |

## 조교/복종 메카닉

### S02 시스템 재활용

S02의 복종 시스템을 기반으로 확장. **S02 기능은 삭제하지 않고 유지** (S02에서 역수입 가능).

S02 기존 요소:
- `관계:{name}:복종` prop — 개별 NPC 복종 수치
- 약점 이벤트 → 협박 → 복종↑
- 강제 행위 (romance) → 복종 자연 증가
- 결박 + 회유 → 장기간 복종 축적
- 채찍/성인용품 → 반발+복종 동시 증감
- 복종 임계치 (≥70) → 굴복 루트

### S04 추가 경로: 납치 → 조교소

```
S02 기존: 약점 발견 → 협박 → 강제 행위 → 복종 축적 → 굴복
S04 추가: 실신 납치 → 조교소 감금 → 결박/회유/강제 → 복종 축적 → 파티 편입
```

### 조교소 프로세스

| 단계 | 내용 | 시간 |
|------|------|------|
| 감금 | 조교소에 배치, 결박 상태 | 즉시 |
| 회유/협박 | 대화 선택지 (매일 방문) | 수일 |
| 강제 행위 | romance 시스템 활용 | 방문 시 |
| 방치 | 시간 경과로 소폭 복종↑ | 자동 |
| 편입 판정 | 복종 임계치 도달 → 파티 합류 가능 | — |

### 조교 대상의 저항

| NPC 성향 | 저항도 | 특징 |
|---------|--------|------|
| 순종적 | 낮음 | 빠른 복종, 안정적 |
| 보통 | 보통 | 표준 기간 |
| 반항적 | 높음 | 장기간 필요, 탈출 시도 가능 |
| 야심파 | 극높음 | 겉복종 후 배신 가능 (위장 복종) |

### 조교 실패/리스크

- 장기간 실패 → NPC 사망 (체력 고갈) or 폐인화
- 방치 중 탈출 시도 (결박 강도/감시에 따라)
- 목격자 (파티원/마을 NPC) → 평판↓↓, 신뢰↓↓
- 조교 완료 NPC → 높은 복종, 낮은 자율성, 불복률 극저
  - 단, 야심파 위장 복종 시 → 던전 깊은 곳에서 배신 가능

### S04 확장 요소 (S02에 없는 것)

| 요소 | 내용 | 비고 |
|------|------|------|
| 조교소 시설 | 건축으로 설치, 숨겨진 장소 | 마을 시설 |
| 감금 상태 관리 | 결박 강도, 식사 제공, 감시 수준 | 비용 발생 |
| 탈출 시도 | NPC 근력/의지 vs 결박/감시 | 실패 시 반발↑ |
| 위장 복종 | 야심파 NPC 전용 | 복종 높아 보이지만 실제 낮음 |
| 마을 혼란도 연동 | 조교 행위 발각 시 혼란도↑ | 평판 시스템 |
