## 1. 1D 공간 기반 설계 원칙

### 방(Room)의 구조

```
방 입구(Gate)                                    방 출구(Gate)
  |                                                    |
  X=0 ─────────────────────────────────────────── X=length
        ↑          ↑         ↑          ↑
      함정(30)   오브젝트(120) 적(200)  출구(350)
```

- 방 길이: 100 (좁음) ~ 500 (넓음)
- 오브젝트/이벤트는 **특정 X 좌표에 배치**
- 플레이어가 오브젝트의 X 근처(±20)에 도달하면 **상호작용 가능**
- 은신 판정: 적/함정과의 **X 거리**가 감지 거리 내인지 기준

### 진입 방향과 정보

```
← 왼쪽 Gate에서 진입: X=0부터 시작
→ 오른쪽 Gate에서 진입: X=length부터 시작

진입 시 즉시 보이는 것: 밝기 범위 내 오브젝트
보이지 않는 것: 은신 함정, 잠복 적, 어둠 너머
```

## 2. 방 콘텐츠 유형

### 2.1 함정 (Trap)

**발견 → 회피/해제 → 효과**의 3단계.

| 함정 | X배치 | 감지 | 효과 | 해제 |
|------|-------|------|------|------|
| **압력판** | 통로 중앙 | 민첩 판정 (탐지) | 화살 — HP -15 | 도적: 자동 감지 |
| **독가스 분출** | 벽면 | 시각 (연기 흔적) | 중독 — HP -5/시간, 3시간 | 천으로 막기 (아이템) |
| **함몰 바닥** | 랜덤 | 무게 판정 (장비 무게) | 낙하 — HP -25, 이동 불가 1시간 | 밧줄 (아이템) |
| **소음 함정** | Gate 근처 | 자물쇠 판정 | 큰 소리 — 인접 방 적 소환 | 도적: 해제 가능 |
| **침식 웅덩이** | 바닥 | 시각 (검은 얼룩) | 침식 +10 | 우회 (X 이동으로 피함) |
| **거미줄 벽** | 통로 차단 | 자동 발견 | 이동 불가 — 칼로 절단 필요 | 날붙이 아이템 |
| **환각 포자** | 넓은 방 | 냄새 (정신 판정) | 혼란 — 다음 전투 명중 -20% | 마스크 (아이템) |
| **붕괴 경고** | 보스 방 앞 | 자동 | 30초 타이머 — 통과 or 되돌아감 | 없음 (판단) |

**1D 연동:**
- 함정은 특정 X에 배치
- 플레이어 X가 함정 X ±10 내 진입 시 발동 판정
- 탐지 성공 → 함정 X 표시 (피할 수 있음)
- X 이동으로 물리적 회피 가능 (침식 웅덩이 등)

### 2.2 보물 (Treasure)

**잠금 상태별 보상 차등.**

| 보물 | X배치 | 잠금 | 내용물 | 함정 |
|------|-------|------|--------|------|
| **나무 상자** | 벽면 | 없음 | 소비 아이템 1~2개 | 없음 |
| **철제 상자** | 방 중앙 | 보통 (20) | 장비 or 소재 | 10% 소음 함정 |
| **봉인 상자** | 은밀한 곳 | 복잡 (35) | 희귀 장비 or 다량 소재 | 30% 독가스 |
| **모험가의 배낭** | 랜덤 | 없음 | 소비+소재 혼합, 일기장 | 20% 침식 잔류 |
| **제단 공물** | 특수 방 | 없음 (비용) | 소원 1회 (HP회복/침식감소/정보) | 공물 필요 (아이템 헌납) |
| **미확인 아이템** | 드롭 | - | 감정 전까지 효과 불명 | 저주 가능 (침식 +) |

**모험가의 배낭 — 서사적 가치:**
- 죽은 모험가의 소지품 → 일기장에서 던전 정보 획득 (도감 갱신)
- Veteran Pool에 있던 NPC의 배낭일 수 있음 → "이 배낭... 기억나는 이름이다"
- 침식 잔류: 장기간 던전에 방치된 물건 → 만지면 침식 소량

### 2.3 환경 위험 (Hazard)

**지속적/공간적 위험 — 함정과 달리 1회성이 아님.**

| 위험 | 범위 | 효과 | 대응 |
|------|------|------|------|
| **침수 구간** | X=50~150 (구간) | 이동속도 ×0.5, 횃불 소화 | 우회로 탐색 or 강행 |
| **독기 지대** | 방 전체 | HP -3/분, 체류 시간 = 피해 | 빠르게 통과, 마스크 |
| **암흑 구간** | X=100~ (조명 무효) | 조명 불가, 은신 판정 불리 | 공명충 소재 (발광) |
| **고온 구간** | 방 전체 | 체온 상승, 갑옷 패널티 | 방어구 해제 (리스크) |
| **침식 폭풍** | 방 전체 (일시) | 침식 +3/분, 2~5분간 | 엄폐 (오브젝트 뒤) or 대기 |
| **중력 이상** | 최하층 전용 | 이동 랜덤 방향, X 조작 반전 | 적응 (3회 이동 후 해소) |
| **벽면 눈** | 하층 | 응시당함 — 침식 +1/분 | 시선 차단 (횃불 꺼서 안 보이게) |

**1D 연동:**
- 침수/독기는 **X 구간**으로 정의 → 통과 시간 = 피해량
- 빠른 이동(달리기) → 통과 시간 감소, but 소음 증가
- 느린 이동(은신) → 통과 시간 증가, but 조용

### 2.4 휴식 지점 (Rest Point)

**안전 or 반안전 구간. 자원 소비로 회복.**

| 유형 | 조건 | 효과 | 리스크 |
|------|------|------|--------|
| **안전 방 (Safe Room)** | 문 잠금 가능 | 장 휴식 가능, 침식 -5 | 없음 (보스 전 1회만 등장) |
| **캠프 흔적** | 이전 모험가 흔적 | 단 휴식 가능, 모닥불 잔해 | 25% 적 순찰 중 발견 |
| **수원지** | 물 웅덩이 | 갈증 해소, 물병 충전 | 10% 오염수 (침식 +5) |
| **환기구** | 벽면 틈 | 독기 해소, 신선한 공기 | 소음 전달 (인접 방에 존재 노출) |

**1D 연동:**
- 캠프/수원지는 특정 X에 배치된 오브젝트
- 근접(±15) 시 상호작용 가능
- 캠프 중 적 출현 시 → X 거리에 따라 대응 시간 결정

### 2.5 NPC 조우 (Encounter — 비전투)

**던전 안에서 만나는 살아있는 사람들.**

| 조우 | 확률 | 상호작용 | 결과 |
|------|------|---------|------|
| **다른 모험가 파티** | 15% | 대화/거래/합류 제안 | 정보 교환, 아이템 거래, 임시 동맹 |
| **부상당한 모험가** | 10% | 구출/약탈/무시 | 구출→명성+도덕+, 약탈→아이템+도덕-, 무시→도덕- |
| **떠돌이 상인** | 5% | 매매 | 고가, 희귀 아이템 취급 (횃불/약/자물쇠 도구) |
| **갇힌 포로** | 8% | 구출 (자물쇠) | 구출 시 Veteran Pool 합류 가능 (감사→신뢰 높은 상태) |
| **미친 모험가** | 5% | 대화/전투 | 침식 100+ 상태. 정보 제공 or 공격 (선택에 따라) |
| **Veteran NPC 재회** | 3% | 대화/재합류 | Veteran Pool NPC가 던전에서 등장 |

**1D 연동:**
- NPC는 특정 X에 서있거나 이동 중
- 플레이어와의 X 거리로 감지/대화 범위 결정
- 은신 중이면 NPC도 못 봄 → 몰래 지나가거나 기습 선택

**다른 모험가 파티 — 확장:**
- 세력 성향 (정의/중립/약탈) → creature-system.md의 NPC 파티 참조
- 약탈 성향 파티: PvP 전투 가능
- 정의 성향 파티: 침식체/이형 공동 전투 가능
- 도덕성/명성에 따른 초기 반응 변화

### 2.6 퍼즐/수수께끼 (Puzzle)

**전투 외 두뇌 플레이. 보상이 크다.**

| 퍼즐 | 출현 층 | 방식 | 보상 | 실패 |
|------|---------|------|------|------|
| **돌문 기호** | 상층 | 벽의 기호 3개를 순서대로 터치 | 은밀 방 개방 (보물) | 소음 발생 |
| **무게 저울** | 중층 | 양쪽에 아이템 올려 균형 맞추기 | 비밀 통로 해금 | 아이템 소실 |
| **거울의 방** | 중층 | 거울(이형)에 정답 대화 | 층 지도 공개 + 희귀 아이템 | 전투 돌입 |
| **음파 문** | 하층 | 특정 순서로 소리 발생 (아이템/행동) | 숏컷 문 개방 | 소음 → 적 소환 |
| **기억의 방** | 심층 | 플레이어 과거 행동 기반 질문 | 침식 -20 대량 회복 | 침식 +10 |
| **선택의 방** | 보스 전 | 2개 문 — 하나는 보스, 하나는 보물 | 정보 없으면 50:50 | - |

**1D 연동:**
- 기호/저울 등은 방 내 특정 X에 배치된 오브젝트
- 음파 문: 방 양끝(X=0, X=length)에 공명 장치 → 이동하며 순서대로 활성화

### 2.7 자원 채취 (Gathering)

**소재/소비 아이템 획득. 시간 소비 = 리스크.**

| 자원 | X배치 | 도구 | 시간 | 획득물 | 리스크 |
|------|-------|------|------|--------|--------|
| **벽면 광석** | 벽면 | 곡괭이 | 5분 | 철광석, 희귀 광석 | 소음 → 적 유인 |
| **균류 채집** | 바닥/벽 | 없음 | 2분 | 식용 버섯, 약재 | 10% 독버섯 (HP-10) |
| **물 웅덩이** | 바닥 | 물병 | 1분 | 식수 보충 | 5% 오염 (침식+3) |
| **시체 수색** | 랜덤 | 없음 | 3분 | 아이템/소지금/일기장 | 20% 침식 잔류, 5% 기생충 |
| **결정체** | 중층+ | 없음 | 1분 | 침식 결정 (거래/정화 소재) | 채취 시 침식 +3 |
| **점액충 채취** | 상층 | 용기 | 3분 | 점액 (윤활/접착 소재) | 점액충이 수비로 전환 |

**1D 연동:**
- 채취 지점은 X 좌표에 고정된 오브젝트
- 채취 중 = 해당 X에 정지 → 적 순찰과 조우 가능
- 채취 시간이 길수록 위험 (소음 누적)

### 2.8 이상 현상 (Anomaly) — SCP 영감

**설명할 수 없는 것. 하층/심층 전용.**

| 현상 | 효과 | 대응 |
|------|------|------|
| **시간 정지 구간** | 특정 X 구간에서 시간 멈춤 (이동만 가능) | 통과하면 해제 |
| **반복의 방** | 출구로 나가면 같은 방으로 돌아옴 (3회) | 3번째에 탈출 or 숨겨진 조건 |
| **속삭임** | 방 전체에서 이름을 부름 (침식 +2/분) | 무시하고 빠르게 통과 |
| **사라지는 바닥** | X 좌표가 서서히 줄어듦 (방이 좁아짐) | 빠르게 출구로 |
| **온도 역전** | 횃불이 어둠을, 어둠이 빛을 발함 | 횃불 끄면 밝아짐 |
| **거울상** | 파티원의 복제가 반대쪽에서 걸어옴 | 전투 or 대화 (정답 시 아이템) |
| **글자** | 벽에 메시지 출현 (힌트 or 함정 유도) | 판단 (도감 정보 참조) |

**1D 연동:**
- 사라지는 바닥: `location.length`가 시간에 따라 감소 → Gate X도 변동
- 시간 정지 구간: X=100~200에서 시간 흐름 멈춤 (HP/침식/피로 변동 없음)

## 3. 방 생성 알고리즘

### 3.1 방 유형 결정

방 생성 시 콘텐츠 유형을 확률적으로 결정:

```python
ROOM_CONTENT_WEIGHTS = {
    "empty":     15,   # 빈 방 (이동만)
    "combat":    25,   # 전투 (기존 has_monster)
    "trap":      12,   # 함정
    "treasure":  10,   # 보물
    "hazard":     8,   # 환경 위험
    "rest":       5,   # 휴식 지점
    "npc":        8,   # NPC 조우
    "puzzle":     5,   # 퍼즐
    "gather":    10,   # 자원 채취
    "anomaly":    2,   # 이상 현상 (하층+에서 가중치 상승)
}
```

**층별 가중치 보정:**

| 층 | 보정 |
|----|------|
| 상층 (1~5) | combat -5, trap +5, gather +5, anomaly 0 |
| 중층 (6~10) | combat 기본, npc +5, puzzle +3 |
| 하층 (11~15) | combat +5, hazard +5, anomaly +5 |
| 심층 (16~20) | combat +10, anomaly +10, rest -3 |

### 3.2 방 내 배치

```python
def populate_room(room, floor):
    """방 콘텐츠 배치 — 1D X축 기반"""
    content_type = weighted_random(ROOM_CONTENT_WEIGHTS, floor_modifier(floor))
    length = room["length"]
    
    objects = []
    
    if content_type == "combat":
        # 적: 방 중앙~후반부에 배치
        enemy_x = random.randint(length // 3, length * 2 // 3)
        objects.append({"type": "enemy", "x": enemy_x, ...})
        
    elif content_type == "trap":
        # 함정: 입구~중앙 사이 (진입 시 밟도록)
        trap_x = random.randint(length // 6, length // 2)
        objects.append({"type": "trap", "x": trap_x, ...})
        # 보물: 함정 너머에 배치 (유인)
        if random.random() < 0.4:
            treasure_x = random.randint(trap_x + 30, length - 20)
            objects.append({"type": "treasure", "x": treasure_x, ...})
            
    elif content_type == "treasure":
        # 보물: 방 후반부
        treasure_x = random.randint(length // 2, length - 20)
        objects.append({"type": "treasure", "x": treasure_x, ...})
        
    elif content_type == "gather":
        # 채취: 벽면 (X=10~30 또는 length-30~length-10)
        gather_x = random.choice([
            random.randint(10, 30),
            random.randint(length - 30, length - 10)
        ])
        objects.append({"type": "gather", "x": gather_x, ...})
    
    # ... 기타 유형
    
    room["content"] = content_type
    room["objects"] = objects
```

### 3.3 복합 방

하나의 방에 여러 콘텐츠가 공존:

```
[함정 + 보물] — 함정을 넘어야 보물 도달
[적 + 자원]   — 적을 처리해야 안전하게 채취
[NPC + 위험]  — 독기 지대에 갇힌 NPC 구출
[퍼즐 + 보물] — 퍼즐 풀면 보물 방 개방
```

## 4. 대결 전투 진입 — 1D 공간 연동

### 전투 진입 시점

```
플레이어 X ─────────→ 이동 중
                 ↓
          적 감지 거리 (전투:감지거리) 내 진입
                 ↓
          ┌──────┴──────┐
          │ 은신 판정    │
          ├─ 미감지 → 선제 공격 or 우회 선택
          └─ 감지됨 → 전투 돌입
                         ↓
                  대결 전투 시작
                  (별도 전투 화면)
```

### X 거리 기반 전투 요소

| 요소 | X 연동 | 설명 |
|------|--------|------|
| **선제권** | 감지 시 X 거리 | 거리 > 감지거리×0.8 → 플레이어 선제 |
| **기습** | 은신 + 근접 X | X 차이 < 20 + 은신 성공 → 기습 (1턴 무조건 선제) |
| **도주** | Gate까지 X 거리 | Gate에 가까울수록 도주 성공률 ↑ |
| **잠복 적** | 은신 상태 X | 잠복 적의 X에 도달해야 감지 가능 |
| **군집** | 다중 X | 군집은 X 범위 (±30)에 분산 → 개별 감지 |

### 비전투 해법 분기

```
적 감지
  │
  ├─ 행동 = aggressive → 전투 강제
  │
  ├─ 행동 = defensive
  │    ├─ 공격 → 전투
  │    └─ 무시 (X 우회) → 안전 통과 (적 건드리지 않으면)
  │
  ├─ 행동 = evasive
  │    └─ 도주 시작 → 추격 선택 (민첩 판정)
  │
  ├─ 행동 = ambush
  │    ├─ 탐지 성공 → 전투 or 우회 선택
  │    └─ 탐지 실패 → 기습당함 (적 선제 1턴)
  │
  └─ 행동 = special (이형)
       └─ 대화/퍼즐/도주 선택지
```

## 5. 시간/자원 압박 시스템 — 4개의 타이머

**"던전에 오래 있을수록 위험하다"**

던전 체류 중 4개의 자원이 동시에 소모된다.
**가장 먼저 바닥나는 것이 귀환 시점을 결정한다.**

```
식량 ────→ 바닥나면 HP 감소 ──→ 사망
피로 ────→ 기절하면 무방비 ──→ 습격/사망
침식 ────→ 200 도달 ─────────→ 즉사
횃불 ────→ 소진되면 암흑 ──→ 전투 불리
```

### 5.1 포만감 (식량 압박)

시간 경과: **-10/시간 (파티원 전원 개별 소모)**

| 포만감 | 상태 | 전투 효과 | 기타 |
|--------|------|----------|------|
| 80~100 | 포식 | 없음 | |
| 50~79 | 보통 | 없음 | |
| 20~49 | 공복 | 공격력 -10% | 배 소리 → 은신 판정 불리 |
| 1~19 | 기아 | 공격력 -25%, 민첩 -20% | 채취/퍼즐 시간 ×1.5 |
| 0 | 아사 위기 | HP -5/시간 | 전투 불가 (도주만) |

**의사결정: "식량을 얼마나 가져갈 것인가"**
- 인벤토리 슬롯 유한 → 식량 vs 횃불 vs 도구 vs 빈 칸(드롭용)
- 파티 4인이면 소비 ×4 → 깊은 층 = 식량 대량 필요
- 던전 내 식용 버섯 채취 = 보조 수단 (10% 독버섯 리스크)
- 마을 식량 가격 vs 인벤토리 공간 트레이드오프

### 5.2 피로 (체력 소진 → 강제 휴식)

시간 경과: **+5/시간, 전투 시 +15/회**

| 피로 | 상태 | 전투 효과 | 기타 |
|------|------|----------|------|
| 0~30 | 쾌적 | 없음 | |
| 31~60 | 피곤 | 회피 -10% | |
| 61~80 | 탈진 직전 | 회피 -25%, 명중 -15% | 함정 감지 실패율 ↑ |
| 81~99 | 탈진 | 전투 속도 ×0.5 | 은신 불가, 채취 불가 |
| 100 | 기절 | **그 자리에서 강제 수면** | 무방비 → 적 순찰 시 습격 대상 |

**의사결정: "언제 쉴 것인가"**
- 전투 3~4회 후 휴식 필요
- 안전 방 (확실, 희소) vs 캠프 흔적 (25% 발견 리스크)
- 피로 100 기절 = 최악 (위치 선택 불가, 무방비)
- 보초 = 파티원 1명 피로 미회복 (보초 인원 트레이드오프)

### 5.3 침식

시간 경과: **+1/시간 (상층), +3/시간 (중층), +5/시간 (하층), +8/시간 (심층)**

| 침식 | 상태 | 효과 |
|------|------|------|
| 0~49 | 안전 | 없음 |
| 50~99 | 경고 | 기벽 발현 확률 ↑, 손 떨림 (자물쇠 -5) |
| 100~149 | 위험 | 후천적 기벽 획득, 전투 시 혼란 5% |
| 150~199 | 임계 | 기벽 악화, 도덕성 하락 경향, NPC 불안 (사기-) |
| 200 | 침식사 | 즉사 → 리셋 |

**의사결정: "얼마나 깊이 갈 것인가"**
- 정화소 비용 = 침식 관리 비용
- 침식 결정(소재) 채취 = 침식 +3 but 고가 거래품
- 심층은 체류 자체가 시간 싸움

### 5.4 조명 (횃불/랜턴)

| 광원 | 지속 | 밝기 | 비고 |
|------|------|------|------|
| 초 | 2시간 | 0.3 | 싸고 가벼움, 어둡고 짧음 |
| 횃불 | 6시간 | 0.5 | 기본 선택 |
| 랜턴 | 12시간 | 0.7 | 비쌈, 기름 보충 가능 |
| 없음 | - | 0.0 | 암흑: 은신 유리, 전투 불리, 그림자(이형) 활성화 |

**의사결정: "밝게 갈 것인가, 어둡게 갈 것인가"**
- 밝음 → 함정 탐지 ↑, 전투 유리, but 적 감지 ↑ (은신 불리)
- 어둠 → 은신 유리, but 함정 밟음, 그림자 출현, 전투 불리
- 광원 복수 보유 = 인벤토리 압박

### 5.5 종합 — 체류 시간 시뮬레이션

```
F1 기준 (상층):
  식량 10개 (1개=포만감 30 회복) → 파티 4인 × 10시간분
  횃불 2개 → 12시간
  피로 → 전투 4회 + 6시간 = 피로 80 (탈진 직전)
  침식 → 10시간 × 1/h = 10 (안전)

  → 약 8~10시간 탐사 가능 (피로가 제한 요인)

F10 기준 (중층):
  같은 준비물
  침식 → 8시간 × 3/h = 24 (안전하지만 누적)
  피로 → 전투 5회 + 5시간 = 100 (기절!)
  
  → 약 5~6시간 탐사 (피로+침식 이중 압박)

F20 기준 (심층):
  침식 → 3시간 × 8/h = 24 (빠르게 누적)
  모든 자원 빠르게 소모
  
  → 약 2~3시간이 한계 (숏컷 필수)
```

**핵심 의사결정: "한 방 더 갈 것인가, 돌아갈 것인가"**

- 채취/탐색에 시간 쓰면 → 자원 획득 but 4개 타이머 모두 진행
- 빠르게 통과하면 → 안전 but 보물/소재 놓침
- 마을 창고에 보관 = 유일한 영구 자산 → **"언제 돌아갈 것인가"**

### 5.6 기타 시간 경과

| 요소 | 효과 |
|------|------|
| 적 재생 | 처치한 적: 6시간 후 리스폰 (같은 방 재방문 시) |
| 순찰 적 | 시간 경과 → 빈 방에 적 순찰 확률 ↑ |
| NPC 체력 | 파티원도 동일한 포만감/피로 소모 |

## 6. 도감 연동

비전투 콘텐츠에서도 도감이 갱신된다:

| 발견 | 도감 갱신 |
|------|----------|
| 함정 경험 | 함정 유형 등록 → 재방문 시 감지 보너스 |
| 모험가 배낭 일기장 | 생물/함정/층 정보 추가 |
| NPC 정보 교환 | 특정 층/보스 약점 정보 |
| 퍼즐 해결 | 퍼즐 유형 등록 → 유사 퍼즐 힌트 |
| 이상 현상 경험 | 현상 패턴 등록 → 재발 시 대응 가능 |
| 채취 | 소재 도감 등록 → 크래프팅 레시피 연계 |

**도감 = 영구 자산. 죽어도 남는다.**
"정보를 모으는 것 자체가 진행"
