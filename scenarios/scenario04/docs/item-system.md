# S04 아이템/장비 진행 체계

> 상태: 설계 단계 (미구현)
>
> 핵심: **런 내 장비는 소모품이다. 마을에 축적한 소재만이 영구 자산.**

---

## 설계 원칙

**"던전에서 얻은 것은 던전에서 잃는다. 마을로 가져온 것만 남는다."**

- 장비: 런마다 소실 (사망 시). 강화보다 **교체 사이클**이 핵심
- 소재: 마을 창고 보관 = 영구. 크래프팅의 원재료
- 소비: 던전 내 즉시 사용. 식량/횃불/약/도구
- 정보: 도감/레시피 = 영구. 죽어도 남는 가장 귀한 자산

## 1. 아이템 분류

| 카테고리 | 사망 시 | 예시 |
|---------|---------|------|
| **장비 (Equipment)** | 소실 | 무기, 방어구, 액세서리 |
| **소비 (Consumable)** | 소실 | 식량, 약, 횃불, 자물쇠 도구 |
| **소재 (Material)** | 인벤토리→소실, 창고→유지 | 광석, 가죽, 점액, 침식 결정 |

| **정보 (Info)** | **영구** | 일기장, 지도 조각, 레시피 |

## 2. 장비 체계

### 2.1 장비 슬롯

| 슬롯 | 효과 | 예시 |
|------|------|------|
| 무기 (weapon) | 공격력, 공격속도, 사거리 | 단검, 도끼, 활, 지팡이 |
| 머리 (head) | 방어력, 특수 효과 | 가죽 모자, 철 투구, 채굴 모자(밝기+) |
| 몸통 (torso) | 방어력, 보온 | 가죽 갑옷, 사슬 갑옷, 로브 |
| 하의 (legs) | 방어력, 이동속도 | 가죽 바지, 철 다리보호대 |
| 신발 (feet) | 이동속도, 함정 감지 | 가죽 부츠, 철 장화, 도적의 신발 |
| 액세서리 (accessory) | 특수 효과 | 반지, 부적, 마스크 |

### 2.2 장비 등급

| 등급 | 출처 | 내구도 | 비고 |
|------|------|--------|------|
| **조잡 (Crude)** | 사망 후 기본 지급, 잡화점 | 낮음 | 최저 스탯 |
| **보통 (Common)** | 잡화점, 상층 드롭 | 보통 | 기본 성능 |
| **양품 (Fine)** | 대장간 제작, 중층 드롭 | 높음 | 스탯 +20% |
| **명품 (Superior)** | 대장간 제작 (희귀 소재), 하층 드롭 | 매우 높음 | 스탯 +40%, 특수 효과 |
| **유물 (Relic)** | 보스 드롭, 심층 보물 | 무한 | 고유 효과, 극히 희귀 |

### 2.3 부식 (Corrosion) — 내구도 대체

**침식 환경이 장비를 갉아먹는다.**
내구도가 아닌 **부식** — 세계관과 일치하는 장비 열화 시스템.

```
부식도: 0~100
- 던전 체류: +1/시간 (상층), +2/시간 (중층), +3/시간 (하층), +5/시간 (심층)
- 침식체 피격: +3~5/회
- 침식 웅덩이 접촉: +10
- 부식 30 이상 → "부식됨" (성능 -15%)
- 부식 60 이상 → "심하게 부식됨" (성능 -35%)
- 부식 100 → 붕괴 (소멸)
```

**수리 (부식 제거):**
- 대장간: 부식 0으로 복구 (비용 = 등급 비례)
- 녹 제거제 (소비 아이템): 부식 -20 (던전 내 사용)
- 유물 등급: 부식 속도 ×0.3 (느리게 부식)

**부식은 침식의 물질적 표현** — 플레이어의 침식이 정신을 갉아먹듯, 부식은 장비를 갉아먹는다.

### 2.4 외관 상태 (Visual State)

장비에 누적되는 시각적 상태. **전투 성능에 영향 없음.**
비전투 상호작용 (대화, NPC 반응, 수치심)에 영향.

| 상태 | 원인 | 제거 | 효과 |
|------|------|------|------|
| **피 (Blood)** | 전투 (피격/처치) | 세탁, 물 사용 | NPC 경계/공포. 도덕 인식에 영향 |
| **더러움 (Filth)** | 던전 환경, 점액, 진흙 | 세탁, 물 사용 | NPC 경멸. 상점 가격 불리 |
| **찢어짐 (Torn)** | 전투 피격 (확률), 함정 | 수선 (대장간/재봉) | **노출 발생** → 수치심/성욕 연동 |
| **젖음 (Wet)** | 침수 구간, 물 | 시간 경과 (자연 건조) | 보온 ↓, 체온 하락 |

```
전투 피격 시:
  - 피 묻음: 항상
  - 찢어짐: 피격 대미지 > 방어력×0.5 → 20% 확률
  - 방어구 부위별: 피격 부위의 장비에 적용

찢어짐 누적:
  찢어짐 0: 정상
  찢어짐 1: 약간 해짐 (미관 불량)
  찢어짐 2: 심하게 찢어짐 (노출 발생)
  찢어짐 3: 거의 넝마 (높은 노출)
```

### 2.5 노출 (Exposure) → 수치심/성욕 연동

**찢어진 장비 → 신체 노출 → 본인 수치심 + 주변 성욕에 영향.**

노출도 계산:
```
exposure = Σ(각 장비 슬롯의 찢어짐 레벨) + 미착용 슬롯 × 3
```

| 노출도 | 상태 | 수치심 영향 | 성욕 영향 |
|--------|------|-----------|----------|
| 0~2 | 정상 | 없음 | 없음 |
| 3~5 | 약간 노출 | 수치심 높은 캐릭터: 불편 | 주변 NPC libido +0.05 |
| 6~8 | 상당 노출 | 대화 선택지 제한 (부끄러움) | 주변 NPC libido +0.1 |
| 9+ | 심한 노출 | 공공장소 행동 제약, NPC 반응 극단 | 주변 NPC libido +0.2, 야간 습격 확률 ↑ |

**수치심 (Shame) — 자기 자신에 대한 가이드레일:**

| 범위 | 등급 | 행동 특성 |
|------|------|----------|
| 80~100 | 수줍음 (Shy) | 노출 극도 거부, 알몸 패닉, 성적 행위 거부 |
| 50~79 | 보통 (Normal) | 노출 불편, 공공장소 자제 |
| 20~49 | 대담 (Bold) | 약간 노출 무시, 성적 행위 수용 |
| 0~19 | 무감각 (Numb) | 노출 무관심, 어떤 상태든 행동 제약 없음 |

수치심 변동:
| 이벤트 | 수치심 변화 |
|--------|-----------|
| 노출 상태로 대화 | 수치심 높으면 -2 (적응), 낮으면 변동 없음 |
| 타인에게 알몸 목격 | -5 (충격) |
| 성적 행위 (합의) | -3 |
| 성적 행위 (비합의/습격) | -10 (큰 충격) |
| 깨끗한 옷 착용 후 시간 경과 | +1/일 (회복) |
| 침식 100+ | 수치심 하락 경향 (-1/일) — 던전이 감각을 무디게 함 |

**수치심 × 도덕성 비교:**

| | 도덕성 (Morality) | 수치심 (Shame) |
|---|---|---|
| 대상 | 타인에 대한 행위 | 자기 자신의 상태 |
| 예시 제약 | 도둑질, 살인, 매춘 거래 | 노출, 성적 노출, 공공장소 행위 |
| NPC에도 적용 | O (NPC 도덕성) | O (NPC 수치심) |
| 침식 영향 | 하락 경향 | 하락 경향 |

**성욕 연동:**

노출은 본인과 주변 모두에게 성욕 자극:
```
본인:
  수치심 높음 + 노출 → 불안/스트레스 (성욕 억제)
  수치심 낮음 + 노출 → 해방감 (성욕 소폭 상승)

주변 NPC:
  NPC.orientation이 노출자 성별과 일치 → libido 상승
  NPC.orientation 불일치 → 무반응
  NPC.morality 높음 → "눈을 돌림" (libido 억제)
  NPC.morality 낮음 → "훑어봄" (libido 추가 상승)
```

야간 습격 확률에도 반영:
```
rest_ambush_modifier = 1.0 + (party_max_exposure / 9) × 0.5
# 노출도 9 → 습격 확률 ×1.5
```

### 3.4 인벤토리 제한

```
플레이어: 20 슬롯 (장비 착용 슬롯 별도)
NPC 파티원: 10 슬롯
```

**슬롯 전략:**
- 식량 6~8 + 횃불 2~3 + 도구 2~3 = 기본 12~14슬롯 소비
- 남는 6~8슬롯 = 드롭/소재용 빈 칸
- 파티원에게 분산 가능 (NPC 10슬롯 활용)
- **빈 칸 없이 가면 → 보물 발견해도 가져갈 수 없음**

## 5. 크래프팅 (마을 대장간)

### 5.1 제작 구조

```
소재 + 소재 + (기존 장비) → 신규 장비
                              │
                         레시피 필요 (영구 해금)
```

**레시피 획득:**
- 던전 내 일기장/서적 발견
- NPC 정보 교환
- 대장간 연구 (소재 투입 → 확률적 발견)
- 보스 처치 보상

### 5.2 제작 예시

| 결과물 | 소재 1 | 소재 2 | 기타 | 비용 |
|--------|--------|--------|------|------|
| 철검 (보통) | 철광석 ×3 | - | - | 500 |
| 가죽 갑옷 (보통) | 쥐가죽 ×5 | 거미실 ×2 | - | 800 |
| 흑철 도끼 (양품) | 흑철 ×4 | 쥐가죽 ×2 | 철검 (강화 베이스) | 2000 |
| 심층강 검 (명품) | 심층강 ×3 | 흑철 ×2 | 흑철 도끼 (강화 베이스) | 5000 |
| 발광석 (도구) | 공명 수정 ×2 | 점액 ×1 | - | 3000 |
| 해독제 | 약초 ×2 | 점액 ×1 | - | 100 |
| 정화약 | 침식 결정 ×1 | 약초 ×3 | - | 500 |

### 5.3 강화 경로

```
조잡 → 보통: 기본 소재
보통 → 양품: 중급 소재 + 보통 장비
양품 → 명품: 상급 소재 + 양품 장비
유물: 제작 불가. 보스 드롭 또는 고대 파편으로 복원.
```

**강화 = 새 장비 제작 (기존 장비 소비)**
"강화"라기보다 "재단조" — 기존 장비를 녹여서 상위 장비를 만든다.

## 6. 마을 시설과 아이템 경제

### 6.1 시설별 역할

| 시설 | 기능 | 핵심 서비스 |
|------|------|------------|
| **잡화점** | 소비/도구 판매 | 식량, 횃불, 도구 구매. 소재 매입 |
| **대장간** | 장비 제작/수리 | 크래프팅, 내구도 복구. 소재 분해 |
| **여관** | 숙박/식사 | 장 휴식, 도시락 구매, NPC 만남 |
| **구호소** | HP/상태이상 치료 | 전투 후 치료, 사망 후 부활 지점 |
| **정화소** | 침식 제거 | 침식 결정 납품, 정화 서비스 |
| **술집** | 정보/매춘/의뢰 | 소문 수집, 모험가 조우, 도감 힌트 |

### 6.2 가격 밸런스

**수입원:**
- 소재 판매 (잡화점): 시세 = 소재 등급 × 0.7 (매입가)
- 배회자 장비 분해 → 소재 회수
- 침식 결정 납품 (정화소): 고가
- 퀘스트 보상

**지출처:**
- 식량/도구 구매: 매 런 필수
- 장비 제작/수리: 성능 유지
- 구호소/정화소: 회복
- NPC 모집비: 10K~50K
- 마을 시설 확장 (향후)

**밸런스 목표:**
- F1~5 런: 약간의 이익 (소재 > 소비)
- F6~10 런: 손익 분기 (좋은 소재 = 큰 이익, 실패 = 적자)
- F11+ 런: 고위험 고수익
- 사망 = 전액 소실 → **창고 보관이 유일한 보험**

## 7. 정보 아이템 (영구)

| 아이템 | 출처 | 효과 |
|--------|------|------|
| 일기장 | 모험가 배낭, 시체 | 생물 도감 갱신, 층 힌트 |
| 지도 조각 | 보물, 퍼즐 보상 | 해당 층 방 배치 일부 공개 (다음 런에서) |
| 레시피 | 서적, NPC 정보, 보스 보상 | 크래프팅 영구 해금 |
| 연구 노트 | 심층 보물 | 생물 약점 등록 (전투 보정) |

**사망 시에도 유지** — 인벤토리에서 자동으로 마을 도서관에 등록.
"죽었지만 정보는 가져왔다" = 실패한 런에도 의미 부여.

## 8. 런 준비 체크리스트 (게임플레이 루프)

```
마을에서:
  1. 장비 확인/제작/수리 (대장간)
  2. 소비 구매 (잡화점)
     - 식량: 파티원 수 × 예상 시간 ÷ 포만감
     - 횃불: 예상 시간 ÷ 지속시간
     - 도구: 자물쇠/밧줄/마스크/약
  3. 인벤토리 정리
     - 빈 칸 확보 (드롭용)
     - 소재 → 창고 보관 (보험)
     - 소지금 → NPC 위탁 or 은행 (보험)
  4. 파티 편성 (여관)
  5. 정보 확인 (도감/게시판)

던전에서:
  6. 탐사 + 자원 수집
  7. 4개 타이머 모니터링
  8. "한 방 더?" 의사결정
  9. 귀환 결정 → 마을 복귀

마을 복귀:
  10. 소재 → 창고 (영구화)
  11. 치료/정화 (구호소/정화소)
  12. 장비 수리 (대장간)
  13. 정보 등록 (자동)
  → 1로 돌아감
```

## 9. 구현 우선순위

| 순위 | 작업 | 이유 |
|------|------|------|
| 1 | 인벤토리 슬롯 제한 (20/10) | 자원 압박의 기반 |
| 2 | 기본 소비 아이템 (식량 3종, 횃불, 붕대) | 최소 런 루프 |
| 3 | 장비 슬롯 + 조잡/보통 장비 | 전투 연동 |
| 4 | 마을 창고 (아이템 보관) | 로그라이트 핵심 |
| 5 | 소재 드롭 (상층 생물 4종) | 수집 동기 |
| 6 | 부식 + 외관 상태 + 수치심 | 장비 열화 + 비전투 영향 |
| 7 | 대장간 크래프팅 (기본 레시피 5종) | 진행 체감 |
| 8 | 잡화점 매입/매출 | 경제 순환 |
| 9 | 정보 아이템 + 도감 | 메타 진행 |
| 10 | 장비 등급 확장 (양품/명품/유물) | 깊은 층 동기 |
