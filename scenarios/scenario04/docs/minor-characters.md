# S04 마이너 고정 캐릭터 계획

## 정의

**마이너 고정 캐릭터** = 파티원/리더로 합류 가능한 **고정 개성 NPC**. 랜덤 생성(`npc_generator.py`)과 달리 이름·성별·스탯·성향·배경이 세션마다 동일.

| 구분 | 수 | 비고 |
|-----|---|------|
| 메이저 정규 NPC | 4~5명 | 메인 스토리 분기 담당 (A 카엘 / B 도현 / C 레이 / D 유이) |
| **마이너 고정 NPC** | **목표 25명 전후** | 본 문서의 대상. 사이드 파티 후보 |
| 랜덤 NPC | 가변 | 매번 달라지는 배경 파티 후보 |

## 역할

- 플레이어 경로 6종 (쫄다구/범죄/배신/승계/연애/치정)에 어울리는 다양한 파트너 제공
- 반복 플레이에서 "어, 그 사람 또 왔네" 체감 형성
- 마을 여관/던전 내 조우 등 다양한 등장 지점

## 분포 체크

- **클래스**: 타격수 4 / 사수 3 / 방패잡이 3 / 척후 4 / 약사 3 / 기술자 3 / 거간꾼 3 / 오염술사 2 = 25
- **성별**: 남 13 / 여 12
- **성향 다양성**: 충성/탐욕/야심/이탈/순진/폭력/내성적/고독 등 적절히 섞음
- **경로 지원**: 연애 가능 후보 다수 (4, 14, 18, 24 등), 배신 위험 (5, 10, 15, 17), 리더 후보 (3, 12, 19) 등

## 데이터 포맷 (예정)

`assets/characters/minor/` 디렉토리에 파일별 구현 예정:

```python
# assets/characters/minor/npc_raon.py
class NpcRaon(Character):
    unique_id = "minor_raon"
    name = "라온"
    base_str, base_agi, base_vit, base_mnd = 14, 11, 13, 8
    character_class = "타격수"
    self_tags = {"sex:male", "age:adult", "species:human"}
    preferences = {"sex:female"}
    aversions = set()
    # 성향
    props = {
        "성격": "호쾌",
        "성별": "남",
        "성향:공격성": 0.5,
        "성향:탐욕": 0.3,
        "성향:충성성향": 0.4,
        "성향:도덕성": 10,
        "성향:독립성": 0.3,
    }
    # 등장
    spawn_region = 0    # 마을 (여관)
    spawn_location = 1
```

## 우선순위

1차: 5~10명 구현 (각 클래스 1명씩 대표)
2차: 나머지 15명 점진 추가
3차: 수인/오염술사 등 특수 캐릭터

현재는 **계획 단계** — 구체 스탯/대사는 구현 직전 확정.
