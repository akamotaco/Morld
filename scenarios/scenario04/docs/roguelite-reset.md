# S04 로그라이트 리셋 명세

> 상태: 설계 단계 (미구현)

---

## 기본 정책

**"플레이어는 모든 것을 잃지만, 세상은 기억한다."**

- 플레이어 소유물: **전부 소실**
- 사망 후 기본 장비 지급 (알몸 방지)
- 마을/NPC/관계/시설: **전부 유지**
- 던전: **구조 재생성** (시드 변경)

---

## 1. 사망 트리거

| 트리거 | 조건 | 비고 |
|--------|------|------|
| 전투 사망 | HP ≤ 0 | 가장 빈번 |
| 침식사 | erosion ≥ 200 | 점진적, 예측 가능 |
| 즉사 트랩 | 구멍(The Hole) 접촉 등 | 드물지만 즉각적 |

**모든 사망 트리거는 동일한 리셋 절차를 밟는다.**
차이 없음 — 죽음은 죽음이다.

## 2. 리셋 대상 (소실)

### 2.1 플레이어 상태

| 항목 | 처리 | 비고 |
|------|------|------|
| HP | → 최대체력 | 완전 회복 |
| 포만감 | → 80 | 기본값 |
| 침식 | → 0 | 완전 해소 |
| 피로 | → 0 | 완전 회복 |
| 상태이상 | → 전부 해제 | 기벽 포함 (후천적 기벽 소실) |
| 소지금 | → 0 | **전액 소실** |
| 도덕성 | → +20 (기본값) | 내면 리셋 (로그라이크) |
| 수치심 | → 70 (기본값) | 내면 리셋 |
| 스탯 (STR/AGI/VIT/MND) | → 기본값 | 레벨 1로 리셋 |
| 레벨 | → 1 | 경험치 0 |
| 직업 | → 유지 | 직업 선택은 유지 (재선택 가능?) |

### 2.2 플레이어 소지품

| 항목 | 처리 | 비고 |
|------|------|------|
| 장착 장비 | **소실** | 무기/방어구/액세서리 전부 |
| 인벤토리 | **소실** | 소비/소재/도구 전부 |
| 자물쇠 도구 | **소실** | |
| 횃불/랜턴 | **소실** | |

### 2.3 사망 후 기본 지급 (알몸 방지)

```
지급 아이템:
- 낡은 상의     (방어력 1, 보온 0)
- 낡은 하의     (방어력 1, 보온 0)
- 낡은 신발     (방어력 0)
- 조잡한 단검   (공격력 3)    ← 직업 무관 공용 무기
- 초 1개        (밝기 0.3, 지속 2시간)
```

**지급 기준: "구호소에서 준 최소한의 물품"**
스토리적으로 구호소가 시신을 수습하고 최소 장비를 제공하는 설정.

### 2.4 던전

| 항목 | 처리 | 비고 |
|------|------|------|
| 던전 구조 | **재생성** | 시드 변경, 방 배치 새로 |
| 몬스터 배치 | **재생성** | 스포너 재등록 |
| 바닥 아이템 | **재생성** | 이전 런의 드롭 소실 |
| 보스 처치 상태 | **리셋** | 보스 부활 |

### 2.5 파티

| 항목 | 처리 | 비고 |
|------|------|------|
| 파티 편성 | **해산** | 전원 여관 복귀 |
| 파티원 HP/침식/피로 | **회복** | 파티원도 구호소 치료 설정 |
| 파티원 소지품 | **파티원이 보유** | 플레이어 것만 소실 |
| 파티원 후천적 기벽 | **유지** | NPC의 기벽은 관계의 일부 |

## 3. 유지 대상 (영구)

### 3.1 마을

| 항목 | 유지 | 비고 |
|------|------|------|
| 건물/시설 | O | 건축한 시설 유지 |
| 시설 레벨/업그레이드 | O | 투자한 발전 유지 |
| 상점 재고 | O | (재입고 타이머도 유지) |
| 마을 NPC (고정) | O | 대장장이, 상인 등 |

### 3.2 NPC 관계

| 항목 | 유지 | 비고 |
|------|------|------|
| NPC 존재 | O | 여관에 있던 NPC 유지 |
| 신뢰 (trust) | O | 쌓은 관계 유지 |
| 사기 (morale) | O → 보정 | 플레이어 사망 목격 시 -10 |
| NPC 도덕성/성향 | O | 내면 불변 |
| NPC 장비/아이템 | O | NPC 소유물 유지 |
| NPC 침식 | O → 감소 | 마을 귀환으로 -20 자연 회복 |
| NPC 후천적 기벽 | O | 경험의 일부 |
| 적대/우호 관계 | O | NPC 간 관계 유지 |

**특수: 파티원 사망 시**
- 던전에서 NPC 파티원이 사망한 경우 → NPC 소멸 (영구 사망)
- 플레이어 사망으로 인한 해산 → NPC 생존 (여관 복귀)
- "플레이어가 죽었다"는 사실을 NPC가 인지 → 대사/반응 변화

### 3.3 명성/도덕성

| 항목 | 유지 | 비고 |
|------|------|------|
| 명성 (fame) | O | 죽어도 소문은 남음 |
| 도덕성 (morality) | O | 내면 불변 |

**명성 특수 처리:**
- 사망 횟수가 누적되면 명성에 부정적 태그 추가
  - 1~2회: 영향 없음
  - 3~5회: "운 없는 모험가" (NPC 동정)
  - 6회+: "죽음의 단골" (NPC 경계 — 같이 가면 죽는다는 인식)

### 3.4 메타 진행

| 항목 | 유지 | 비고 |
|------|------|------|
| 숏컷 해금 (F5/F10/F15) | **X** | 로그라이크 — 매 런 다시 해금 |
| 도감 (발견한 생물) | O | 정보 = 영구 자산 |
| 최고 도달 층 기록 | O | 기록 게시판 |
| 사망 횟수 | O | 통계 |
| 레시피 해금 | O | 크래프팅 레시피 발견 → 영구 |
| 지도 데이터 | X | 던전 재생성으로 무의미 |

### 3.5 마을 창고/예치

| 항목 | 유지 | 비고 |
|------|------|------|
| 마을 창고 아이템 | O | **런 전에 보관 = 안전** |
| 대장간 맡긴 장비 | O | 수리/강화 중이던 것 유지 |

**이것이 로그라이트 핵심 전략:**
- 좋은 소재를 얻으면 → 마을로 돌아가서 창고에 보관
- 욕심 부려서 더 깊이 가면 → 사망 시 전부 소실
- **"언제 돌아갈 것인가"가 핵심 의사결정**

## 4. 리셋 절차 (구현 순서)

```
사망 트리거 발생
  │
  ├─ 1. 사망 연출
  │    - 화면 암전
  │    - "당신은 의식을 잃었다..." 텍스트
  │    - (침식사: "던전이 당신을 삼켰다...")
  │
  ├─ 2. 파티 처리
  │    - party.reset()
  │    - 생존 파티원 → 마을 여관 텔레포트, HP/침식 회복
  │    - 사망 파티원 → 영구 소멸 (NPC 삭제)
  │    - 생존 파티원 사기: 플레이어 사망 목격 -10, 동료 사망 목격 -15
  │
  ├─ 3. 던전 리셋
  │    - dungeon.reset() (구조 소멸)
  │    - spawner 소스 전부 해제
  │    - 던전 region 삭제
  │
  ├─ 4. 플레이어 리셋
  │    - 인벤토리 전체 삭제
  │    - 장착 장비 전체 해제 + 삭제
  │    - HP/포만감/침식/피로 → 기본값
  │    - 상태이상/후천적 기벽 해제
  │    - 소지금 → 0
  │    - 기본 장비 지급
  │
  ├─ 5. 플레이어 텔레포트
  │    - 위치: 마을 구호소 (Region 0, Location 5)
  │
  ├─ 6. 메타 데이터 갱신
  │    - 사망 횟수 +1
  │    - 사망 명성 태그 갱신
  │    - 도감 변동 없음 (이미 반영됨)
  │
  ├─ 7. NPC 스케줄 리셋 + 시간 유지
  │    - NPC 스케줄: 리셋 (현재 활동 중단 → 기본 루틴 복귀)
  │    - 게임 시간: 유지 (마을 발전과 마찬가지로 시간은 되돌리지 않음)
  │    - 사망 → 구호소 도착까지 24시간 경과
  │    - 떠돌이 NPC 체류 카운터: 계속 진행 (시간 유지이므로)
  │
  └─ 8. 게임 재개
       - 구호소에서 눈을 뜸
       - "...여기는 구호소인가." 대사
       - 자유 행동 시작
```

## 5. 엣지 케이스

### 5.1 NPC 파티원 사망 (던전 내)

```
NPC HP ≤ 0 (던전 내)
  │
  ├─ 전투 중: party.handle_faint() → 파티 이탈
  │    - NPC는 해당 방에 잔류 (실신 상태)
  │    - 플레이어가 생존하여 귀환:
  │         → 실신 NPC는 던전에 남겨짐
  │         → 24시간 경과 후: 영구 사망 (구조 실패)
  │         → 또는 플레이어가 돌아가서 구출 (구호소로 이송)
  │
  ├─ 플레이어도 사망: 리셋 절차
  │    → 해당 런의 사망 NPC: 영구 소멸
  │    → 생존 NPC: 마을 여관 복귀
  │
  └─ 특수 NPC (스토리 NPC):
       → 사망 대신 "행방불명" 상태
       → 특정 조건 달성 시 재등장 가능 (퀘스트)
```

**NPC 영구 사망 있음.**
던전에서 NPC가 사망하면 해당 NPC는 소멸한다.
- 플레이어 리셋에 포함 — 플레이어 사망 시 같이 죽은 파티원도 영구 소멸
- 소지품/장비도 함께 소멸
- 여관에 새로운 떠돌이가 채워짐 (npc_generator)
- **특수 NPC는 예외 처리 가능** (스토리 NPC 등 — 부활/구조 분기)

영구 사망의 의미:
- "이 사람과 깊은 층에 갈 것인가" 긴장감
- 마을 NPC 풀이 서서히 교체됨
- 오래 함께한 NPC일수록 잃었을 때 타격 (신뢰/명성 하락)

### 5.2 헤어진 NPC 생존 시스템 (Veteran Pool)

파티에서 이탈하거나 헤어진 NPC는 즉시 소멸하지 않는다.
**Veteran Pool**에 저장되어 마을에 재등장할 수 있다.

```
파티 이탈/해산
  │
  └─ NPC → Veteran Pool에 저장
       - 스탯 스냅샷 (현재 상태 그대로)
       - 관계 데이터 (trust/morale)
       - 후천적 기벽
       - 장비/아이템
       - expiry_timer 설정 (기본 168시간 = 7일)
```

**재등장 규칙:**
- 여관에 빈 자리가 있을 때 → Veteran Pool에서 우선 등장 (신규 랜덤보다 우선)
- 등장 시 대사: "또 만나네." / "혼자 한 번 가봤는데..." 등 관계 반영
- 스탯: 유지 또는 소폭 변동 (+/-1~2 랜덤, 혼자 활동한 결과)

**소멸 규칙 (expiry_timer):**

| 조건 | expiry_timer |
|------|-------------|
| 파티 합류 중 | 갱신 중지 (만료 안 됨) |
| 마을에서 재회 (대화) | 타이머 리셋 (168시간 재시작) |
| 파티 재합류 후 해산 | 타이머 리셋 |
| 방치 (접촉 없음) | 카운트다운 진행 |
| 타이머 만료 | 소멸 이벤트 발동 |

**소멸 이벤트 (타이머 만료 시):**

```
확률 판정:
  ├─ 60%: "던전에서 소식이 끊겼다" → 영구 사망 (조용한 퇴장)
  ├─ 25%: "다른 마을로 떠났다" → 영구 이탈 (사망 아닌 퇴장)
  └─ 15%: "어딘가에서 살아남았다" → expiry 자동 연장 1회 (최후 기회)
```

게시판/여관 주인 대사로 소식 전달:
- "그 사람... 던전에서 안 돌아왔대."
- "어제 짐 싸서 떠나더라고."

**설계 의도:**
- 자주 불러오는 NPC → expiry 계속 갱신 → 오래 살아남음
- 방치한 NPC → 자연스럽게 퇴장 → 메모리 관리 + 서사적 의미
- "같이 다닌 동료가 혼자 가서 죽었다" → 감정적 임팩트
- Veteran Pool 상한: 10명 (초과 시 가장 오래된 NPC부터 소멸 판정)

```python
# 데이터 구조 (예상)
_veteran_pool = {
    "npc_unique_id": {
        "unit_data": { ... },       # 스탯/장비/기벽 스냅샷
        "trust": 45,
        "morale": 60,
        "expiry_timer_ms": 604_800_000,  # 168시간
        "last_contact_ms": 12345678,     # 마지막 접촉 시각
        "times_recruited": 3,            # 합류 횟수
    }
}
```

### 5.3 마을에서 사망

마을에서는 사망 대신 **실신 판정**으로 전환.
- HP 0 → 실신 → 구호소 자동 이송
- **리셋 절차 발동하지 않음** — 소지품/소지금 유지
- 구호소 치료비 발생 (economy 연동)
- 침식은 마을에서 자연 감소 → 200 도달 불가
- NPC와의 전투(PvP)에서도 동일 — 실신, 사망 아님

### 5.4 던전 입구에서 사망

던전 region이면 리셋 대상.
입구 방이든 최하층이든 동일 처리.

### 5.5 소지금 보존 수단

| 수단 | 설명 |
|------|------|
| 마을 은행 (향후) | 예치금은 사망 시 유지. 수수료 10% |
| NPC에게 맡기기 | NPC 소유물은 유지 — 신뢰 높은 NPC에게 금화 위탁 |
| 마을 창고 | 아이템만 (소지금 보관 불가) |

**기본: 소지금 전액 소실. 보존하려면 플레이어의 사전 행동 필요.**

### 5.6 진행 중이던 퀘스트/이벤트

| 상황 | 처리 |
|------|------|
| 던전 퀘스트 (특정 몬스터 처치 등) | 진행도 리셋 (던전 재생성) |
| 마을 퀘스트 (NPC 부탁 등) | 유지 (마을 불변) |
| NPC 대화 이벤트 중간 | 유지 (관계 기반) |
| 수집 퀘스트 (소재 N개) | 수집한 소재 소실 → 진행도 후퇴 |

## 6. 가속 루프 — "플레이어는 죽지만 마을이 강해진다"

### 리셋/유지 분류 원칙

| 분류 | 기준 | 예시 |
|------|------|------|
| **리셋 (로그라이크)** | 플레이어 내면 + 던전 | 스탯, 레벨, 도덕성, 수치심, 장비, 던전, 숏컷 |
| **유지 (로그라이트)** | 외부 세계 + 타인과의 관계 | 마을 시설, 은행, 명성, NPC 관계, 도감 |

### 런별 가속 구조

```
1회차: 약한 플레이어 + 빈 마을
  → 느린 진행, F1~F3이 한계
  → 소재/소지금을 마을에 투자 (은행, 시설, NPC)

N회차: 약한 플레이어 + 성장한 마을
  → 은행에서 예치금 인출
  → 레벨 높은 대장간에서 강력 장비 구매
  → 높은 명성으로 우수한 동료 즉시 영입
  → 빠른 레벨업 → 이전 최고 층을 빠르게 돌파
  → 새로운 영역 탐사
```

### 마을 성장 = 영구 투자

| 마을 투자 | 리셋 후 효과 |
|----------|------------|
| 대장간 업그레이드 | 더 강한 장비 **구매** 가능 (1회차엔 조잡만) |
| 은행 예치 | 사망 후 자금 확보 (즉시 장비 구매) |
| 잡화점 확장 | 더 많은 소비/도구 종류 |
| 구호소 업그레이드 | 부활 후 더 나은 기본 장비 |
| NPC 명성/관계 축적 | 높은 신뢰 NPC → 빠른 영입, 더 좋은 초기 관계 |
| 도감 축적 | 몬스터 약점 → 전투 보정, 함정 패턴 → 탐지 보너스 |
| 레시피 축적 | 더 다양한 크래프팅 선택지 |

### 핵심 감각

**"이번에도 죽었지만, 헛되지 않았다."**
- 매 런마다 마을에 뭔가 남긴다 (소재, 돈, 관계, 정보)
- 마을이 강해질수록 초반 구간이 빠르게 지나간다
- 결국 **최전선에서 보내는 시간이 늘어난다**
